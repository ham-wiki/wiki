# 改裝教學

業餘無線電的精神之一就是動手實驗與改造。許多火腿喜歡對自己的設備進行改裝，以獲得更好的性能或更多的功能。本章收集了常見電台的改裝教學，從韌體刷寫到硬體修改，幫助你安全地提升設備能力。

泉盛 UV-K5 是近年最受歡迎的可改裝手持機。了解如何刷入第三方韌體以解鎖頻譜顯示、AM 接收等強大功能。

車機常見的改裝項目，包含擴頻、風扇升級和音頻改善等。

使用 CHIRP 軟體為你的電台進行頻率編程，批次設定記憶頻道。

## 改裝前的注意事項

::: warning 重要提醒
1. **法規遵守**：改裝不得使設備超出法規允許的發射頻率和功率範圍。擴頻改裝後，你仍然只能在業餘頻段內發射。
2. **保固風險**：大部分改裝會導致原廠保固失效。在改裝前請確認你願意承擔這個風險。
3. **備份優先**：在進行韌體刷寫前，務必備份原廠韌體和設定。
4. **循序漸進**：如果你是改裝新手，先從簡單的軟體改裝開始，不要貿然進行硬體修改。
:::
