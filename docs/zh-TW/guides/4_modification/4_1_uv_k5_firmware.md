# 泉盛 UV-K5 韌體刷寫

泉盛 UV-K5 是一款價格低廉但硬體規格意外出色的手持機。它使用了泉盛自家的 DP32G030 微控制器，並被開源社群發現可以完全替換韌體。這使得 UV-K5 成為了業餘無線電史上最受歡迎的可改裝手持機之一。

## 為什麼要刷韌體？

原廠韌體功能較為基本，而第三方韌體可以解鎖許多強大的功能：

- **頻譜分析器**：即時顯示頻譜活動，類似簡易版 SDR 瀑布圖
- **AM 接收模式**：接收航空通信頻段（118-137 MHz）
- **SSB 接收**：部分韌體支援 SSB 解調（品質有限但堪用）
- **更多可自訂功能**：自訂按鍵功能、螢幕顯示、掃描選項
- **改善的掃描速度**：比原廠韌體快得多
- **訊號強度顯示**：更準確的 S 表讀數
- **NOAA 氣象頻道**：接收氣象廣播
- **改善的音頻品質**：部分韌體優化了音頻處理

## 常見的第三方韌體

### Egzumer 韌體

目前最受歡迎的 UV-K5 第三方韌體：

- **GitHub**：github.com/egzumer/uv-k5-firmware-custom
- 基於 LOSEHU 的中文韌體，增加了大量功能
- 頻譜分析器、AM 接收、自訂按鍵等
- 社群活躍，持續更新

### LOSEHU 韌體

中文社群開發的韌體：

- 針對中文使用者優化
- 功能豐富
- 介面友善

### UV-K5 CEC 韌體

另一個活躍的韌體專案：

- 專注於接收功能的增強
- 包含信標（Beacon）功能
- 持續社群開發中

## 刷寫前的準備

### 硬體需求

1. **泉盛 UV-K5（或 UV-K5(8)/UV-K6/UV-5R Plus）**：確認你的機型支援刷寫
2. **編程線**：USB 編程線（通常使用 Kenwood 2-pin 接頭）
3. **電腦**：Windows、macOS 或 Linux

### 軟體需求

1. **USB 驅動程式**：CH340 或 PL2303 晶片的驅動程式（依編程線使用的晶片而定）
2. **韌體刷寫工具**：通常使用網頁版刷寫工具或專用的命令列工具
3. **韌體檔案**：從 GitHub 下載對應的 .bin 韌體檔案

### 備份原廠韌體

**極為重要**：在刷寫第三方韌體之前，務必先備份原廠韌體和校準資料。

1. 使用 UV-K5 備份工具連接電台
2. 讀取並儲存原廠韌體映像
3. 讀取並儲存 EEPROM 資料（包含校準資料和頻道設定）
4. 將備份檔案保存在安全的地方

::: danger 警告
如果不備份校準資料，刷寫韌體後可能會丟失出廠時的頻率校準和功率校準數據。這些數據一旦丟失就無法恢復，會影響電台的發射頻率準確度和功率輸出。
:::

## 刷寫步驟

### 方法一：網頁版刷寫工具（推薦）

這是最簡便的方法，不需要安裝任何軟體：

1. 使用 Chrome 或 Edge 瀏覽器（需要支援 Web Serial API）
2. 前往韌體刷寫網頁（例如 egzumer 提供的線上刷寫頁面）
3. 用編程線連接電台與電腦
4. 關閉電台
5. 在瀏覽器中選擇對應的 COM 埠
6. 按住電台的 PTT 鍵不放，同時開啟電台電源
7. 電台進入刷寫模式（螢幕不亮是正常的）
8. 在瀏覽器中選擇下載好的韌體 .bin 檔案
9. 點擊「Flash」開始刷寫
10. 等待刷寫完成（通常約 30 秒）
11. 刷寫完成後重新開機

### 方法二：命令列工具

1. 安裝 Python 3
2. 安裝刷寫工具：`pip install uv-k5-firmware-flasher`
3. 連接電台並進入刷寫模式
4. 執行刷寫命令

### 刷寫後的設定

1. 開機確認韌體版本
2. 恢復之前備份的 EEPROM 資料（或手動重新設定頻道）
3. 探索新功能：按功能鍵查看頻譜分析器等功能
4. 根據個人偏好自訂按鍵配置

## 常見問題排除

### 無法進入刷寫模式

- 確認編程線接觸良好
- 確認 USB 驅動程式已正確安裝
- 嘗試不同的 USB 埠
- 確認操作順序：先按住 PTT，再開電源

### 刷寫失敗

- 不要恐慌，通常可以重新刷寫
- 重新進入刷寫模式並再試一次
- 嘗試使用不同的韌體版本
- 確認韌體檔案與你的機型相容

### 刷寫後電台無法開機

- 嘗試重新進入刷寫模式（方法與正常刷寫相同）
- 刷回原廠韌體或嘗試其他版本的第三方韌體
- 如果完全無法恢復，可能需要使用 SWD 介面直接燒錄（需要額外的硬體工具）

### 頻率偏移

- 如果校準資料丟失，需要使用已知頻率的信號源重新校準
- 部分韌體提供校準功能，可以在設定選單中調整

## UV-K5 的局限性

雖然第三方韌體大幅增強了 UV-K5 的功能，但硬體限制仍然存在：

- **接收靈敏度**：硬體前端決定了接收性能的上限
- **發射品質**：偽雜散抑制能力有限
- **SSB 接收**：品質遠不如專用的 HF 接收機
- **頻譜分析**：頻寬和動態範圍有限
- **發射功率**：改韌體無法提升實際發射功率

UV-K5 是一台出色的學習和實驗平台，但它不能取代正規的業餘無線電設備。將它定位為一台「有趣的入門工具」會更恰當。

::: tip 建議
UV-K5 搭配 Egzumer 韌體是目前性價比最高的入門方案。花幾百元就能獲得一台功能豐富的手持機，非常適合用來學習和探索業餘無線電。但如果你需要可靠的通信品質，建議日後升級到日系品牌的設備。
:::
