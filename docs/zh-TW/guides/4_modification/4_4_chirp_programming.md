# CHIRP 編程指南

CHIRP 是一款免費、開源的業餘無線電編程軟體，支援超過 300 種不同廠牌和型號的電台。使用 CHIRP 可以在電腦上方便地批次編輯記憶頻道、設定中繼站參數，然後一次性寫入電台，大幅節省手動編程的時間。

## 安裝 CHIRP

### Windows

1. 前往 CHIRP 官方網站（chirp.danplanet.com）下載安裝程式
2. CHIRP 有兩個版本：穩定版（Legacy）和新版（CHIRP-next）
3. 建議使用 CHIRP-next，它支援更多新機型且持續更新
4. 下載後執行安裝程式，按照提示完成安裝

### macOS

1. 下載 macOS 版本的 CHIRP-next
2. 將應用程式拖放到 Applications 資料夾
3. 首次開啟時可能需要在「系統偏好設定」→「安全性與隱私」中允許執行

### Linux

1. 使用 pip 安裝：`pip3 install chirp`
2. 或從官方網站下載 Flatpak 版本
3. 部分 Linux 發行版的套件管理器也有收錄

## 編程線準備

### 常見編程線類型

不同電台使用不同的編程線：

- **Kenwood 2-pin**：寶鋒、泉盛等中國品牌手持機
- **Yaesu SCU-35**：Yaesu FT-65R、FT-70DR 等
- **ICOM OPC-478UC**：ICOM 手持機
- **品牌專用線**：各品牌車機通常有專用的編程線

### USB 驅動程式

大多數編程線使用以下晶片，需要安裝對應的驅動程式：

- **CH340/CH341**：最常見，中國品牌編程線常用
- **PL2303**：較老型號的編程線
- **FTDI FT232**：較高品質的編程線
- **CP2102**：部分品牌使用

安裝驅動程式後，在裝置管理員中確認 COM 埠號碼（例如 COM3、COM5 等）。

## 基本操作流程

### 1. 連接電台

1. 關閉電台
2. 將編程線插入電台的編程介面
3. 將 USB 端插入電腦
4. 開啟電台

### 2. 讀取電台資料

1. 開啟 CHIRP 軟體
2. 選擇 Radio → Download From Radio
3. 選擇正確的 COM 埠（Port）
4. 選擇電台的廠牌和型號
5. 點擊 OK，等待讀取完成

CHIRP 會從電台讀取所有記憶頻道和設定，顯示在電腦畫面上。

::: tip 小提示
每次編程前都建議先從電台讀取現有資料。這不僅能讓你在現有基礎上修改，也相當於一次備份。
:::

### 3. 編輯頻道

CHIRP 的頻道編輯介面類似試算表，每一行代表一個記憶頻道：

| 欄位 | 說明 | 範例 |
|------|------|------|
| Loc | 頻道編號 | 0, 1, 2... |
| Name | 頻道名稱（最多6-8字元） | RPT-01 |
| Frequency | 接收頻率 | 145.240 |
| Duplex | 頻差方向 | +, -, Off |
| Offset | 頻差值 | 0.600000 |
| Tone | 亞音模式 | Tone（CTCSS 發射）、TSQL（收發都用） |
| rToneFreq | 發射亞音頻率 | 88.5 |
| cToneFreq | 接收亞音頻率 | 88.5 |
| DtcsCode | DCS 碼 | 023 |
| Mode | 調變模式 | FM, NFM |
| TStep | 頻率步進 | 12.5 kHz |
| Power | 發射功率 | High, Mid, Low |

### 4. 設定中繼站

設定中繼站頻道時，需要填入以下關鍵資訊：

1. **Frequency**：填入中繼站的接收頻率（你聽到的頻率）
2. **Duplex**：選擇 + 或 -（取決於中繼站的頻差方向）
3. **Offset**：填入頻差值（VHF 通常 0.6 MHz，UHF 通常 5 MHz）
4. **Tone**：選擇 Tone（僅發射亞音）
5. **rToneFreq**：填入中繼站要求的亞音頻率
6. **Name**：給頻道取一個容易辨識的名稱

### 5. 寫入電台

1. 確認所有編輯都正確
2. 選擇 Radio → Upload To Radio
3. 確認 COM 埠和電台型號
4. 點擊 OK，等待寫入完成
5. 寫入完成後在電台上驗證

## 進階功能

### 匯入 / 匯出

CHIRP 支援多種檔案格式：

- **.chirp**：CHIRP 原生格式
- **.csv**：逗號分隔值，可用 Excel 開啟和編輯
- **.img**：電台記憶映像檔

你可以將頻道清單匯出為 CSV 檔案，在 Excel 中批次編輯後再匯入。這對於需要設定大量頻道時非常方便。

### 從頻率資料庫匯入

CHIRP 內建了多種頻率資料庫：

1. 選擇 Radio → Import from data source
2. 選擇資料來源（如 RadioReference、RepeaterBook）
3. 設定搜尋範圍（國家、城市、頻段等）
4. 選擇要匯入的頻道
5. 加入到你的頻道清單中

### 頻道排序

- 可以用拖放的方式重新排列頻道順序
- 也可以按頻率、名稱等欄位排序
- 建議將常用頻道放在前面的編號

### 跨電台複製

如果你有多台電台，可以將一台的頻道設定複製到另一台：

1. 從源電台讀取資料
2. 另存為 .chirp 或 .csv 檔案
3. 開啟新的分頁，連接目標電台
4. 匯入之前儲存的檔案
5. 根據需要調整後寫入

## 常見問題排除

### 無法偵測到電台

- 確認編程線的 USB 驅動程式已安裝
- 確認電台已開機
- 嘗試不同的 COM 埠
- 部分電台需要在特定模式下才能編程

### 讀取或寫入失敗

- 確認選擇了正確的電台型號
- 嘗試降低傳輸速度（如果軟體有此選項）
- 確認編程線接觸良好
- 關閉其他可能佔用 COM 埠的軟體
- 嘗試重新插拔 USB

### 頻道資料不正確

- 仔細檢查頻率、頻差和亞音設定
- 確認亞音模式選擇正確（Tone vs TSQL vs DCS）
- 確認功率設定在電台支援的範圍內

### CHIRP 不支援我的電台

- 確認使用的是最新版本的 CHIRP-next
- 查看 CHIRP 的支援機型清單
- 部分新機型可能需要等待社群開發支援
- 某些電台有品牌專用的編程軟體（如 ICOM 的 CS 系列、Yaesu 的 ADMS 系列）

## 實用技巧

1. **命名規範**：為頻道名稱制定統一的命名規範，例如「地區-用途」（如 TPE-RPT 表示台北中繼站）
2. **分群管理**：將頻道按用途分群（如中繼站群、單頻群、氣象群等）
3. **定期備份**：每次修改後都將頻道清單儲存一份到電腦
4. **共享頻道表**：將整理好的頻道清單分享給社團夥伴
5. **留白頻道**：在頻道清單中預留空位，方便日後新增

::: info 推薦的編程流程
讀取 → 備份 → 編輯 → 確認 → 寫入 → 驗證。養成這個習慣可以避免不小心覆蓋重要的頻道設定。
:::
