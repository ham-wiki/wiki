# Q 碼與縮語

Q 碼（Q Codes）是一套以字母 Q 開頭的三字母縮寫，最初用於商業和軍事無線電通信，後來被業餘無線電廣泛採用。Q 碼可以跨越語言障礙，讓不同國家的火腿高效溝通。

## 常用 Q 碼

### 最常用的 Q 碼

| Q 碼 | 作為問句 | 作為回答/陳述 |
|------|----------|-------------|
| QRA | 你的電台名稱是什麼？ | 我的電台名稱是⋯ |
| QRG | 你的精確頻率是多少？ | 我的精確頻率是⋯ |
| QRH | 我的頻率有漂移嗎？ | 你的頻率有漂移 |
| QRI | 我的音調如何？ | 你的音調是⋯ |
| QRK | 我的信號可讀性如何？ | 你的信號可讀性是⋯ |
| QRL | 這個頻率有人使用嗎？ | 這個頻率正在使用中 |
| QRM | 你受到人為干擾嗎？ | 我受到人為干擾 |
| QRN | 你受到天電干擾嗎？ | 我受到天電干擾 |
| QRO | 我需要增大功率嗎？ | 請增大功率 |
| QRP | 我需要減小功率嗎？ | 請減小功率 / 低功率操作 |
| QRQ | 我需要發得更快嗎？ | 請發得更快 |
| QRS | 我需要發得更慢嗎？ | 請發得更慢 |
| QRT | 我應該停止發射嗎？ | 我要停止發射（關機） |
| QRU | 你有什麼訊息給我嗎？ | 我沒有訊息給你 |
| QRV | 你準備好了嗎？ | 我準備好了 |
| QRX | 你什麼時候再呼叫我？ | 我將在⋯再呼叫你 |
| QRZ | 誰在呼叫我？ | 呼叫你的是⋯ |
| QSB | 我的信號有衰落嗎？ | 你的信號有衰落 |
| QSL | 你能確認收到嗎？ | 我確認收到 / QSL 卡片 |
| QSO | 你能與⋯直接通聯嗎？ | 我能與⋯直接通聯 / 一次通聯 |
| QSP | 你能轉達訊息嗎？ | 我可以轉達訊息 |
| QST | 有給所有電台的公告 | — |
| QSX | 你在什麼頻率上收聽？ | 我在⋯頻率上收聽 |
| QSY | 我應該換到其他頻率嗎？ | 請換到⋯頻率 |
| QTH | 你的位置是哪裡？ | 我的位置是⋯ |

### 最常在日常通聯中使用的

- **QTH**：你在哪裡？ / 我在（某地方）
- **QSL**：收到、確認
- **QSY**：換頻率
- **QRZ**：誰在叫我？
- **QSO**：通聯（名詞用法）
- **QRP**：低功率（也用作形容詞）
- **QRT**：關機、停止操作
- **QRV**：準備就緒
- **QRM**：人為干擾
- **QRN**：自然雜訊/天電干擾
- **QSB**：信號衰落

## RST 信號報告系統

### R - 可讀性（Readability）

| 數值 | 含義 |
|------|------|
| 1 | 不可讀 |
| 2 | 勉強可讀，偶爾能辨認幾個字 |
| 3 | 讀取困難但大致可懂 |
| 4 | 可讀但有些困難 |
| 5 | 完全清楚可讀 |

### S - 信號強度（Signal Strength）

| 數值 | 含義 |
|------|------|
| 1 | 極微弱，幾乎不可察覺 |
| 2 | 很微弱 |
| 3 | 微弱 |
| 4 | 尚可 |
| 5 | 適中 |
| 6 | 良好 |
| 7 | 中等偏強 |
| 8 | 強 |
| 9 | 極強 |

### T - 音調（Tone，僅用於 CW）

| 數值 | 含義 |
|------|------|
| 1 | 極粗糙的交流聲 |
| 5 | 略有音調調變 |
| 9 | 純淨的音調 |

### 實際使用

在 FM 通聯中，通常只用 R 和 S 兩位數，例如「59」。

在 SSB 和 CW 通聯中，使用完整的 RST。例如 CW 通聯中的「599」表示信號完美。

在競賽中，信號報告通常千篇一律地給「59」或「599」，主要是為了效率而非實際信號描述。

## 常見通聯用語範例

### SSB 通聯

```
「CQ CQ CQ, this is Bravo Victor Two X-ray X-ray X-ray,
 BV2XXX calling CQ and listening.」

「BV2XXX, this is Bravo Mike Three Zulu Zulu Zulu, over.」

「BM3ZZZ, thanks for the call.
 Your signal is five nine, my QTH is Taipei.
 My name is David, David. How copy? Over.」

「Roger, QSL. You are also five nine into Taichung.
 My name is Kevin, Kevin. 73, BV2XXX.」

「73 Kevin, thanks for the QSO. BM3ZZZ, BV2XXX clear.」
```

### CW 通聯（簡化）

```
CQ CQ CQ DE BV2XXX BV2XXX K
BV2XXX DE BM3ZZZ BM3ZZZ K
BM3ZZZ DE BV2XXX GM UR 599 QTH TAIPEI OP DAVID HW? K
BV2XXX DE BM3ZZZ R UR 599 QTH TAICHUNG OP KEVIN 73 TU K
BM3ZZZ DE BV2XXX VY 73 CUL SK
```

::: tip 學習建議
不需要一次記住所有的 Q 碼和縮語。從最常用的十幾個開始（QTH、QSL、QSY、QRZ、73、CQ、DE、K），隨著操作經驗的累積，你會自然而然地學會更多。
:::
