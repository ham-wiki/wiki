## 操作的基本原則

無論使用何種模式，業餘無線電操作都應遵循以下基本原則：

1. **先聽後說**：在發射前先監聽頻率，確認沒有正在進行的通聯
2. **報出呼號**：依照規定頻率報出你的呼號
3. **禮讓他人**：業餘頻率是共享資源，不要長時間佔用
4. **保持友善**：業餘無線電社群建立在互助和友善的基礎上
5. **遵守法規**：嚴格遵守執照等級允許的頻率和功率限制
