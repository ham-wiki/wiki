# 應急通信背包

應急通信背包（Go Bag）是一個隨時可以拿起就走的裝備包，裡面包含你在應急情況下提供通信支援所需的所有設備和物資。一個準備完善的 Go Bag 可以讓你在接到通知後 15-30 分鐘內出發。

## 準備原則

### 1. 自給自足

Go Bag 應該讓你在沒有外部支援的情況下，獨立操作至少 24-72 小時。這意味著你需要攜帶足夠的電源、食物和水。

### 2. 輕量化

在保證功能的前提下盡量減輕重量。災害現場可能需要步行較長距離，過重的裝備會降低你的行動能力。

### 3. 模組化

將裝備按功能分成不同的模組（如通信模組、電源模組、生活模組），方便根據任務需求靈活組合。

### 4. 即時可用

所有設備應保持充滿電、設定完成的狀態。定期檢查和測試。

### 5. 冗餘備份

關鍵設備（如電源）應有備份方案。不要將所有雞蛋放在同一個籃子裡。

## 通信設備

### VHF/UHF 設備

| 項目 | 建議 | 說明 |
|------|------|------|
| 手持機 | 雙頻手持機 × 1-2 | 主力通信設備 |
| 備用手持機 | 入門級手持機 × 1 | 備份或借給他人 |
| 車機/基地台 | 視情況攜帶 | 功率更大，通信範圍更廣 |
| 天線 | 原廠 + 加長天線 | Nagoya NA-771 或類似產品 |
| 外接天線 | J-Pole 或 Slim Jim | 可掛在高處大幅改善通信 |

### HF 設備（可選）

| 項目 | 建議 | 說明 |
|------|------|------|
| QRP 電台 | Xiegu G90 或類似 | 遠距通信用 |
| HF 天線 | EFHW 或偶極天線 | 輕量化 HF 天線 |
| 天線調諧器 | 小型 ATU | 如果電台未內建 |

### 數位模式設備（可選）

| 項目 | 建議 | 說明 |
|------|------|------|
| 筆記型電腦/平板 | 輕薄型 | Winlink、FT8 操作用 |
| 音頻介面 | SignaLink USB 或類似 | 電台與電腦的連接 |
| USB 線材 | CAT 控制線 | 電台控制用 |

## 電源系統

電源是應急通信中最關鍵的資源。在災害現場，商業電力可能長時間中斷。

### 電池

| 類型 | 容量建議 | 說明 |
|------|----------|------|
| 手持機電池 | 3-4 塊 | 原廠 + 大容量備用 |
| LiFePO4 電池 | 10-20 Ah | 車機/HF 電台供電 |
| 行動電源 | 20000+ mAh | 手機和小型設備充電 |
| AA/AAA 電池 | 各 8-12 顆 | 通用備用電池，優先選充電式 |

### 充電設備

| 項目 | 說明 |
|------|------|
| 太陽能板 | 20-50W 摺疊式太陽能板 |
| 太陽能充電控制器 | 搭配 LiFePO4 電池使用 |
| 車用充電器 | 利用車輛電源充電 |
| 手搖發電機 | 最後手段的備用電源 |

### 電源管理建議

1. **知道你的功耗**：計算每台設備的耗電量
2. **節約用電**：使用最低可通聯的功率
3. **輪流使用**：不需要通信時關閉設備
4. **善用太陽能**：白天盡量用太陽能補充電力
5. **優先充電**：確保最關鍵的設備（手持機）始終有電

### 估算電力需求

**手持機**（5W 發射）：
- 待機電流：約 50 mA
- 接收電流：約 200 mA
- 發射電流：約 1.5 A
- 以 10% 發射、30% 接收、60% 待機估算
- 1800 mAh 電池約可使用 6-10 小時

**車機**（50W 發射）：
- 接收電流：約 0.5 A
- 發射電流：約 10 A
- 12 Ah LiFePO4 電池約可支撐數小時中等強度操作

## 線材與配件

### 必備線材

- 同軸電纜（3-5m，帶連接器）
- SMA/BNC/SO-239 轉接頭若干
- 電源線（鱷魚夾 + Anderson Powerpole）
- USB 充電線（Type-C、Micro USB）
- 延長電源線

### 工具

- 小型工具組（螺絲起子、尖嘴鉗、剪刀）
- 電工膠帶和自融膠帶
- 束線帶若干
- 繩索（10-20m 的細繩或傘兵繩）
- 小型三用電表

### 天線支撐

- 輕量化伸縮桿或釣竿
- 繩子和重物（拋線用）
- 磁吸式天線底座（車用）

## 文件與記錄

| 項目 | 說明 |
|------|------|
| 執照影本 | 業餘無線電人員執照和電台執照 |
| 身份證件影本 | 個人身份證明 |
| 頻率清單 | 當地中繼站、應急頻率的紙本清單 |
| 通信記錄表 | 空白的訊息記錄表格 |
| 防水筆和記事本 | 防水記錄工具 |
| 地圖 | 當地紙質地圖（手機可能沒電或無信號） |
| 聯絡清單 | 社團成員和應急聯絡人的電話和呼號 |

::: warning 重要
不要完全依賴手機或電腦中的電子資料。在災害現場，電子設備可能沒電或損壞。關鍵資訊（如頻率清單、聯絡人）務必準備紙本備份。
:::

## 個人生活用品

Go Bag 不僅要有通信設備，還要能維持你自己的基本生活需求：

### 基本需求

- 飲用水或濾水器（至少 2 公升）
- 食物（能量棒、乾糧、即食餐，至少 24-72 小時份量）
- 雨衣或防水外套
- 保暖衣物（依季節）
- 手電筒和備用電池
- 急救包
- 個人藥物
- 現金（小額紙鈔和硬幣）

### 舒適與安全

- 防曬用品
- 防蟲噴劑
- 工作手套
- 安全帽或頭燈
- 哨子
- 睡袋或保暖毯（如果需要過夜）

## 背包選擇

### 建議規格

- **容量**：30-50 公升
- **材質**：防水或附有防雨罩
- **結構**：多隔層，便於分類收納
- **舒適性**：有胸帶和腰帶分散重量
- **耐用性**：能承受野外環境的磨損

### 分層收納建議

- **頂層**：立即需要的物品（手持機、頻率清單、手電筒）
- **中層**：通信設備和電源
- **底層**：生活用品和備用物資
- **外掛**：天線桿、繩索等長條物品

## 維護與檢查

Go Bag 準備好後，需要定期維護：

### 每月檢查

- 手持機和電池的電量
- 電池是否需要充放電保養
- 食物和水是否過期

### 每季檢查

- 測試所有電台設備
- 更新頻率清單
- 檢查天線和線材的狀態
- 根據季節更換衣物

### 每年全面檢視

- 更換過期的食物、藥品和電池
- 評估是否需要更新或升級設備
- 參照實際演練的經驗調整裝備清單
- 確認執照和證件都在有效期內

## 快速部署清單

當接到應急通信任務時的行動清單：

1. 確認自身安全和家人安全
2. 拿起 Go Bag
3. 確認手持機有電並設定到應急頻率
4. 向網控台或社團報到
5. 前往指定位置
6. 到達後架設天線和設備
7. 確認通信正常並回報網控台
8. 開始執行通信任務

## 不同規模的 Go Bag

### 基礎版（5-10 kg）

適合短時間（數小時）的應急通信：
- 1 台手持機 + 2 塊電池
- 加長天線
- 頻率清單
- 水和少量食物
- 基本文件

### 標準版（10-15 kg）

適合 24 小時的應急通信部署：
- 以上所有 + 車機或 HF 電台
- LiFePO4 電池 + 太陽能板
- 便攜天線
- 完整的個人生活用品
- 通信記錄工具

### 完整版（15-20 kg）

適合 72 小時的長時間部署：
- 以上所有 + 數位模式設備
- 更多電源和備用設備
- 睡袋和更多生活物資

::: tip 最後提醒
Go Bag 的目的是讓你在緊急時刻能夠快速行動。把它放在容易拿到的地方（如門口的衣櫃或車的後車廂），不要藏在閣樓或地下室。記住：你無法使用你找不到或來不及拿的裝備。
:::
