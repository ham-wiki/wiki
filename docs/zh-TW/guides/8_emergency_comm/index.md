# 應急通信

當地震、颱風、洪水等自然災害發生時，商業通信基礎設施（手機基地台、網際網路、有線電話）往往首先受損。此時，業餘無線電可能是唯一可靠的通信手段。應急通信是業餘無線電最重要的社會功能之一，也是各國政府支持業餘無線電發展的重要原因。

## 業餘無線電在應急通信中的角色

### 歷史案例

業餘無線電在歷次重大災害中發揮了關鍵作用：

- **1999 年台灣 921 大地震**：商業通信中斷，業餘無線電愛好者提供了重要的通信支援
- **2005 年美國卡崔娜颶風**：超過千名火腿參與了為期數週的應急通信
- **2008 年中國汶川地震**：業餘無線電在災區通信中發揮了重要作用
- **2011 年日本 311 大地震**：業餘無線電在海嘯災區提供了關鍵通信
- **各次颱風災害**：台灣每年的颱風季節，業餘無線電都可能派上用場

### 為什麼業餘無線電適合應急通信？

1. **獨立於基礎設施**：不依賴基地台、電纜或網際網路
2. **電力自給**：可以用電池、太陽能或手搖發電機供電
3. **覆蓋範圍廣**：HF 可以跨越數百公里通信
4. **靈活部署**：設備便攜，可以快速建站
5. **訓練有素**：持照火腿具備必要的技術知識
6. **社群網路**：現成的操作員網路和中繼站基礎設施

## 平時準備

應急通信的關鍵在於「平時準備，戰時應用」：

- 定期參加應急通信演練
- 維護設備在良好狀態
- 準備好應急通信背包
- 熟悉當地的應急通信計劃
- 與當地的防災組織建立聯繫
- 學習基本的急救知識

::: warning 重要提醒
應急通信不是業餘愛好者的個人英雄行為。在災害發生時，應在當地應急管理機構的協調下有組織地提供通信支援。未經授權擅自行動可能會干擾正式的救援作業。
:::
