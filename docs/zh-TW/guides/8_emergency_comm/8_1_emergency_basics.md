# 應急通信基礎

應急通信（Emergency Communication，EmComm）是業餘無線電最重要的社會功能。當災害導致正常通信基礎設施癱瘓時，業餘無線電愛好者可以利用自己的設備和技能，為救災行動提供關鍵的通信支援。

## 應急通信的基本原則

### 1. 生命優先

在任何應急狀況下，保護人員安全永遠是第一要務。不要為了提供通信支援而將自己置於危險之中。

### 2. 先評估再行動

災害發生後，先評估自身安全和周圍環境，再決定是否以及如何參與應急通信。

### 3. 聽從指揮

在有組織的應急行動中，聽從應急管理機構和通信指揮者的調度。不要擅自行動或佔用頻率。

### 4. 精確傳達

應急通信中的每一條訊息都可能影響救援決策。確保資訊的準確性，不要傳播未經證實的消息。

### 5. 保持紀律

應急通信頻率上嚴格遵守通信紀律：簡潔、準確、只傳達必要的資訊。

## 應急通信的組織架構

### 國際架構

- **IARU**（國際業餘無線電聯盟）：協調各國業餘無線電組織的應急通信活動
- **ARES**（Amateur Radio Emergency Service）：ARRL 下屬的應急通信服務組織
- **RACES**（Radio Amateur Civil Emergency Service）：美國民防應急無線電服務

### 台灣的應急通信

台灣的業餘無線電應急通信主要透過：

- 各地業餘無線電社團的應急通信小組
- 與地方政府防災單位的合作機制
- 中繼站網路提供的覆蓋範圍
- 火腿社群的自發性協助

### 應急通信網（Emergency Net）

應急通信網是一種有組織的通信模式：

- **網控台（Net Control Station, NCS）**：負責管理通信秩序的電台
- **參與台**：向網控台報到並等待指派任務的電台
- **訊息轉發**：所有訊息透過網控台統一管理和轉發

## 應急通信程序

### 建立通信網

1. 網控台在指定頻率上呼叫建立通信網
2. 各參與台依序報到
3. 網控台記錄可用的電台和它們的位置
4. 指派任務和頻率

### 訊息格式

應急通信中的訊息應使用標準格式，確保資訊完整且不遺漏：

**標準訊息欄位**：
- **訊息編號**：每條訊息的唯一編號
- **優先等級**：緊急（Emergency）、優先（Priority）、福利（Welfare）、一般（Routine）
- **發信台**：發送訊息的電台呼號
- **收信台**：接收訊息的電台呼號或單位
- **發送時間**：UTC 時間
- **訊息內容**：簡潔明確的訊息文字
- **簽收**：收信台確認收到

### 通信優先順序

在應急頻率上，訊息的優先順序為：

1. **MAYDAY（求救）**：有生命危險的緊急求救
2. **PAN-PAN（緊急）**：緊急但非生命危險的情況
3. **優先訊息**：重要的救災相關訊息
4. **福利訊息**：人員安否確認
5. **一般訊息**：其他常規通信

### 求救呼叫

如果你或他人遭遇生命危險：

> 「MAYDAY MAYDAY MAYDAY，這裡是 BV2XXX，我在（位置描述），（情況描述），需要（所需協助）。有人聽到請回應。」

重複三次 MAYDAY，並持續呼叫直到有人回應。

## 應急通信使用的頻率

### VHF/UHF 頻段

- **當地中繼站**：最常用的應急通信管道
- **146.520 MHz**：VHF 國際呼叫頻率（單頻）
- **433.000 MHz**：UHF 呼叫頻率
- 各地可能有指定的應急通信頻率，請事先了解

### HF 頻段

當 VHF/UHF 覆蓋不足時，HF 可以提供更遠的通信距離：

- **7.030 MHz**：40m CW 應急頻率
- **7.060 MHz**：40m LSB 應急頻率
- **14.300 MHz**：20m USB，國際應急通信頻率
- **各頻段的應急通信中心頻率**：請查閱 IARU 的頻率分配建議

### 數位模式

- **Winlink**：透過無線電收發電子郵件，非常適合應急通信中傳遞結構化資訊
- **APRS**：追蹤人員和資源位置
- **FT8**：在極弱信號條件下建立基本通信

## 應急通信的技能

### 必備技能

1. **設備操作**：熟練操作你的所有電台設備
2. **天線架設**：能夠在野外快速架設天線
3. **電源管理**：了解如何使用電池、太陽能板等替代電源
4. **訊息記錄**：準確記錄收發的每條訊息
5. **地圖閱讀**：能夠描述和理解地理位置

### 進階技能

1. **Winlink 操作**：使用無線電電子郵件
2. **NVIS 天線架設**：架設近距離 HF 通信的 NVIS（Near Vertical Incidence Skywave）天線
3. **多頻段操作**：根據情況靈活切換頻段
4. **網控操作**：擔任通信網的網控台

## 應急通信演練

定期參加應急通信演練是保持技能的最佳方式：

### 常見的演練類型

- **桌面推演**：討論式演練，不需要實際操作設備
- **通信演練**：使用電台進行模擬應急通信
- **全面演練**：結合實際部署和通信操作的綜合演練
- **Field Day**：ARRL 的年度野外操作活動，模擬應急條件下的電台架設和操作

### 個人練習

即使沒有組織的演練，你也可以自行練習：

1. 定期使用你的應急通信裝備，確保設備功能正常
2. 練習在不同環境下架設天線
3. 測試電池的續航時間
4. 練習使用替代電源（如太陽能板）
5. 練習快速寫下和傳達標準格式的訊息

## 與官方機構的配合

### 建立聯繫

- 聯繫當地的消防局、民防單位或應急管理辦公室
- 了解他們是否有與業餘無線電合作的機制
- 參加相關的訓練和演練
- 登記為志願通信人員

### 注意事項

- 業餘無線電志願者不是專業救援人員
- 我們的角色是提供通信支援，而非直接參與救援
- 聽從專業救援人員的指揮
- 不要干擾正式的救援行動
- 確保自身安全是第一要務

::: tip 關鍵提醒
最好的應急通信準備就是：平時多練習、設備保持良好狀態、與社群保持聯繫。當災害真正發生時，你才能冷靜、有效地提供通信支援。
:::
