# 基礎概念

在開始你的業餘無線電之旅前，有一些基礎的物理與技術概念需要了解。這些知識不僅是考照的必備內容，更是日後操作電台、選擇設備與製作天線的基礎。

## 頻率與波長

### 什麼是頻率？

頻率是指電磁波每秒鐘振盪的次數，單位為赫茲（Hz）。在業餘無線電中，我們常用的單位包括：

- **千赫（kHz）**：1 kHz = 1,000 Hz
- **兆赫（MHz）**：1 MHz = 1,000,000 Hz
- **吉赫（GHz）**：1 GHz = 1,000,000,000 Hz

例如，FM 廣播電台使用的頻率範圍大約在 88～108 MHz，而業餘無線電的 2 公尺頻段則在 144～148 MHz 左右。

### 什麼是波長？

波長是指一個完整電磁波週期的長度，通常以公尺（m）為單位。頻率與波長之間有一個簡單的反比關係：

$$
\lambda = \frac{c}{f}
$$

其中：

- λ（lambda）為波長，單位為公尺
- c 為光速，約為 300,000,000 m/s（通常簡化為 300 × 10⁶）
- f 為頻率，單位為赫茲

**實用簡化公式**：波長（公尺）= 300 ÷ 頻率（MHz）

例如：

- 144 MHz → 波長約 2.08 公尺（所以稱為「2 公尺頻段」）
- 430 MHz → 波長約 0.70 公尺（所以稱為「70 公分頻段」）
- 7 MHz → 波長約 42.86 公尺（所以稱為「40 公尺頻段」）

波長的概念在天線設計中非常重要，因為天線的尺寸通常與工作頻率的波長成正比。

## 調變方式

調變（Modulation）是將聲音或資料訊號「搭載」到無線電載波上的方法。常見的調變方式包括：

### AM（Amplitude Modulation，振幅調變）

最早的無線電廣播調變方式。透過改變載波的振幅來傳遞訊號。AM 的優點是電路簡單，缺點是容易受到雜訊干擾。在業餘無線電中，AM 已較少使用，但仍有部分愛好者在 HF 頻段使用 AM 進行復古風格的通聯。

### FM（Frequency Modulation，頻率調變）

透過改變載波的頻率來傳遞訊號。FM 的抗雜訊能力比 AM 好得多，音質也更佳。FM 是 VHF/UHF 頻段最常用的類比語音調變方式，大部分中繼站都使用 FM 模式。

- **NFM（Narrow FM，窄頻 FM）**：頻寬約 12.5 kHz，業餘無線電常用
- **WFM（Wide FM，寬頻 FM）**：頻寬約 200 kHz，FM 廣播使用

### SSB（Single Side Band，單邊帶）

SSB 是 AM 的一種改良形式，只傳送上邊帶（USB）或下邊帶（LSB）其中之一，大幅提高了頻譜效率和功率效率。SSB 是 HF 頻段語音通信的主流模式。

- **LSB（Lower Side Band，下邊帶）**：通常在 10 MHz 以下的頻段使用
- **USB（Upper Side Band，上邊帶）**：通常在 10 MHz 以上的頻段使用

### CW（Continuous Wave，等幅電報）

嚴格來說，CW 不是一種調變方式，而是使用摩斯密碼（Morse Code）進行通信的方式。發射機只需要在開和關之間切換。CW 的頻寬極窄（約 150 Hz），因此在微弱信號條件下效率極高，是遠距通信的利器。

### 數位調變

現代業餘無線電中，數位調變方式越來越普遍：

- **FSK（Frequency Shift Keying）**：RTTY 等模式使用
- **PSK（Phase Shift Keying）**：PSK31 等模式使用
- **GFSK**：DMR 數位語音使用
- **MFSK**：FT8、JS8Call 等模式使用
- **C4FM**：Yaesu System Fusion 使用
- **GMSK**：D-STAR 使用

## 發射功率

發射功率是指電台發射機輸出的射頻功率，通常以瓦特（W）為單位。

### 常見功率等級

| 類型 | 典型功率 | 說明 |
|------|----------|------|
| QRP（低功率） | 5W 以下 | 挑戰微弱信號通信 |
| 手持機 | 1～8W | 日常便攜使用 |
| 車機 | 25～75W | 車載或基地台使用 |
| HF 電台 | 5～100W | 短波通信常見功率 |
| 線性放大器 | 100～1000W | 需要較高等級執照 |

### 功率與通信距離

很多新手會認為功率越大，通信距離越遠。但事實上，影響通信距離的因素很多：

- **天線效率與增益**：好的天線比增加功率更有效
- **天線高度**：VHF/UHF 頻段中，天線高度對通信距離影響極大
- **傳播條件**：HF 頻段的電離層傳播效果隨時間、季節變化
- **接收靈敏度**：對方接收機的靈敏度同樣重要
- **調變方式**：CW 和 FT8 等窄頻模式在同等功率下能通信更遠

將功率增加一倍（例如從 5W 增加到 10W），在接收端只會增加約 3 dB 的信號強度，人耳幾乎感覺不到差異。但將功率從 5W 增加到 50W（10 倍），也只增加了 10 dB。相比之下，換一根更好的天線往往能獲得更顯著的改善。

## 駐波比（SWR）

### 什麼是 SWR？

駐波比（Standing Wave Ratio，SWR）是衡量天線系統匹配程度的重要指標。當發射機的輸出阻抗、饋線的特性阻抗、以及天線的輸入阻抗三者匹配時，射頻能量能最有效地傳送到天線並輻射出去。

- **SWR 1:1**：完美匹配，所有能量都被天線輻射出去（理想狀態）
- **SWR 1.5:1**：良好匹配，約 4% 的功率被反射回來
- **SWR 2:1**：可接受，約 11% 的功率被反射
- **SWR 3:1**：需要改善，約 25% 的功率被反射
- **SWR 5:1 以上**：嚴重不匹配，可能損壞發射機

### 如何測量 SWR？

測量 SWR 需要使用 SWR 表（駐波比表）或天線分析儀。將 SWR 表串接在發射機與天線之間，發射時即可讀取數值。

現代的天線分析儀（如 NanoVNA）功能更強大，可以掃描整個頻段的 SWR 曲線，幫助你精確地調整天線。NanoVNA 價格便宜且功能實用，是每位火腿的必備工具之一。

### 如何改善 SWR？

- **調整天線長度**：這是最基本的方法，透過修剪天線元件的長度使其諧振在目標頻率
- **使用天線調諧器（Antenna Tuner）**：在發射機和天線之間加入匹配網路，可以將 SWR 降到可接受範圍
- **檢查饋線與連接器**：鬆動的連接器或受損的饋線都會導致 SWR 升高
- **調整天線位置**：天線周圍的金屬物體會影響其阻抗特性

::: warning 注意
長時間在高 SWR 狀態下發射可能導致發射機過熱甚至損壞。大多數現代電台內建 SWR 保護機制，會在 SWR 過高時自動降低功率，但最好還是在發射前確認 SWR 在可接受範圍內。
:::

## 分貝（dB）

分貝是業餘無線電中經常使用的對數單位，用於表示兩個功率或電壓之間的比值。

### 常用分貝參考

- **0 dB**：無變化
- **3 dB**：功率加倍（或減半）
- **6 dB**：功率變為 4 倍
- **10 dB**：功率變為 10 倍
- **20 dB**：功率變為 100 倍

### 常見分貝單位

- **dBm**：以 1 毫瓦為參考，0 dBm = 1 mW
- **dBi**：天線增益，以等向性天線為參考
- **dBd**：天線增益，以半波偶極天線為參考（dBd ≈ dBi - 2.15）
- **dB**：一般性的比值表示

理解分貝的概念，有助於你評估天線增益、饋線損耗、接收靈敏度等技術指標。
