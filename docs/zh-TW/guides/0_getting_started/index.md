# 入門指南

歡迎來到業餘無線電的世界！業餘無線電（Amateur Radio），俗稱「火腿」（HAM），是一項結合科學、技術與通信的興趣活動。全球有超過三百萬名業餘無線電愛好者，他們透過無線電波跨越國界，彼此交流、實驗，並在緊急時刻提供關鍵的通信支援。

## 為什麼要玩業餘無線電？

- **科學探索**：親手實驗電磁波傳播、天線設計、電子電路等理論
- **全球交友**：與世界各地的火腿通聯，結交志同道合的朋友
- **應急通信**：在自然災害或緊急狀況下，業餘無線電往往是最後可靠的通信手段
- **技術挑戰**：從手工製作天線到撰寫數位通信軟體，永遠有新的挑戰等著你
- **戶外活動**：結合登山、露營等戶外活動，在山頂架設電台與遠方通聯（SOTA）

::: tip 給新手的話
不用擔心自己沒有電子學背景。業餘無線電社群非常歡迎新手，許多老火腿都樂於指導初學者。從一台入門手持機開始，慢慢探索這個精彩的世界吧！
:::
