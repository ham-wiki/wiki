# 什麼是業餘無線電

## 定義

業餘無線電（Amateur Radio）是經由各國電信主管機關核准，供個人在非商業目的下進行無線電通信、技術研究與自我訓練的無線電業務。國際電信聯盟（ITU）在《無線電規則》中明確定義了業餘業務（Amateur Service）與業餘衛星業務（Amateur-Satellite Service），為全球業餘無線電愛好者提供了法律基礎。

業餘無線電操作員通常被暱稱為「火腿」（HAM），這個名稱的由來眾說紛紜。一種說法是早期業餘電台操作員被專業電報員戲稱為「ham-fisted」（笨手笨腳的），後來業餘愛好者反而以此自稱，將其轉化為一種身份認同。

## 發展歷史

### 早期發展（1900 年代初期）

業餘無線電的歷史可以追溯到 20 世紀初。1901 年，馬可尼（Guglielmo Marconi）成功完成跨大西洋無線電通信後，許多科學愛好者開始自行搭建無線電收發設備。這些早期的實驗者就是業餘無線電的先驅。

1914 年，美國業餘無線電聯盟（ARRL）成立，成為全球最早且至今仍最具影響力的業餘無線電組織之一。

### 戰爭時期的貢獻

在兩次世界大戰期間，業餘無線電愛好者為軍方提供了大量受過訓練的通信人才。戰後，這些退役的通信兵將軍用無線電技術帶入民間，推動了業餘無線電的蓬勃發展。

### 現代發展

進入 21 世紀，業餘無線電並未因網際網路和行動電話的普及而消亡，反而融合了數位技術，發展出 DMR、FT8、APRS 等新型態的通信模式。軟體定義無線電（SDR）的出現更大幅降低了進入門檻，讓更多人能夠參與這項活動。

## 業餘無線電 vs CB 對講機 vs FRS 無線電

許多人分不清業餘無線電與市面上常見的對講機有什麼區別。以下做一個簡單的比較：

### CB 對講機（Citizens Band Radio）

- **頻率**：27 MHz 頻段（HF）
- **執照**：在大多數國家不需要執照
- **功率**：通常限制在 4W（AM）或 12W（SSB）
- **用途**：主要用於短距離通信，卡車司機常用
- **限制**：頻道固定、功率低、天線選擇有限

### FRS / GMRS 無線電

- **頻率**：462/467 MHz 頻段（UHF）
- **執照**：FRS 不需要執照；GMRS 在美國需要執照
- **功率**：FRS 限制在 2W，GMRS 可達 50W
- **用途**：家庭、戶外活動短距離通信
- **限制**：不可修改設備、不可使用外接天線（FRS）

### 業餘無線電（Amateur Radio）

- **頻率**：從 1.8 MHz 到 250 GHz 的多個頻段
- **執照**：必須通過考試取得執照
- **功率**：依等級可達 1000W 甚至更高
- **用途**：技術研究、全球通信、應急通信、競賽等
- **優勢**：頻段廣泛、可自製設備與天線、通信距離可達全球

## 業餘無線電能做什麼？

1. **遠距通信**：利用短波（HF）頻段，與地球另一端的火腿直接通聯
2. **衛星通信**：透過業餘衛星進行通信，甚至與國際太空站（ISS）上的太空人對話
3. **月面反射通信（EME）**：將信號發射到月球，利用月面反射與遠方通聯
4. **應急通信**：在地震、颱風等災害中提供緊急通信支援
5. **無線電測向（ARDF）**：俗稱「獵狐」，結合定向運動與無線電技術的體育活動
6. **自製設備**：設計並製作自己的電台、天線、濾波器等設備
7. **數位通信**：使用各種數位模式進行文字、圖像、甚至影像傳輸

## 台灣的業餘無線電

台灣的業餘無線電由國家通訊傳播委員會（NCC）主管。業餘無線電愛好者需通過考試取得業餘無線電人員執照，再申請電台執照後方可合法操作。台灣的業餘無線電呼號以 BM、BN、BO、BP、BQ、BU、BV、BW、BX 等字首開頭。

台灣擁有活躍的業餘無線電社群，中華民國業餘無線電促進會（CTARL）是主要的全國性組織，各地也有許多業餘無線電社團定期舉辦活動。
