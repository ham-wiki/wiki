# 第一步

你已經了解了業餘無線電的基礎知識，現在是時候採取行動了！本篇將引導你完成從考取執照、購買第一台電台，到加入中繼站進行第一次通聯的完整流程。

## 第一步：考取執照

在台灣，要合法操作業餘無線電，你需要取得兩種執照：

1. **業餘無線電人員執照**：證明你具備操作業餘無線電的知識和能力
2. **業餘無線電電台執照**：登記你的電台設備，取得合法的呼號

### 台灣考照流程

1. 向 NCC（國家通訊傳播委員會）報名業餘無線電人員測驗
2. 參加考試並通過（選擇題筆試）
3. 取得業餘無線電人員執照
4. 購買電台設備
5. 向 NCC 申請電台架設許可
6. 取得電台執照及呼號

台灣的業餘無線電執照分為三個等級，初學者應從最基礎的等級開始。考試內容涵蓋無線電法規、基本電學、無線電原理及操作規範。

### 中國大陸考照

如果你在中國大陸，需要透過 CRAC（中國無線電協會）的考試系統。詳細資訊請參閱[中國 CRAC 考試指南](../1_license_exam/1_1_china_crac.md)。

## 第二步：購買你的第一台電台

### 新手推薦：雙頻手持機

對於剛取得執照的新手，一台 VHF/UHF 雙頻手持機是最佳的入門選擇：

**入門級（預算有限）**

- **寶鋒 UV-5R 系列**：價格極低（約新台幣 500-800 元），功能基本齊全，缺點是接收性能和做工一般
- **泉盛 UV-K5**：價格便宜，支援刷入第三方韌體（如 Egzumer），擴充功能強大

**中階推薦**

- **Yaesu FT-65R**：日系品牌，接收性能好，操作簡單
- **ICOM IC-T10**：做工精良，防水防塵

**進階選擇**

- **Yaesu FT-70DR**：支援 C4FM 數位模式
- **ICOM ID-52A**：支援 D-STAR 數位模式，內建 GPS 和藍牙
- **Anytone AT-D878UVII Plus**：支援 DMR 數位模式

### 選購要點

- **雙頻（144/430 MHz）** 是基本需求
- 注意電池容量，較大容量的電池可以使用更長時間
- 如果對數位模式有興趣，可以直接選購支援 DMR 或 C4FM 的機種
- 別忘了額外購買一條較好的天線，原廠天線通常性能一般

## 第三步：基本設定

拿到電台後，你需要進行一些基本設定：

### 1. 設定頻率

- 將電台切換到 VFO（可變頻率振盪器）模式
- 輸入你想使用的頻率
- 對於 2 公尺頻段，嘗試 146.000 MHz 附近的頻率
- 對於 70 公分頻段，嘗試 435.000 MHz 附近的頻率

### 2. 設定亞音（CTCSS / DCS）

大多數中繼站需要設定亞音才能使用：

- **CTCSS（Continuous Tone-Coded Squelch System）**：一種低於可聽範圍的持續音調，常見的有 88.5 Hz、100.0 Hz、127.3 Hz 等
- **DCS（Digital-Coded Squelch）**：數位編碼靜噪，效果比 CTCSS 更好

向當地的業餘無線電社團詢問你所在地區中繼站的頻率和亞音設定。

### 3. 設定頻差（Offset）

中繼站的發射頻率和接收頻率不同，你需要設定正確的頻差：

- 2 公尺頻段通常使用 ±600 kHz 的頻差
- 70 公分頻段通常使用 ±5 MHz 的頻差

### 4. 儲存頻道

將常用的中繼站頻率、亞音、頻差設定儲存到記憶頻道中，方便日後快速切換。也可以使用 CHIRP 軟體透過電腦進行批次設定。

## 第四步：加入中繼站

中繼站（Repeater）是架設在高處的自動轉發站，可以大幅延伸手持機和車機的通信範圍。透過中繼站，一台 5W 的手持機就能與數十公里外的火腿通聯。

### 如何找到中繼站

- 詢問當地的業餘無線電社團
- 在網路上搜尋你所在城市的業餘無線電中繼站資訊
- 台灣的中繼站資訊可以在 CTARL 網站或各地社團的網站上找到

### 中繼站操作禮儀

1. **先聽再發**：在發射前先聽一段時間，確認頻率上沒有其他人在通話
2. **報出呼號**：每次通話開始和結束時，都要報出你的呼號
3. **等待間隔**：在對方說完後，稍等一兩秒再按下 PTT，避免蓋台
4. **保持簡短**：中繼站是共享資源，通話應盡量簡潔
5. **禮貌用語**：使用標準的無線電用語，態度友善

### 你的第一次通聯

準備好了嗎？按下 PTT 按鈕，試著呼叫：

> 「各位火腿朋友大家好，這裡是 BM2XXX（你的呼號），我是剛取得執照的新手，請問有沒有人可以回應？Over。」

不要害怕開口！每位老火腿都曾經是新手，大家都很樂意歡迎新夥伴的加入。

## 第五步：持續學習

取得執照只是起點，業餘無線電的世界非常廣闊：

- **加入社團**：加入當地的業餘無線電社團或線上社群
- **參加活動**：參與各種競賽（Contest）、空中聚會（Net）
- **學習新模式**：嘗試數位模式（DMR、FT8）、CW 電報
- **升級執照**：準備更高等級的考試，解鎖更多頻段和功率
- **動手實作**：從製作簡單的天線開始，體驗 DIY 的樂趣

::: tip 新手常見問題
**Q：手持機通信距離大概多遠？**
A：在平坦地形上，5W 手持機直接通信約 3-10 公里。透過中繼站可以延伸到數十甚至上百公里。

**Q：我需要花很多錢嗎？**
A：不需要。一台入門級手持機（如寶鋒 UV-5R）只需數百元台幣，加上考照費用，總共不到兩千元就能開始。

**Q：我住在公寓，能玩業餘無線電嗎？**
A：當然可以！手持機加上中繼站就能進行通聯。如果想玩 HF，也有許多小型天線方案適合公寓使用，或者帶著便攜設備到戶外操作。
:::
