# SDR 軟體定義無線電

軟體定義無線電（Software Defined Radio，SDR）是一種用軟體來實現傳統硬體電路功能的無線電技術。SDR 將射頻信號直接數位化，然後在電腦或嵌入式處理器中用軟體進行濾波、解調、解碼等處理。這種架構帶來了前所未有的靈活性和可擴展性。

## SDR 的基本原理

傳統無線電接收機使用硬體電路（混頻器、濾波器、解調器等）來處理信號。SDR 則使用高速類比數位轉換器（ADC）將射頻信號轉換為數位資料，然後全部交給軟體處理。

### SDR 接收流程

1. **天線**接收到射頻信號
2. **射頻前端**進行初步放大和濾波
3. **ADC**將類比信號轉換為數位信號
4. **軟體**進行頻率選擇、濾波、解調、解碼

### SDR 的優勢

- **寬頻接收**：一次可以看到整個頻段的信號分佈
- **靈活切換模式**：AM、FM、SSB、CW、各種數位模式全靠軟體切換
- **頻譜顯示**：即時的瀑布圖（Waterfall）讓你一目了然地看到頻譜活動
- **錄製回放**：可以錄製整段頻譜，事後再慢慢分析
- **持續升級**：透過更新軟體就能獲得新功能
- **價格親民**：入門級 SDR 接收器只需數百元

## 僅接收型 SDR

以下設備僅能接收信號，不能發射。非常適合入門學習和信號監測。

### RTL-SDR V3 / V4

- **價格**：約新台幣 300 – 800 元
- **頻率範圍**：500 kHz – 1.7 GHz（V3 含直接取樣模式可降至 HF）
- **頻寬**：約 2.4 MHz
- **介面**：USB
- **優點**：價格極低、社群資源豐富、配套軟體多
- **缺點**：動態範圍有限、8 位元 ADC 解析度不高
- **適合**：完美的入門 SDR，可以用來收聽航空頻段、業餘無線電、氣象衛星等

### Airspy Mini

- **價格**：約新台幣 3000 – 4000 元
- **頻率範圍**：24 MHz – 1.8 GHz
- **頻寬**：6 MHz
- **介面**：USB
- **優點**：12 位元 ADC、動態範圍遠優於 RTL-SDR
- **適合**：需要較好接收性能的 VHF/UHF 監聽

### Airspy HF+ Discovery

- **價格**：約新台幣 5000 – 7000 元
- **頻率範圍**：0.5 kHz – 31 MHz / 60 – 260 MHz
- **優點**：HF 接收性能極佳，可媲美中高階短波接收機
- **適合**：短波（HF）廣播和業餘無線電監聽

### SDRplay RSPdx

- **價格**：約新台幣 6000 – 8000 元
- **頻率範圍**：1 kHz – 2 GHz
- **頻寬**：10 MHz
- **優點**：寬廣的頻率覆蓋、14 位元 ADC、三個天線埠
- **適合**：需要全頻段覆蓋的監聽愛好者

## 收發型 SDR

以下設備具備發射功能，可以作為完整的業餘無線電台使用。

### HackRF One

- **價格**：約新台幣 5000 – 8000 元
- **頻率範圍**：1 MHz – 6 GHz
- **功率**：極低（約 -10 dBm，需外接功率放大器）
- **用途**：主要用於研究和實驗，不適合直接作為業餘電台
- **注意**：半雙工，8 位元 ADC

### ADALM-PLUTO（PlutoSDR）

- **價格**：約新台幣 5000 – 7000 元
- **頻率範圍**：325 MHz – 3.8 GHz（可透過修改擴展到 70 MHz – 6 GHz）
- **優點**：全雙工、12 位元 ADC、可用於衛星通信實驗
- **適合**：微波和衛星通信實驗

### 內建 SDR 的商業電台

許多現代商業電台已經採用 SDR 架構：

- **ICOM IC-7300**：直接取樣 SDR，業餘無線電台的標竿
- **Yaesu FTDX101D**：SDR 架構旗艦機
- **FlexRadio FLEX-6000 系列**：純 SDR 電台，需搭配電腦使用

## SDR 軟體

### Windows 平台

- **SDR#（SDRSharp）**：最受歡迎的免費 SDR 軟體，支援多種 SDR 硬體
- **HDSDR**：功能豐富的免費 SDR 軟體
- **SDR Console**：進階功能豐富，支援遙控操作
- **SDRuno**：SDRplay 官方軟體

### 跨平台

- **GNU Radio**：開源的信號處理框架，功能強大但學習曲線陡峭
- **CubicSDR**：跨平台的開源 SDR 軟體
- **GQRX**：Linux 和 macOS 上常用的 SDR 軟體

### 專用軟體

- **WSJT-X**：FT8/FT4 等弱信號數位模式軟體
- **fldigi**：多模式數位通信軟體
- **DSD+（Digital Speech Decoder）**：DMR/P25/D-STAR 數位語音解碼

## SDR 入門建議

### 第一步：RTL-SDR 起步

1. 購買一個 RTL-SDR V3 或 V4 接收器
2. 安裝 SDR# 軟體
3. 連接天線，開始探索頻譜
4. 嘗試收聽：FM 廣播、航空通信（118-137 MHz）、業餘無線電、氣象衛星（137 MHz）

### 第二步：嘗試解碼

- 使用 WSJT-X 解碼 FT8 信號
- 接收 NOAA 氣象衛星圖像
- 解碼 ADS-B 飛機追蹤信號（1090 MHz）
- 接收 APRS 信號

### 第三步：進階應用

- 升級到更好的 SDR 硬體
- 學習 GNU Radio 進行信號處理
- 搭建自己的 WebSDR 伺服器
- 嘗試衛星通信

::: info 合法使用提醒
使用 SDR 接收信號在大多數國家是合法的，但發射信號則必須持有有效的業餘無線電執照。即使是僅接收，也請尊重通信隱私，不要對截獲的非公開通信內容進行傳播。
:::
