## 選購原則

在購買設備前，請先思考以下問題：

1. **你的執照等級允許什麼？** 不要購買超出你操作權限的設備
2. **你主要想做什麼？** 本地通聯、遠距 DX、數位模式、應急通信？
3. **你的預算是多少？** 從幾百元到數十萬元的選擇都有
4. **你的安裝條件如何？** 公寓、透天厝、車上？
5. **你是否需要便攜性？** 室內固定使用還是戶外攜帶？

::: tip 新手建議
剛入門的新手不需要一步到位購買頂級設備。從一台雙頻手持機開始，邊用邊學，等你更清楚自己的興趣方向後，再升級設備也不遲。
:::
