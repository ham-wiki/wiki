# 手持機選購指南

手持對講機（Handheld Transceiver，簡稱 HT）是大多數火腿的第一台電台。它體積小巧、攜帶方便、價格親民，透過中繼站就能與其他火腿通聯。本篇將幫助你選擇一台適合的手持機。

## 選購要素

### 頻段支援

- **單頻**：僅支援 VHF 或 UHF 一個頻段
- **雙頻**：同時支援 VHF（144 MHz）和 UHF（430 MHz），這是目前最主流的選擇
- **三頻/多頻**：部分機種還支援 220 MHz 或接收航空頻段等

建議至少選擇雙頻機型，能讓你在兩個最常用的頻段上操作。

### 發射功率

手持機的典型功率範圍：

- **低功率**：0.5 – 1W，適合短距離通信，省電
- **中功率**：2 – 3W，日常使用的平衡點
- **高功率**：5 – 8W，最大覆蓋範圍

注意：高功率模式下電池消耗快，而且實際通信距離的提升有限。在能通聯的前提下，盡量使用較低的功率。

### 電池容量

- 標準電池通常為 1500 – 1800 mAh
- 加大電池可達 2500 – 3800 mAh
- 電池容量直接影響使用時間
- 建議準備一塊備用電池

### 數位模式支援

如果你對數位通信有興趣，可以考慮支援以下模式的機型：

- **DMR**：最通用的數位模式，設備選擇多
- **C4FM（System Fusion）**：Yaesu 專有，相容性好
- **D-STAR**：ICOM 專有，網路連線功能強大
- **P25**：主要用於公共安全領域，業餘使用較少

## 入門級手持機

### 寶鋒 UV-5R 系列

- **價格**：約新台幣 500 – 800 元
- **頻段**：VHF + UHF 雙頻
- **功率**：1W / 4W（標稱 8W 的版本實測通常不到 5W）
- **優點**：價格極低、配件豐富、社群資源多
- **缺點**：接收靈敏度一般、互調抑制差、做工粗糙、偽雜散可能超標
- **適合**：預算極有限的入門者，或作為備用機

### 泉盛 UV-K5 / UV-K6

- **價格**：約新台幣 600 – 1000 元
- **頻段**：VHF + UHF 雙頻
- **功率**：約 1W / 5W
- **優點**：支援第三方韌體（如 Egzumer），可大幅擴充功能；頻譜顯示、AM 接收等
- **缺點**：原廠韌體功能較陽春
- **適合**：喜歡折騰和改裝的玩家

### TIDRADIO TD-H8

- **價格**：約新台幣 800 – 1200 元
- **頻段**：VHF + UHF 雙頻
- **功率**：約 5W
- **優點**：較好的接收性能、Type-C 充電、螢幕較大
- **缺點**：品牌知名度較低
- **適合**：想要比寶鋒好一點但預算仍有限的入門者

- **缺點**：不支援數位模式
- **適合**：戶外活動使用者

- **價格**：約新台幣 4500 – 6000 元
- **頻段**：VHF + UHF 雙頻

- **優點**：支援 C4FM 數位模式、可同時監聽類比和數位頻道
- **缺點**：操作介面需要學習
- **適合**：想體驗 Yaesu System Fusion 數位模式的使用者

- **適合**：D-STAR 愛好者、追求頂級手持體驗的使用者

- **價格**：約新台幣 12000 – 15000 元
- **頻段**：VHF + UHF 雙頻
- **功率**：5W
- **優點**：支援 C4FM、觸控螢幕、內建 GPS、藍牙
- **缺點**：價格較高
- **適合**：Yaesu System Fusion 的重度使用者

## 手持機使用技巧

### 延長通信距離

1. **更換天線**：原廠短天線性能有限，換一根較長的第三方天線（如 Nagoya NA-771）可以明顯改善
2. **提高位置**：到高處或空曠處使用，避開建築物遮擋
3. **利用中繼站**：透過中繼站可以將通信距離延伸到數十公里
4. **外接天線**：使用車載天線轉接頭連接外部天線

### 延長電池壽命

1. 使用最低可通聯的功率等級
2. 減少不必要的螢幕背光
3. 調低音量
4. 使用省電模式（如果有的話）
5. 準備備用電池或充電寶

### 保養建議

- 避免跌落和撞擊
- 不要在潮濕環境下為非防水機型充電
- 定期清潔天線接頭和充電觸點
- 長期不用時取出電池
- 避免長時間在高 SWR 狀態下發射（例如未接天線時）

::: warning 注意
絕對不要在未接天線的狀態下發射，這可能會損壞發射機的末級功率放大器。
:::
