# 數位模式

數位模式（Digital Modes）是利用電腦或數位電路對信號進行編碼和解碼的通信方式。相比傳統的類比語音通信，數位模式在抗雜訊能力、頻譜效率和功能擴展性方面都有顯著優勢。

## 數位模式的分類

### 數位語音模式

將語音數位化後進行傳輸：

- **DMR**：ETSI 標準的數位行動無線電
- **C4FM（System Fusion）**：Yaesu 的數位語音系統
- **D-STAR**：ICOM 主導開發的數位語音/資料系統
- **P25**：主要用於公共安全的數位語音系統

### HF 數位通信模式

主要用於 HF 頻段的文字/資料通信：

- **FT8 / FT4**：弱信號數位模式，自動化程度高
- **JS8Call**：基於 FT8 的鍵盤對鍵盤通信
- **PSK31**：經典的鍵盤對鍵盤數位模式
- **RTTY**：無線電傳真（電傳打字）
- **Winlink**：無線電電子郵件系統

### 封包與資料模式

- **APRS**：自動封包回報系統
- **AX.25**：業餘無線電封包通信協定
- **Winlink**：透過無線電收發電子郵件

## 數位模式的優勢

1. **弱信號通信**：FT8 等模式可以在人耳聽不到信號的情況下成功通信
2. **抗干擾能力**：數位信號的錯誤校正能力強
3. **頻譜效率**：多數數位模式佔用的頻寬比類比語音窄
4. **資料傳輸**：可以傳輸文字、位置、圖像等多種資料
5. **自動化操作**：部分模式（如 FT8）可以半自動或全自動運作
6. **網路互連**：DMR、D-STAR 等系統透過網際網路實現全球互連

::: tip 給新手的建議
如果你已經有 HF 電台，強烈建議嘗試 FT8 模式。它操作簡單，在低功率下就能進行全球通聯，是體驗 HF 遠距通信最容易的入門方式。如果你使用 VHF/UHF 手持機，DMR 是最值得嘗試的數位模式。
:::
