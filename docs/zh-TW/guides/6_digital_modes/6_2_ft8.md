# FT8 模式

FT8 是由 Joe Taylor（K1JT）和 Steve Franke（K9AN）在 2017 年開發的弱信號數位通信模式。「FT」代表 Franke-Taylor，「8」代表 8-FSK 調變。自推出以來，FT8 迅速成為 HF 頻段上最活躍的數位模式，徹底改變了業餘無線電的面貌。

## 為什麼 FT8 如此受歡迎？

1. **極強的弱信號能力**：FT8 可以在信噪比 -21 dB 的情況下成功解碼，遠超人耳的極限
2. **低功率就能遠距通聯**：5W 甚至 1W 就能與全球各地通聯
3. **操作門檻低**：軟體半自動操作，不需要精通語音通信技巧
4. **快速通聯**：一次完整的通聯只需要約 75 秒
5. **全天候活躍**：在 HF 各頻段上幾乎 24 小時都有 FT8 活動

## FT8 的技術特性

- **調變方式**：8-GFSK（8 頻移鍵控）
- **頻寬**：約 50 Hz
- **信號週期**：15 秒（每 15 秒一個發射/接收週期）
- **訊息長度**：最多 77 位元（約 13 個字元）
- **時間同步**：需要精確的電腦時鐘（誤差不超過 ±1 秒）
- **最低信噪比**：-21 dB（在 2500 Hz 頻寬參考下）

## 所需設備

### 硬體

1. **HF 電台**：任何能發射 SSB（USB）的電台
2. **電腦**：Windows、macOS 或 Linux
3. **音頻介面**：連接電台與電腦的音頻介面
   - 最簡單：使用內建 USB 音效卡的電台（如 IC-7300）
   - 外接方案：SignaLink USB 或自製隔離介面
4. **CAT 控制線**：讓軟體控制電台的頻率和模式（可選但推薦）

### 軟體

- **WSJT-X**：官方軟體，由 K1JT 團隊開發維護
- **JTDX**：WSJT-X 的分支，提供一些額外功能
- **時鐘同步軟體**：確保電腦時鐘精確

### 時鐘同步

FT8 對時間精度要求很高，電腦時鐘必須與 UTC 同步，誤差不超過 1 秒：

- **Windows**：使用 Meinberg NTP 或 Dimension 4 等 NTP 軟體
- **macOS / Linux**：系統內建的 NTP 通常就足夠
- 在 WSJT-X 的瀑布圖上，如果你看到信號不在正確的時間位置出現，就需要校正時鐘

## 安裝與設定 WSJT-X

### 步驟一：下載安裝

1. 前往 WSJT-X 官方網站（wsjt.sourceforge.io）下載最新版本
2. 按照作業系統的安裝程式進行安裝

### 步驟二：基本設定

開啟 WSJT-X 後，進入 File → Settings：

**General 標籤頁**：
- My Call：填入你的呼號
- My Grid：填入你的網格定位碼（4-6 位，如 PL05）
- 勾選需要的選項

**Radio 標籤頁**：
- Rig：選擇你的電台型號
- Serial Port / Network：設定連接方式
- PTT Method：選擇 PTT 控制方式（CAT 或 VOX）

**Audio 標籤頁**：
- Input：選擇來自電台的音頻輸入裝置
- Output：選擇送往電台的音頻輸出裝置

### 步驟三：測試連接

1. 點擊 Settings 中的「Test CAT」確認電腦可以控制電台
2. 點擊「Test PTT」確認可以控制發射
3. 將電台設定為 USB 模式
4. 在 WSJT-X 主畫面上應該能看到瀑布圖顯示頻譜活動

## FT8 操作流程

### 通聯的四個步驟

一次標準的 FT8 通聯包含四個訊息交換（每個訊息 15 秒）：

| 步驟 | 發送方 | 訊息內容 | 範例 |
|------|--------|----------|------|
| 1 | 呼叫方 | CQ + 呼號 + 網格 | CQ BV2XXX PL05 |
| 2 | 回應方 | 對方呼號 + 自己呼號 + 信號報告 | BV2XXX JA1YYY -12 |
| 3 | 呼叫方 | 對方呼號 + 自己呼號 + 信號報告 | JA1YYY BV2XXX -15 |
| 4 | 回應方 | 對方呼號 + 自己呼號 + RR73 | BV2XXX JA1YYY RR73 |

整個通聯約需 1 分鐘到 1 分 30 秒。

### 呼叫 CQ

1. 確認電台和軟體設定正確
2. 在瀑布圖上找一個沒有信號的空位
3. 設定 TX 頻率（點擊瀑布圖上的空白處）
4. 點擊「Enable TX」按鈕
5. WSJT-X 會自動在下一個偶數（或奇數）時段開始發射 CQ

### 回應 CQ

1. 在解碼清單中看到有人呼叫 CQ
2. 雙擊該訊息
3. WSJT-X 會自動設定回應訊息
4. 確認「Enable TX」已啟用
5. 軟體會在下一個時段自動發射回應

### 完成通聯

WSJT-X 會自動按照標準流程發送後續的訊息。收到對方的 RR73 後，通聯即完成。軟體會自動記錄到日誌中。

## 操作注意事項

### 功率控制

- FT8 不需要大功率，通常 20-50W 就足夠
- QRP（5W）在傳播條件好時也能進行遠距通聯
- **絕對不要使用最大功率**：FT8 使用持續載波，高功率會使發射機過熱
- 電台的 ALC 不應動作（表示音頻電平合適）

### 音頻電平

- 調整音頻輸出電平使電台的 ALC 指示剛好不動作
- 過高的音頻電平會導致信號失真和寬帶干擾
- 在 WSJT-X 中調整「Pwr」滑桿

### 頻率佔用

- 發射前檢查你選擇的頻率上是否有其他信號
- FT8 信號的頻寬約 50 Hz，不要在別人的信號上發射
- 使用「Shift+Click」在瀑布圖上精確選擇 TX 頻率

## FT4 模式

FT4 是 FT8 的快速版本：

- 信號週期：7.5 秒（FT8 的一半）
- 頻寬：約 90 Hz（比 FT8 寬）
- 最低信噪比：-17.5 dB（比 FT8 弱一些）
- 主要用於快節奏的競賽
- 操作方式與 FT8 相同

## 日誌與獎狀

### 自動日誌

WSJT-X 完成通聯後會自動記錄日誌，可以匯出為 ADIF 格式。

### 上傳確認

- **LoTW（Logbook of the World）**：ARRL 的電子確認系統
- **QRZ.com Logbook**：線上日誌
- **eQSL.cc**：電子 QSL 確認
- **PSK Reporter**：即時顯示你的信號被全球哪些站收到

### 相關獎狀

FT8 通聯可以用來申請各種獎狀：

- **DXCC**：通聯 100 個以上的國家/地區
- **WAS**：通聯美國全部 50 州
- **WAC**：通聯全球六大洲
- **Grid Square Awards**：通聯特定數量的網格定位碼

::: tip 新手入門建議
FT8 是 HF 新手最容易上手的模式。建議從 20 公尺頻段（14.074 MHz）開始，這是最活躍的 FT8 頻段。使用 20-30W 功率和一根簡單的偶極天線，你很快就能完成你的第一個 FT8 通聯。
:::
