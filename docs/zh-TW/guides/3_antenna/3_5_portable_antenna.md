# 便攜天線

便攜天線是戶外業餘無線電操作的核心裝備。無論是登山通信（SOTA - Summits on the Air）、公園通信（POTA - Parks on the Air），還是野外應急通信，一根輕巧且容易架設的天線都是不可或缺的。

## 便攜天線的設計考量

- **重量**：越輕越好，背包操作時每一公克都很重要
- **收納尺寸**：方便放入背包或行李箱
- **架設速度**：最好能在 10 分鐘內完成架設
- **結構簡單**：零件越少越不容易遺失或損壞
- **多頻段**：能在多個頻段上工作更加靈活
- **不依賴特殊地形**：不一定每次都能找到樹或高點

## VHF/UHF 便攜天線

### 加長型橡膠天線（Whip Antenna）

- 更換手持機的原廠短天線為較長的第三方天線
- Nagoya NA-771：經典的加長型天線，長約 40 cm
- 成本低、最簡便的改善方案
- 增益比原廠天線好 2-3 dB

### 捲尺八木天線（Tape Measure Yagi）

- 使用金屬捲尺作為天線元件
- 可以捲曲收納，展開後彈性恢復
- 3 元件版本重量不到 300 g
- 增益約 7 dBd
- 非常適合衛星通信和無線電測向

**製作材料**：

- 鋼捲尺 × 3 段（反射器、驅動元件、導向器）
- PVC 管作為臂桿
- 束線帶和管夾固定

### J 型天線（J-Pole）

- 由一段 3/4 波長和一段 1/4 波長的導體組成
- 不需要地線系統
- 可以用銅管或梯線製作
- 捲起後體積小，便於攜帶
- 增益約 0 dBd，但輻射效率高

### Slim Jim 天線

- J-Pole 的改良版，整體為一個折疊的半波振子
- 增益略高於 J-Pole
- 可以用 300Ω 梯線製作，成本極低
- 製作後捲起放入背包，到現場用繩子掛在高處即可

## HF 便攜天線

### 拋線偶極（Wire Dipole）

最簡單的 HF 便攜天線：

- 帶一段預先裁好的電線和一個輕型巴倫
- 到現場用拋線器將繩子拋過樹枝
- 將偶極天線拉成倒 V 形或水平形
- 重量可以控制在 200g 以內

**推薦配置**：

- 40m 偶極：每臂約 10m
- 20m 偶極：每臂約 5m
- 連結環偶極：用鱷魚夾快速切換不同長度

### EFHW（End-Fed Half-Wave，端饋半波天線）

- 從天線的一端饋電，只需要一個高支撐點
- 搭配 49:1 或 64:1 阻抗變換器
- 可以在多個諧波頻段上工作（如 40/20/15/10m）
- 是目前最受歡迎的 HF 便攜天線之一

**優點**：

- 架設方便，只需要一端掛高
- 多頻段操作
- 饋電點在地面，方便連接

**注意事項**：

- 同軸電纜可能會有共模電流，建議使用扼流圈
- 某些頻段的匹配可能不理想
- 阻抗變換器的品質很重要

### 釣竿垂直天線

利用玻璃纖維釣竿作為天線支撐：

- 購買 6-10m 的伸縮釣竿（碳纖維釣竿會導電，須避免）
- 沿釣竿纏繞電線作為垂直輻射元件
- 底部鋪設幾根地線
- 搭配調諧器可以在多個 HF 頻段上工作

**推薦型號**：SOTAbeams、DX Commander 等品牌有專門的釣竿天線套件。

### 磁力環天線（Magnetic Loop）

- 體積小巧，直徑通常 0.5-1.5m
- 不需要地線系統
- 可以在室內或陽台使用
- 頻率調諧透過可變電容器

**優點**：

- 體積極小，適合受限空間
- 對附近的電氣雜訊不太敏感
- 輻射效率在其小尺寸下表現不錯

**缺點**：

- 頻寬極窄，每次換頻都需要重新調諧
- 發射功率受限（高功率時電容器上的電壓很高）
- 效率低於全尺寸天線

### 隨機長度導線（Random Wire）

- 截取一段任意長度的電線（建議避開 1/2 波長的整數倍）
- 一端接在天線調諧器上，另一端盡量掛高
- 搭配天線調諧器可以在多個頻段上工作
- 最簡單、最靈活的便攜天線

建議長度：約 13m 或 20m，這些長度在大多數 HF 頻段上都能比較容易地調諧。

## 便攜天線配件

### 桅杆與支撐

- **伸縮釣竿**：6-10m 玻璃纖維釣竿，重量約 300-500g
- **輕型三腳架**：配合釣竿使用
- **登山杖支撐**：利用登山杖作為臨時桅杆
- **拋線器**：彈弓式或重物式，將繩子拋過樹枝

### 輕量化饋線

- 薄型 RG-174 同軸電纜：重量輕但損耗大，適合短距離
- RG-58 短段：比 RG-174 損耗低，重量適中
- 便攜操作時饋線長度建議控制在 5-10m 以內

### 輕量化調諧器

- Elecraft T1：自動調諧器，僅 170g
- LDG Z-11 Pro II：小型自動調諧器
- 手動 T 型調諧器：可以 DIY，重量依設計而定

## SOTA / POTA 操作建議

### 典型裝備清單

| 項目 | 重量參考 |
|------|----------|
| QRP 電台（如 KX2） | 370g |
| 電池（LiFePO4） | 300-500g |
| EFHW 天線 + 變換器 | 200g |
| 10m 釣竿 | 400g |
| 同軸電纜（5m RG-174） | 100g |
| 繩子、束線帶 | 50g |
| 耳機、鍵 | 100g |
| **總計** | **約 1.5-2 kg** |

### 操作技巧

1. 到達操作點後先觀察地形，選擇最佳的天線架設位置
2. 盡量將天線架高，利用地形優勢
3. 使用 SOTA/POTA 的自我通報（Self-Spot）功能讓其他人知道你在線
4. 先在公認的呼叫頻率上 CQ，再視情況移動頻率
5. QRP 操作時，CW 和 FT8 比 SSB 更容易建立通聯

::: tip 輕量化的祕訣
便攜操作的關鍵是「夠用就好」。不需要追求完美的 SWR 或最高的增益，能成功通聯才是目標。一根簡單的拋線偶極配合 5W QRP 電台，在條件好的時候照樣能通聯全球。
:::
