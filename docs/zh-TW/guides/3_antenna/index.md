# 天線與製作

天線是業餘無線電系統中最重要的環節之一。一句經典的火腿格言是：「最好的投資是天線。」再好的電台，搭配一根差勁的天線，效果也不會好；而一台普通的電台，搭配一根精心調整的天線，往往能獲得令人驚喜的成果。

## 天線的重要性

許多新手傾向於把預算花在電台上，而忽略天線。但事實上：

- 將發射功率從 50W 增加到 100W，只增加了 3 dB
- 而一根好的天線可以輕鬆提供 3-10 dB 的增益改善
- 天線位置（高度）的影響往往比天線本身的類型更大

因此，「先投資天線」是大多數老火腿的建議。

## 自製天線的樂趣

天線是業餘無線電中最適合 DIY 的部分。從最簡單的偶極天線到複雜的八木陣列，你都可以用相對簡單的材料自行製作。自製天線不僅省錢，更能讓你深入理解天線的工作原理。

::: tip 開始動手
如果你從未自己做過天線，建議從一根半波偶極天線開始。它只需要一段電線和一個饋電點，卻是理解天線原理的最佳教材。
:::
