# 知識庫

歡迎來到 HAM.Wiki 業餘無線電知識庫！這裡匯集了從入門到進階的各類業餘無線電知識，無論你是剛接觸無線電的新手，還是已經持照多年的老火腿，都能在這裡找到有用的資訊。

## 章節導覽

### [入門指南](./0_getting_started/)

從零開始認識業餘無線電，了解基礎概念、頻段劃分，以及如何踏出你的第一步。

### [考試與執照](./1_license_exam/)

各國業餘無線電執照考試資訊，包含中國 CRAC、台灣 NCC、美國 FCC、日本及歐洲 CEPT 等考試指南與備考攻略。

### [設備指南](./2_equipment/)

手持機、車機、短波電台、SDR 軟體定義無線電的選購建議，以及各類配件與周邊設備介紹。

### [天線與製作](./3_antenna/)

天線基礎理論與實作，涵蓋偶極天線、垂直天線、八木天線及便攜天線的製作教學。

### [改裝教學](./4_modification/)

常見電台的改裝與韌體刷寫教學，包含泉盛 UV-K5、寶鋒系列，以及 CHIRP 編程指南。

### [操作指南](./5_operating/)

FM 中繼操作、短波通聯、業餘無線電競賽，以及 Q 碼與常用縮語速查。

### [數位模式](./6_digital_modes/)

DMR、FT8、APRS、C4FM、D-STAR 等數位通信模式的介紹與操作教學。

### [書籍與資源](./7_books/)

推薦書籍、線上學習資源，以及業餘無線電常用術語表。

### [應急通信](./8_emergency_comm/)

應急通信的基礎知識與實務操作，以及如何準備一個完善的應急通信背包。

---

::: tip 小提示
如果你是完全的新手，建議從「入門指南」開始閱讀，循序漸進地建立你的業餘無線電知識體系。
:::
