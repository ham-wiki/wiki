# 線上資源

網際網路上有豐富的業餘無線電學習資源。本篇整理了最實用的網站、論壇、影音頻道和行動應用程式。

## 綜合性網站

### QRZ.com

- **網址**：qrz.com
- **簡介**：全球最大的業餘無線電呼號查詢資料庫。輸入任何呼號即可查看操作員的姓名、位置、設備資訊等。也提供論壇、線上日誌和 DX 叢集等功能。
- **必備程度**：極高，每位火腿都應該註冊一個帳號

### ARRL 網站

- **網址**：arrl.org
- **簡介**：美國業餘無線電聯盟的官方網站。提供豐富的技術文章、新聞、教學資源和活動資訊。部分內容需要會員資格。

### eHam.net

- **網址**：eham.net
- **簡介**：業餘無線電設備評測和論壇。在購買設備前查看使用者評價非常有幫助。

### CRAC 網站

- **網址**：crac.org.cn
- **簡介**：中國無線電協會官方網站，提供中國大陸的考試資訊、法規和活動公告。

## 技術與操作資源

### DXWatch / DX Summit

- **網址**：dxwatch.com / dxsummit.fi
- **簡介**：即時 DX 叢集資訊，顯示全球火腿報告的 DX 電台位置和頻率。DX 操作的必備工具。

### PSK Reporter

- **網址**：pskreporter.info
- **簡介**：全球數位模式信號報告地圖。可以看到你的 FT8/CW 信號被世界哪些地方的電台接收到。非常適合評估傳播條件和天線效果。

### VOACAP

- **網址**：voacap.com
- **簡介**：HF 傳播預測工具。輸入你的位置、頻率和時間，即可獲得到達全球各地的傳播預測。

### Repeater Book

- **網址**：repeaterbook.com
- **簡介**：全球業餘無線電中繼站資料庫。可以按位置搜尋附近的中繼站資訊。

### aprs.fi

- **網址**：aprs.fi
- **簡介**：全球 APRS 即時地圖，顯示 APRS 電台的位置和移動軌跡。

### SOTA / POTA

- **sotl.as**：SOTA（Summits on the Air）的活動追蹤和記錄平台
- **pota.app**：POTA（Parks on the Air）官方網站

## 論壇與社群

### Reddit

- **/r/amateurradio**：英文業餘無線電討論區，社群活躍，新手提問友善
- **/r/HamRadio**：另一個業餘無線電相關子版
- **/r/RTLSDR**：SDR 相關討論

### 中文社群

- **業餘無線電相關的 Facebook 社團**：台灣有多個活躍的業餘無線電 Facebook 社團
- **PTT 業餘無線電相關看板**：有時能找到台灣在地的討論
- **中文業餘無線電論壇**：如 HELLOCQ 等中國大陸的業餘無線電論壇
- **各地業餘無線電社團的 LINE 群組**：台灣許多社團使用 LINE 進行日常交流

### Discord

許多業餘無線電主題的 Discord 伺服器，提供即時的文字和語音交流。

## 影音學習

### YouTube 頻道

以下是幾個優質的業餘無線電 YouTube 頻道：

**英文頻道**：

- **Ham Radio Crash Course**：Josh（KI6NAZ）主持，內容豐富，從入門到進階
- **ARRL**：ARRL 官方頻道，技術講座和活動報導
- **DX Commander**：天線製作和便攜操作
- **Ham Radio 2.0**：Jason（KC5HWB）主持，關注數位模式和新技術
- **Temporarily Offline**：SDR 和數位模式技術
- **K6UDA Radio**：設備評測和 DX 操作
- **Ringway Manchester**：無線電歷史和科普

**中文頻道**：

- 各地業餘無線電社團的 YouTube 或 Bilibili 頻道
- 搜尋「業餘無線電」「HAM」「火腿」等關鍵字可以找到相關內容

### Podcast

- **Ham Radio Workbench**：深入的技術討論
- **QSO Today**：訪問各領域的業餘無線電愛好者
- **ICQ Podcast**：英國的業餘無線電播客

## 線上課程

### 免費課程

- **ARRL 線上課程**：部分免費，涵蓋技術和操作主題
- **Dave Casler（KE0OG）的 YouTube 課程**：系統性的考照準備影片
- **MIT OpenCourseWare 的電路課程**：加強電學基礎

### 付費課程

- **Ham Radio Prep**：付費的考試準備課程
- **Udemy 上的無線電相關課程**：搜尋 Amateur Radio 或 SDR

## 軟體資源

### 日誌軟體

- **Log4OM**（免費）：功能豐富的日誌軟體
- **N1MM+**（免費）：競賽日誌的標準
- **Ham Radio Deluxe**（付費）：綜合性的電台控制和日誌軟體
- **WSJT-X**（免費）：FT8/FT4 等弱信號模式

### 天線模擬

- **MMANA-GAL**（免費）：簡單易用的天線模擬軟體
- **4NEC2**（免費）：進階天線模擬
- **NanoVNA Saver**（免費）：NanoVNA 天線分析軟體

### SDR 軟體

- **SDR#（SDRSharp）**（免費）：最流行的 SDR 軟體
- **CubicSDR**（免費）：跨平台 SDR 軟體
- **GNU Radio**（免費）：開源信號處理框架
