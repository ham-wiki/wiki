# 術語表

業餘無線電有許多專業術語和縮寫。本術語表提供中英文對照，方便你在閱讀技術文件或與國際火腿交流時快速查閱。

## A

| 英文 | 中文 | 說明 |
|------|------|------|
| ADC | 類比數位轉換器 | Analog-to-Digital Converter |
| ADIF | 業餘資料交換格式 | Amateur Data Interchange Format，日誌交換標準格式 |
| AF | 音頻 | Audio Frequency |
| AFC | 自動頻率控制 | Automatic Frequency Control |
| AGC | 自動增益控制 | Automatic Gain Control |
| AM | 振幅調變 | Amplitude Modulation |
| AMS | 自動模式選擇 | Automatic Mode Select（C4FM 功能） |
| Antenna Tuner | 天線調諧器 | 又稱 ATU（Automatic Tuner Unit） |
| APRS | 自動封包回報系統 | Automatic Packet Reporting System |
| ARDF | 業餘無線電測向 | Amateur Radio Direction Finding，又稱「獵狐」 |
| ARRL | 美國業餘無線電聯盟 | American Radio Relay League |
| ATU | 自動天線調諧器 | Automatic Tuner Unit |
