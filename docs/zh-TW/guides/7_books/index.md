# 書籍與資源

持續學習是成為優秀火腿的關鍵。本章收集了推薦的書籍、線上學習資源，以及一份業餘無線電常用術語表，幫助你在業餘無線電的道路上不斷進步。

## 本章內容

### [推薦書籍](./7_1_recommended_books.md)

精選的業餘無線電書籍推薦，涵蓋入門教材、技術參考和操作指南。

### [線上資源](./7_2_online_resources.md)

實用的網站、論壇、影音頻道和行動應用程式，讓你隨時隨地學習。

### [術語表](./7_3_glossary.md)

業餘無線電常用術語的中英文對照表，方便快速查閱。

## 學習路徑建議

### 完全新手

1. 先閱讀本 Wiki 的「入門指南」章節
2. 選擇一本入門書籍系統學習
3. 準備並通過考試
4. 開始實際操作

### 已持照火腿

1. 根據興趣方向選擇深入的參考書
2. 關注線上資源獲取最新資訊
3. 參與社群交流分享經驗
4. 準備更高等級的考試
