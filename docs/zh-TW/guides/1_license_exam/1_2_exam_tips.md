# 備考攻略

無論你準備的是哪個國家的業餘無線電考試，良好的備考策略都能讓你事半功倍。本篇整理了實用的學習方法和考試技巧。

## 通用備考策略

### 1. 了解考試範圍

在開始準備之前，先搞清楚考試的具體範圍：

- 取得官方題庫（大多數國家的業餘無線電考試題庫都是公開的）
- 了解各科目的出題比例
- 確認及格分數線和考試時間
- 了解題型（選擇題、填空題或綜合題）

### 2. 制定學習計劃

- **A 類/入門級**：建議準備 2-4 週，每天 1-2 小時
- **B 類/中級**：建議準備 4-8 週，每天 1-2 小時
- **C 類/高級**：建議準備 2-3 個月，需要更深入的學習

### 3. 分階段學習

**第一階段：通讀教材**

先完整地閱讀一遍教材或學習資料，建立整體知識框架。這個階段不需要記住所有細節，重點是理解概念。

**第二階段：做題練習**

開始做模擬試題，標記錯題。針對錯題對應的知識點回頭複習。

**第三階段：重點突破**

集中精力攻克薄弱環節。對於法規部分，需要死記硬背的就老實記；對於技術部分，盡量理解原理而非死背公式。

**第四階段：模擬測驗**

在考前一週，進行多次完整的模擬測驗，讓自己適應考試節奏。

## 各科目學習要點

### 法規部分

法規是考試中佔比較大且相對容易得分的部分：

- **呼號規則**：各類呼號的格式和含義
- **頻率使用**：各等級可用頻段、功率限制
- **操作規範**：通聯程序、識別要求
- **禁止事項**：嚴禁的操作行為
- **干擾處理**：遇到干擾時的處置方式

::: tip 法規記憶技巧
法規內容雖然枯燥，但大多是有邏輯的。試著理解規定背後的原因，而不是單純死記硬背。例如，理解為什麼需要報呼號（識別電台身份）、為什麼限制功率（減少干擾）等。
:::

### 電學基礎

基本電學是很多新手的弱項，但考試中涉及的內容並不深入：

**必須掌握的公式**：

- 歐姆定律：V = I × R
- 功率公式：P = V × I = I² × R = V² / R
- 串聯電阻：R_total = R1 + R2 + R3
- 並聯電阻：1/R_total = 1/R1 + 1/R2 + 1/R3
- 頻率與波長：λ = 300 / f（MHz）
- 諧振頻率：f = 1 / (2π√LC)
- 分貝計算：功率倍數 → dB（3dB = 2倍，10dB = 10倍）

**學習建議**：

- 不要怕數學，考試中的計算都很基本
- 多做計算練習題，熟悉公式的應用
- 理解物理概念比記住公式更重要

### 無線電原理

- **調變方式**：AM、FM、SSB、CW 的原理和特點
- **接收機原理**：超外差式接收機的基本架構
- **發射機原理**：振盪器、調變器、功率放大器
- **天線基礎**：偶極天線、增益、方向性、SWR

### 傳播理論

這是 B 類以上考試的重要內容：

- **地波傳播**：低頻信號沿地面傳播
- **天波傳播**：HF 信號經電離層反射
- **視線傳播**：VHF/UHF 信號的直線傳播
- **電離層結構**：D 層、E 層、F 層的特性
- **太陽活動**：太陽黑子周期對傳播的影響

## 模擬試題資源

### 線上練習平台

- **CRAC 題庫**：中國大陸 A/B/C 類考試的官方題庫，可在 CRAC 網站下載
- **HamTest+**：支援多國考試題庫的行動 App
- **hamstudy.org**：美國 FCC 考試的免費線上練習平台
- **QRZ.com**：提供美國考試的模擬測驗

### 行動應用程式

- **業餘無線電考試**（Android/iOS）：支援 CRAC 題庫的練習 App
- **Ham Radio Exam**：支援多國考試的 App
- **Morse Trainer**：練習摩斯密碼的 App（某些國家的高級考試仍需要 CW 能力）

## 考試當天注意事項

### 考前準備

- 攜帶有效身份證件
- 攜帶准考證或報名確認函
- 帶好考試需要的文具（通常只需要筆）
- 部分考試允許攜帶簡易計算機，事先確認

### 答題策略

1. **先做有把握的題目**：快速瀏覽所有題目，先完成確定答案的題目
2. **排除法**：遇到不確定的題目，先排除明顯錯誤的選項
3. **不要留空**：如果沒有倒扣分數，猜也要猜一個答案
4. **注意陷阱**：仔細閱讀題目，注意「不是」「除了」等否定詞
5. **保持冷靜**：考試時間通常很充裕，不需要趕

### 常見失分點

- **單位混淆**：MHz 和 kHz、W 和 mW 搞混
- **頻段記錯**：將不同等級可用的頻段弄混
- **法規細節**：操作規範中的具體數字和時限
- **計算錯誤**：公式記對了但代入數字時出錯

## 考試通過後

恭喜你通過考試！接下來：

1. 領取執照或操作證書
2. 申請呼號
3. 購買設備並登記備案
4. 開始你的業餘無線電生涯
5. 考慮準備更高等級的考試

::: info 持續進修
業餘無線電的學習永無止境。通過考試只是起點，真正的知識來自於實際操作中的不斷探索和學習。多上線操作、多與老火腿交流、多閱讀技術文章，你的技術水準會持續提升。
:::
