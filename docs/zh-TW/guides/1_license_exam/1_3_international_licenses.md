# 國際執照

業餘無線電是一項全球性的活動，各國都有自己的執照制度。了解國際執照體系不僅有助於你在海外合法操作，也能讓你在與國外火腿通聯時更好地理解對方的操作背景。

## 台灣 NCC 執照

### 主管機關

台灣的業餘無線電由**國家通訊傳播委員會（NCC）**主管，依據《業餘無線電管理辦法》進行管理。

### 執照等級

台灣的業餘無線電人員執照分為三個等級：

| 等級 | 可用頻段 | 最大功率 | 考試內容 |
|------|----------|----------|----------|
| 第三等 | VHF/UHF | 低功率 | 基礎法規與電學 |
| 第二等 | HF + VHF/UHF | 中功率 | 進階技術 |
| 第一等 | 全頻段 | 高功率 | 完整技術考核 |

### 考試方式

- 由 NCC 定期舉辦筆試
- 考試內容包含法規、電學、無線電原理
- 題型為選擇題

### 呼號格式

台灣的業餘無線電呼號字首包括：BM、BN、BO、BP、BQ、BU、BV、BW、BX 等，其中 BV 是最常見的正式呼號字首。呼號中的數字代表不同的行政區域。

### 申請流程

1. 報名參加 NCC 舉辦的業餘無線電人員考試
2. 通過考試後取得業餘無線電人員執照
3. 購買電台設備
4. 向 NCC 申請業餘無線電電台架設許可
5. 取得電台執照與呼號

## 美國 FCC 執照

### 主管機關

美國業餘無線電由**聯邦通信委員會（FCC）**管理。

### 執照等級

| 等級 | 可用頻段 | 說明 |
|------|----------|------|
| Technician | VHF/UHF 全部 + HF 部分 | 入門級，可使用部分 HF 頻段 |
| General | HF 大部分 + VHF/UHF 全部 | 可使用大部分 HF 頻段 |
| Amateur Extra | 全部頻段 | 最高等級，享有全部頻段權限 |

### 考試特點

- **不需要 CW（摩斯密碼）測驗**：自 2007 年起已取消
- **考試由志工主持**：VEC（Volunteer Examiner Coordinator）系統
- **可線上考試**：COVID-19 後開放遠端線上考試
- **可逐級報考**：同一場考試可以連續報考多個等級
- **題庫完全公開**：所有考題都在網上可查

### 考試費用

- 考試費用約 15 美元（由 VEC 組織收取）
- FCC 執照申請費 35 美元
- 執照有效期 10 年，到期可免費續期

### 呼號格式

美國呼號格式為：字首 + 數字 + 後綴（1-3 個字母）

- 字首：K、W、N、AA-AL 等
- 數字：0-9，代表不同地區
- 例如：W1AW（ARRL 總部電台）、K6XXX

### 為什麼台灣人可能想考 FCC？

- FCC 執照在全球知名度高
- 透過國際互認協定，可在許多國家操作
- 線上考試方便，不受地理限制
- 英語題庫資源豐富

## 日本執照

### 主管機關

日本業餘無線電由**總務省**管理。

### 執照等級

| 等級 | 可用頻段 | 最大功率 | 難度 |
|------|----------|----------|------|
| 第四級 | VHF/UHF + HF（限制） | 20W（HF 10W） | 入門 |
| 第三級 | 更多頻段 | 50W | 中級 |
| 第二級 | 全頻段 | 200W | 進階 |
| 第一級 | 全頻段 | 1000W（需申請） | 最高 |

### 考試特點

- 日本的四級考試可以用日語或英語作答
- 考試由 JARD（日本業餘無線電振興協會）舉辦
- 也可以透過講習會的方式取得第四級和第三級執照
- 外國人也可以在日本參加考試

### 呼號格式

日本呼號格式為 JA-JS 字首 + 數字 + 後綴

- 例如：JA1XXX、JH6XXX
- 數字 1-0 代表不同地區（1 為關東、3 為近畿等）

## 歐洲 CEPT 執照

### CEPT 制度

歐洲郵電主管部門大會（CEPT）建立了一套業餘無線電執照互認制度：

- **CEPT T/R 61-01**：允許持有 CEPT 執照的業餘無線電愛好者在其他 CEPT 成員國臨時操作，無需另外申請當地執照
- **CEPT Novice Licence（ECC/REC 05-06）**：入門級的 CEPT 執照互認制度

### CEPT 成員國

目前有超過 40 個國家參與 CEPT 業餘無線電互認制度，涵蓋幾乎所有歐洲國家以及部分歐洲以外的國家。

### HAREC（Harmonised Amateur Radio Examination Certificate）

HAREC 是 CEPT 成員國之間互認的業餘無線電考試標準，持有 HAREC 證書的人可以在任何 CEPT 成員國申請完整的業餘無線電執照。

## 國際操作

### IARP（International Amateur Radio Permit）

國際業餘無線電許可證，主要用於美洲國家之間的互認。

### 互惠操作（Reciprocal Operating）

許多國家之間簽訂了業餘無線電互惠協定，允許對方國家的執照持有人在本國臨時操作。操作時通常需要在自己的呼號前加上所在國的字首。

例如，一位台灣火腿（BV2XXX）在日本操作時，可能使用 JA/BV2XXX 或被分配一個臨時的日本呼號。

### 操作注意事項

在國外操作時，請注意：

1. **遵守當地法規**：即使你有互惠操作權，仍須遵守所在國的法規
2. **頻率限制**：你的操作權限取決於你的執照等級和所在國的規定，取較嚴格者
3. **功率限制**：同上
4. **識別方式**：按照所在國的規定進行電台識別

## 各國執照比較

| 項目 | 台灣 | 中國大陸 | 美國 | 日本 |
|------|------|----------|------|------|
| 等級數 | 3 | 3 | 3 | 4 |
| CW 要求 | 否 | 否 | 否 | 否（2005年後） |
| 題庫公開 | 部分 | 是 | 是 | 部分 |
| 線上考試 | 否 | 否 | 是 | 否 |
| 外國人可考 | 是 | 是 | 是 | 是 |
| 執照有效期 | 有期限 | 長期 | 10年 | 5年 |

::: tip 建議
如果你經常出國旅行或計劃在海外操作業餘無線電，考取美國 FCC 的 General 或 Extra 等級執照是一個不錯的選擇。FCC 執照在全球的認可度很高，而且可以透過線上方式考取，不需要親自前往美國。
:::
