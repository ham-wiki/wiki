# 考試與執照

業餘無線電是受各國法規管理的無線電業務，操作者必須通過考試並取得合法執照後方可上線操作。本章將詳細介紹各國的業餘無線電執照制度與考試資訊。

## 為什麼需要執照？

業餘無線電使用的頻率是寶貴的公共資源，不當使用可能干擾到航空、海事、緊急通信等重要業務。執照制度確保每一位操作者都具備基本的技術知識和法規觀念，能夠負責任地使用無線電頻譜。

## 執照等級概覽

大多數國家的業餘無線電執照分為多個等級，每個等級對應不同的操作權限：

| 國家/地區 | 等級數量 | 基礎等級 | 最高等級 |
|-----------|----------|----------|----------|
| 台灣 | 3 級 | 第三等 | 第一等 |
| 中國大陸 | 3 級 | A 類 | C 類 |
| 美國 | 3 級 | Technician | Amateur Extra |
| 日本 | 4 級 | 第四級 | 第一級 |
| 歐洲 CEPT | 2 級 | CEPT Novice | CEPT |

::: tip 建議
即使你主要在某個國家操作，了解其他國家的執照制度也很有幫助。特別是如果你有出國旅行或移居的計劃，了解國際執照互認制度能讓你在海外也能合法享受業餘無線電的樂趣。
:::
