# 中國 CRAC 考試指南

中國大陸的業餘無線電管理由工業和信息化部（工信部）主管，中國無線電協會（CRAC, Chinese Radio Amateurs Club）負責執行考試和相關服務。本篇將詳細介紹中國大陸的業餘無線電考試制度。

## 執照等級

中國大陸的業餘無線電操作證書分為三個等級：

### A 類（初級）

- **操作權限**：僅限 VHF/UHF 頻段（30 MHz 以上），功率不超過 25W
- **適合人群**：入門新手
- **可用頻段**：144 MHz、430 MHz 等 VHF/UHF 頻段
- **可用模式**：FM、數位模式等

### B 類（中級）

- **操作權限**：可使用 HF 至 UHF 全部業餘頻段，功率不超過 100W
- **適合人群**：想要體驗短波通信的愛好者
- **可用頻段**：1.8 MHz 至 UHF 的所有業餘頻段
- **可用模式**：所有模式（CW、SSB、FM、數位模式等）
- **前置條件**：需先取得 A 類操作證書

### C 類（高級）

- **操作權限**：可使用全部業餘頻段，功率上限最高可達 1000W
- **適合人群**：進階愛好者
- **前置條件**：需先取得 B 類操作證書
- **附加要求**：需具備一定的實際操作經驗

## 考試內容

### A 類考試

A 類考試為入門級考試，題庫公開，考試從題庫中隨機抽取：

- **題目數量**：30 題
- **及格標準**：答對 25 題以上（滿分 30 分，25 分及格）
- **考試時間**：40 分鐘
- **題目類型**：單選題

考試範圍包括：

1. **無線電管理法規**：業餘無線電管理辦法、頻率使用規定
2. **基本電學知識**：歐姆定律、功率計算、交直流電路基礎
3. **無線電基本原理**：調變方式、天線基本概念、傳播基礎
4. **操作規範**：呼號使用、通聯程序、干擾處理

### B 類考試

B 類考試在 A 類的基礎上增加了更多技術內容：

- **題目數量**：50 題
- **及格標準**：答對 40 題以上
- **考試時間**：60 分鐘
- **題目類型**：單選題

額外考試範圍：

1. **進階電學**：RLC 電路、諧振、濾波器
2. **HF 傳播理論**：電離層傳播、太陽活動影響
3. **天線理論**：天線增益、方向性、饋線匹配
4. **安全知識**：射頻安全、電氣安全

### C 類考試

C 類考試是最高等級，技術深度更大：

- **題目數量**：50 題
- **及格標準**：答對 40 題以上
- **考試時間**：60 分鐘

額外考試範圍：

1. **進階電路設計**：放大器、振盪器、混頻器
2. **進階天線理論**：天線陣列、電磁場計算
3. **進階傳播理論**：多種傳播模式的深入分析
4. **電磁相容性（EMC）**：干擾排除、屏蔽技術

## 報名方式

### 線上報名

1. 前往 CRAC 官方網站（www.crac.org.cn）
2. 註冊帳號並完善個人資訊
3. 選擇考試地點和考試時間
4. 完成線上報名

### 考試地點

CRAC 在全國各主要城市設有考點，通常由各地無線電協會或無線電運動協會代為組織。考試通常在週末舉行，具體時間和地點需查看 CRAC 的考試公告。

## 考試後的流程

1. **領取操作證書**：考試通過後，在 CRAC 網站上可以查詢成績和下載電子版操作證書
2. **設置電台**：購買符合規定的業餘無線電設備
3. **申請呼號**：透過 CRAC 網站或當地無線電管理機構申請呼號
4. **備案登記**：將電台設備資訊進行備案登記
5. **合法上線**：完成以上步驟後，即可合法操作業餘無線電

## 中國大陸呼號格式

中國大陸的業餘無線電呼號格式為：

- **B + 等級字母 + 分區數字 + 後綴字母**
- 等級字母：A 類用 D/G/H/I，B 類用 A/D/G/H/I，C 類用 A
- 分區數字：0-9，代表不同省份區域

例如：BH4XXX（B 類，第 4 區）、BA1XXX（C 類，第 1 區北京）

::: warning 注意事項

- 未取得執照即操作業餘無線電屬於違法行為
- A 類操作員不得使用 HF 頻段
- 操作時必須使用核配的呼號
- 操作功率不得超過執照允許的上限
- 嚴禁在業餘頻率上進行商業通信
:::
