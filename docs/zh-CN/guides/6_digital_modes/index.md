# 数字模式简介

数字模式（Digital Modes）是业余无线电中发展最快的领域。通过将信息编码为数字信号，数字模式能够在传统语音模式难以通联的条件下实现可靠通信。

## 什么是数字模式

数字模式是指通过无线电传输数字编码信息的通信方式。与传统的 FM 语音或 SSB 语音不同，数字模式使用计算机或专用设备对信息进行编码和解码。

数字模式可以大致分为两类：

### 1. 数字语音模式

将模拟语音数字化后传输，提供更清晰的音质和更多附加功能：

- **[DMR（数字移动无线电）](./6_1_dmr.md)** — 开放标准，设备选择丰富
- **[C4FM / System Fusion](./6_4_c4fm_dstar.md)** — Yaesu 的数字语音系统
- **[D-STAR](./6_4_c4fm_dstar.md)** — ICOM 开发的数字语音标准

### 2. 数据/文字模式

通过调制解调将文字或数据转化为音频信号传输：

- **[FT8](./6_2_ft8.md)** — 当前最流行的弱信号数字模式
- **[APRS（自动分组位置报告系统）](./6_3_aprs.md)** — 位置追踪和短消息系统
- **RTTY** — 经典的无线电传打字模式
- **PSK31** — 低带宽高效率的键盘对键盘模式
- **JS8Call** — 基于 FT8 技术的键盘聊天模式
- **Winlink** — 通过无线电收发电子邮件

## 为什么选择数字模式

数字模式相比传统模拟模式有诸多优势：

1. **弱信号性能** — FT8 等模式可以在信号淹没在噪声中时仍然解码成功，灵敏度比 SSB 高出 10-20 dB
2. **频谱效率** — 数字模式占用的带宽通常远小于语音模式
3. **抗干扰能力** — 数字编码天然具有更强的纠错能力
4. **自动化** — 许多操作可以由软件自动完成，降低操作门槛
5. **附加功能** — 数字语音模式支持文字消息、GPS 定位、网络互联等

## 入门所需设备

不同的数字模式需要不同的设备，但一些基本配置是通用的：

| 需求 | 数字语音（DMR/C4FM/D-STAR） | 数据模式（FT8/RTTY） | APRS |
|------|---------------------------|---------------------|------|
| 电台 | 支持对应数字模式的电台 | 任何 SSB 电台 | VHF 电台 |
| 电脑 | 写频时需要 | 必须 | 可选 |
| 声卡接口 | 不需要 | 需要（连接电台与电脑） | 不需要 |
| 网络 | 热点需要 | 不需要（但推荐） | iGate 需要 |
| 专用软件 | 写频软件 | WSJT-X 等 | APRSDroid 等 |
