# FT8 模式

FT8（Franke-Taylor design, 8-FSK modulation）是由 Joe Taylor（K1JT）和 Steve Franke（K9AN）于 2017 年开发的数字通信模式。凭借其极强的弱信号解码能力和高度自动化的操作流程，FT8 迅速成为业余无线电中最受欢迎的数字模式。

## FT8 原理

### 技术特点

| 参数 | 值 |
|------|-----|
| 调制方式 | 8-GFSK（8 音频频移键控） |
| 音频带宽 | 约 50 Hz |
| 信号周期 | 15 秒 |
| 传输时长 | 12.64 秒 |
| 信息容量 | 77 bit（含 CRC 校验） |
| 最低信噪比 | 约 -21 dB（远低于人耳可辨识的水平） |
| 频率精度要求 | 时钟误差 < 1 秒 |

### 为什么 FT8 如此强大

FT8 的核心优势在于用**时间换信噪比**：

- 每条消息传输 12.64 秒，远长于语音通联中一个词的持续时间
- 使用前向纠错编码（LDPC），即使部分数据丢失也能恢复
- 8-FSK 调制具有良好的抗噪声性能
- 每条消息仅 77 bit，信息高度压缩

这意味着在 SSB 语音完全无法通联的条件下，FT8 仍然可以成功解码对方的信号。

### FT8 的信号结构

一个完整的 FT8 通联周期为 15 秒，分为偶数序列（0、15、30、45 秒起始）和奇数序列。完成一次标准通联通常需要 4-6 个周期（1-1.5 分钟）。

标准通联流程（以 BH1ABC 呼叫 JA1XYZ 为例）：

```
周期 1: BH1ABC → JA1XYZ  "CQ BH1ABC PM90"          (CQ 呼叫 + 网格)
周期 2: JA1XYZ → BH1ABC  "BH1ABC JA1XYZ PM95"       (回复 + 网格)
周期 3: BH1ABC → JA1XYZ  "JA1XYZ BH1ABC -12"        (信号报告)
周期 4: JA1XYZ → BH1ABC  "BH1ABC JA1XYZ R-15"       (确认 + 信号报告)
周期 5: BH1ABC → JA1XYZ  "JA1XYZ BH1ABC RRR"        (收到确认)
周期 6: JA1XYZ → BH1ABC  "BH1ABC JA1XYZ 73"         (结束)
```

## 所需设备

### 硬件

1. **短波电台（HF Transceiver）** — 任何支持 SSB 模式的短波电台都可以
2. **电脑** — Windows、macOS 或 Linux 均可
3. **声卡接口（Audio Interface）** — 连接电台和电脑的桥梁
4. **天线** — 适合目标频段的天线
5. **电台控制线（CAT Cable）** — 用于电脑控制电台频率和模式（推荐但非必须）

### 声卡接口

声卡接口是 FT8 操作中最关键的连接设备，它负责：

- 将电台接收到的音频信号传送到电脑
- 将电脑生成的 FT8 音频信号传送到电台
- 控制电台的 PTT（发射/接收切换）

**常见声卡接口设备：**

| 设备 | 特点 | 价格 |
|------|------|------|
| **SignaLink USB** | 即插即用，使用广泛 | 中等 |
| **DigiRig Mobile** | 体积极小，集成 CAT 控制 | 较低 |
| **MFJ-1204** | 经济型，基本功能 | 较低 |
| **Yaesu SCU-17** | Yaesu 电台专用接口 | 中等 |
| **ICOM 内置 USB** | 部分 ICOM 电台内置声卡接口 | 无需额外购买 |
| **自制接口** | 使用 USB 声卡 + 隔离变压器 | 最低 |

> **提示：** 许多现代短波电台（如 ICOM IC-7300、Yaesu FT-991A）内置了 USB 声卡接口，只需一根 USB 线即可连接电脑，无需外置声卡接口。

### PTT 控制方式

| 方式 | 说明 |
|------|------|
| **CAT 控制** | 通过电台控制协议切换收发，最推荐 |
| **VOX** | 声控发射，简单但可能误触发 |
| **RTS/DTR** | 通过串口信号控制 PTT |
| **专用 PTT 线** | 部分声卡接口提供独立 PTT 控制 |

## WSJT-X 软件

WSJT-X 是进行 FT8 操作的标准软件，由 Joe Taylor（K1JT）团队开发，免费开源。

### 安装

- 官方下载地址：[physics.princeton.edu/pulsar/k1jt/wsjtx.html](https://physics.princeton.edu/pulsar/k1jt/wsjtx.html)
- 支持 Windows、macOS、Linux
- 下载安装后按提示完成安装

### 基本配置

**1. 电台设置（File → Settings → Radio）**

- **Rig** — 选择你的电台型号
- **Serial Port / Network** — 设置 CAT 控制连接
- **PTT Method** — 选择 PTT 控制方式（推荐 CAT）
- **Mode** — 选择 USB（上边带）

**2. 音频设置（File → Settings → Audio）**

- **Input（输入）** — 选择连接电台的声卡设备（即电台的音频输出）
- **Output（输出）** — 选择连接电台的声卡设备（即电台的音频输入）

**3. 个人信息设置（File → Settings → General）**

- **My Call** — 输入你的呼号
- **My Grid** — 输入你的 6 位网格定位（如 PM90jl）

**4. 时钟同步**

FT8 对时间精度要求极高，电脑时钟误差必须在 1 秒以内。

- **Windows** — 使用 Meinberg NTP 或 Dimension 4 等 NTP 客户端
- **macOS / Linux** — 系统自带 NTP 同步通常足够
- 在 WSJT-X 界面右下角可以看到时间差（dT），应接近 0.0 秒

### 操作界面说明

WSJT-X 的主界面包含：

- **频谱瀑布图（Waterfall）** — 显示接收到的信号在频率-时间维度上的分布
- **解码窗口** — 显示成功解码的消息
- **发射控制区** — 控制发射频率和消息内容
- **日志区** — 记录已完成的通联

## FT8 操作流程

### 接收与解码

1. 启动 WSJT-X，确认电台设置正确
2. 选择目标频段（如 14.074 MHz 是 20m FT8 频率）
3. 将电台设为 USB 模式，频率调到 FT8 频率
4. 观察瀑布图，成功接收到的 FT8 信号会以彩色条纹显示
5. 每 15 秒一个周期，软件自动解码并在解码窗口显示结果

### 常用 FT8 频率

| 波段 | FT8 频率 (MHz) | 模式 |
|------|---------------|------|
| 160m | 1.840 | USB |
| 80m | 3.573 | USB |
| 60m | 5.357 | USB |
| 40m | 7.074 | USB |
| 30m | 10.136 | USB |
| 20m | 14.074 | USB |
| 17m | 18.100 | USB |
| 15m | 21.074 | USB |
| 12m | 24.915 | USB |
| 10m | 28.074 | USB |
| 6m | 50.313 | USB |

### 发起 CQ 呼叫

1. 在瀑布图上选择一个空闲频率位置（点击瀑布图设置 TX 频率）
2. 确认左下角的发射频率（TX offset）没有与其他信号重叠
3. 点击 **"Enable TX"** 按钮
4. 软件会在下一个周期自动发射 CQ 消息
5. 等待有人回复你

### 回复 CQ 呼叫

1. 在解码窗口中找到一个感兴趣的 CQ 呼叫
2. **双击该消息** — 软件自动设置对方信息并开始自动通联序列
3. 在下一个合适的周期，软件自动发射回复
4. 之后的信号报告交换会自动进行
5. 通联完成后软件会提示保存日志

### 发射功率设置

FT8 **不需要大功率**。由于其优秀的弱信号性能：

- 通常使用 20-50W 即可完成大多数通联
- QRP（5W）也能实现远距离通联
- 过大的功率反而可能造成互调失真，干扰其他信号
- 建议从低功率开始，根据需要逐步调整

> **重要：** 确保电台的 ALC 指示不过载。在 WSJT-X 中调整输出音量（Power slider），使电台的 ALC 指示在安全范围内。

## 网格定位（Grid Locator）

FT8 通联中交换的关键信息之一是网格定位（Maidenhead Grid Locator），这是一种将地球表面划分为网格的定位系统。

### 网格定位格式

- 由 2 个字母 + 2 个数字 + 2 个字母组成（如 PM90jl）
- 前 4 位（如 PM90）定义一个约 111km x 55km 的区域
- 6 位完整定位精确到约 4.6km x 9.3km

### 如何查找你的网格定位

1. 使用在线工具：搜索 "Grid Locator Lookup" 输入你的位置
2. 在 Google Maps 上找到你的经纬度，使用转换工具
3. 使用手机 GPS 应用获取经纬度后转换

**中国主要城市网格定位（示例）：**

| 城市 | 大致网格 |
|------|---------|
| 北京 | PM90 |
| 上海 | PM01 |
| 广州 | OL72 |
| 成都 | OM21 |
| 哈尔滨 | PN13 |
| 乌鲁木齐 | MN88 |

## 进阶功能

### PSKReporter

PSKReporter（pskreporter.info）是一个实时显示全球 FT8（及其他数字模式）接收报告的网站。

- 你可以看到谁收到了你的信号
- 也可以看到你收到了哪些电台的信号
- 是判断传播条件的绝佳工具
- WSJT-X 默认会自动向 PSKReporter 上报接收数据

### JTDX

JTDX 是 WSJT-X 的一个分支版本，在解码算法上做了优化：

- 弱信号解码能力略强于 WSJT-X
- 提供更多自动化选项
- 界面布局略有不同
- 适合有经验的操作者

### GridTracker

GridTracker 是一个配合 WSJT-X 使用的辅助软件：

- 在地图上实时显示你收到的信号来源
- 高亮显示你还需要的网格、国家
- 帮助你追踪 DXCC、WAS 等奖状进度
- 免费开源

## 常见问题

### 没有信号解码出来？

1. 检查电脑时钟是否准确（最重要！）
2. 确认电台频率和模式（USB）设置正确
3. 确认音频连接正常（WSJT-X 左下角的音频电平指示应有变化）
4. 检查电台的频段噪声是否太高
5. 确认 WSJT-X 中选择了正确的音频输入设备

### 能解码但发射不出去？

1. 检查 PTT 控制设置
2. 确认音频输出设备选择正确
3. 检查 CAT 控制连接
4. 确认电台没有处于锁定或保护状态

### dT 值偏差很大？

dT（delta Time）显示你的电脑时间与对方的时间差。如果你自己的时钟准确，大的 dT 值说明对方时钟不准。如果所有解码的 dT 都偏向同一方向，说明你自己的时钟需要校准。

### 如何提高通联成功率？

1. 使用合适的天线，天线比功率更重要
2. 关注传播条件，选择正确的波段和时间
3. 不要在拥挤的频率上发射，找一个相对空闲的位置
4. 保持电脑时钟精确同步
5. 适当调整功率，避免 ALC 过载
