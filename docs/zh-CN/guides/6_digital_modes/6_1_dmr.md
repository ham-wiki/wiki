# DMR 数字中继

DMR（Digital Mobile Radio）是一种开放的数字无线电标准，最初由 ETSI（欧洲电信标准协会）为专业移动通信制定。由于其开放性和设备的高性价比，DMR 在业余无线电领域得到了广泛应用。

## DMR 基本原理

### TDMA 时分多址

DMR 采用 TDMA（Time Division Multiple Access，时分多址）技术，将一个 12.5 kHz 的信道分为两个**时隙（Time Slot）**：

- **时隙 1（TS1）** — 第一个逻辑信道
- **时隙 2（TS2）** — 第二个逻辑信道

这意味着一个 DMR 中继器可以在同一频率上同时支持两组独立的通话，频谱效率是传统 FM 中继器的两倍。

### 语音编码

DMR 使用 AMBE+2 语音编解码器对语音进行数字化压缩。每个时隙的数据速率为 3.6 kbps，其中语音数据约 2.45 kbps。虽然带宽有限，但在大多数情况下语音质量完全可以接受。

### 数字信号的优势

- **无底噪** — 没有模拟 FM 的嘶嘶声，要么清晰通话要么完全静默
- **更远的有效距离** — 在信号边缘区域，数字信号比模拟 FM 表现更好
- **数据功能** — 支持短消息、GPS 位置等数据传输

## 核心概念

### 色码（Color Code）

色码类似于模拟 FM 中的 CTCSS 亚音，用于区分使用同一频率的不同系统。色码取值范围为 0-15。

- 你的电台色码必须与中继器的色码一致才能通信
- 大多数业余 DMR 中继器使用色码 1

### 通话组（Talkgroup, TG）

通话组是 DMR 系统中的核心概念，类似于"聊天房间"。加入同一个通话组的电台可以互相听到。

**中国 HAM 常用通话组：**

| 通话组 | 编号 | 说明 |
|--------|------|------|
| World Wide | TG 91 | 全球通话组 |
| Asia Pacific | TG 9 | 亚太地区通话组 |
| China | TG 460 | 中国通话组 |
| BrandMeister China | TG 4600 | BrandMeister 网络中国组 |
| Local | TG 9 (TS2) | 本地通话组（仅覆盖单个中继器） |
| TAC 310 | TG 310 | 常用聊天组 |

**通话组类型：**

- **静态通话组（Static TG）** — 永久链接到中继器的通话组，一直处于活跃状态
- **动态通话组（Dynamic TG）** — 需要用户通过按键触发激活，超时后自动断开
- **私人通话（Private Call）** — 点对点呼叫，使用对方的 DMR ID

### DMR ID

每个 DMR 用户都需要一个唯一的数字 ID，类似于电话号码。

**申请 DMR ID：**

1. 访问 [RadioID.net](https://radioid.net)
2. 使用你的业余无线电呼号注册
3. 获取一个 7 位数的 DMR ID
4. 将 DMR ID 写入你的电台

> **注意：** 一个呼号只能申请一个 DMR ID。申请时需要提供有效的业余无线电执照信息。

## DMR 网络

### BrandMeister

BrandMeister 是目前全球最大的业余 DMR 网络。

**特点：**

- 覆盖全球，中继器数量最多
- 支持通过网页面板和手机 App 操控通话组
- 支持热点（Hotspot）接入
- 可以桥接到其他网络（如 D-STAR、YSF 等）
- 中国大陆有多个 BrandMeister 中继器

**BrandMeister 自助服务：**

- 网址：brandmeister.network
- 可以查看中继器列表、在线用户、通话组活动情况
- 可以管理个人热点的静态通话组设置

### TGIF

TGIF（The Grupo IRLP Forever）是另一个流行的 DMR 网络。

**特点：**

- 独立于 BrandMeister
- 有自己的通话组编号体系
- 社区氛围友好
- 支持热点接入

### 其他网络

- **FreeDMR** — 开源 DMR 网络
- **HBLink** — 另一种开源 DMR 网络架构

## 热点（Hotspot）

热点是 DMR 入门的最佳方式之一，尤其是在你所在地区没有 DMR 中继器的情况下。

### 什么是热点

热点是一个低功率（10-50 mW）的微型收发设备，通过互联网连接到 DMR 网络。你的 DMR 手持台与热点通信，热点再将信号转发到互联网上的 DMR 服务器。

### 常见热点硬件

| 热点 | 特点 | 价格区间 |
|------|------|---------|
| **MMDVM Hotspot** | 最常见，基于树莓派 | 较低 |
| **ZUMspot** | 即插即用，体积小 | 中等 |
| **SharkRF openSPOT** | 独立设备，无需树莓派，配置方便 | 较高 |
| **MMDVM Duplex Hotspot** | 双工版本，支持同时收发 | 中等 |

### 热点固件

- **Pi-Star** — 最流行的热点固件，基于树莓派，支持 DMR/D-STAR/YSF/P25 等多种数字模式
- **WPSD** — Pi-Star 的社区分支，更新更活跃
- **openSPOT 固件** — SharkRF 设备专用

### Pi-Star 基本配置

1. 将 Pi-Star 镜像写入 SD 卡
2. 配置 WiFi 连接
3. 在浏览器中访问 Pi-Star 控制面板（通常为 `http://pi-star.local`）
4. 设置以下关键参数：
   - **呼号** — 你的业余无线电呼号
   - **DMR ID** — 你的 DMR ID
   - **频率** — 热点使用的频率（选择一个不干扰其他电台的频率）
   - **DMR Master** — 选择 BrandMeister 或其他网络
   - **色码** — 设置为 1
   - **静态通话组** — 添加你常用的通话组

## 写频（编程）

DMR 电台需要通过电脑软件进行编程（写频），设置频率、通话组、联系人列表等信息。

### 写频的基本步骤

1. **安装写频软件** — 每个品牌/型号的电台都有对应的 CPS（Customer Programming Software）
2. **获取写频模板** — 从当地 HAM 社群获取已有的写频文件作为起点
3. **配置基本信息：**
   - 你的呼号和 DMR ID
   - 中继器频率、偏移、色码
   - 通话组列表
   - 信道列表
   - 区域（Zone）分组
4. **写入电台** — 通过数据线将配置写入电台

### 写频关键概念

| 概念 | 说明 |
|------|------|
| **信道（Channel）** | 一个完整的通信设置：频率 + 时隙 + 色码 + 通话组 |
| **区域（Zone）** | 信道的分组，方便在电台上切换 |
| **联系人（Contact）** | 通话组或个人的列表 |
| **接收组列表（RX Group List）** | 一个信道上可以接收的通话组列表 |
| **扫描列表（Scan List）** | 要扫描的信道列表 |

### 常见 DMR 电台

| 电台 | 类型 | 特点 |
|------|------|------|
| **Anytone AT-D878UV II Plus** | 手持 | 功能丰富，蓝牙，APRS，性价比高 |
| **Anytone AT-D578UV III Pro** | 车载 | 大功率，双频段，GPS |

| **宝锋 DM-1801** | 手持 | 价格最低的 DMR 入门选择 |

### OpenGD77 固件

OpenGD77 是一个开源固件项目，支持部分 DMR 电台（如 Radioddity GD-77、宝锋 DM-1801 等）。刷入 OpenGD77 后：

- 支持热点直连模式
- 改进的用户界面
- 可以直接在电台上编辑信道参数
- 支持 DMR 和 FM 模式

## DMR 操作流程

### 基本通联流程

1. 选择目标通话组对应的信道
2. 监听是否有正在进行的通联
3. 按下 PTT，报出你的呼号
4. 等待回复
5. 通联过程中保持正常语速，每次发射前稍作停顿
6. 结束通联时报出呼号

### 注意事项

- **PTT 延迟** — 按下 PTT 后等待约 1 秒再开始讲话，确保网络已建立连接
- **松开 PTT 延迟** — 说完话后再等约 0.5 秒再松开 PTT
- **通话组礼仪** — 在公共通话组上保持简洁，避免长时间占用
- **时隙选择** — 遵循中继器管理者的时隙分配规定
- **监听优先** — 发射前确认所选时隙没有正在进行的通联

## 常见问题

### 为什么我能听到别人但别人听不到我？

- 检查你的 DMR ID 是否正确写入电台
- 确认色码和时隙设置是否与中继器一致
- 如果使用热点，检查网络连接是否正常

### 为什么通话断断续续？

- 热点用户：检查网络质量，优先使用有线网络
- 中继器用户：可能处于覆盖边缘，尝试移动位置
- 检查电台发射功率设置

### 如何选择 BrandMeister 还是 TGIF？

建议从 BrandMeister 开始，因为它的中继器和用户数量最多，尤其在中国大陆。如果你的热点支持，也可以同时配置两个网络的 Profile 方便切换。
