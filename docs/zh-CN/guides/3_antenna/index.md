# 天线与制作

## 章节简介

天线是业余无线电台的"嘴巴"和"耳朵"——它将发射机产生的射频电流转换为电磁波辐射到空间中，同时也将空间中的电磁波转换为射频电流送入接收机。一副好天线对通联效果的提升，往往远超升级发射功率所带来的改善。业余无线电界有句老话：**"宁可花钱在天线上，也不要花钱在功率上。"**

本章将从天线的基础理论出发，逐步介绍几种最常见、最实用的天线类型，并提供详细的自制（DIY）教程，帮助你用有限的预算搭建出性能优良的天线系统。

## 天线的重要性

在一个完整的业余无线电台系统中，天线往往是决定通联质量的最关键因素：

- **接收灵敏度**：再好的接收机，如果天线效率低下，也无法收到微弱信号。
- **发射效率**：100W 的发射功率配上一副低效天线，实际辐射出去的有效功率可能不足 10W；而同样的功率配上一副高效天线，等效辐射功率可达数百瓦。
- **信噪比**：合理设计的天线能够抑制特定方向的干扰噪声，提高信噪比。
- **通联距离**：天线的增益和方向性直接决定了你能和多远的电台建立联系。

## 天线基础理论简介

要理解和制作天线，你需要了解以下几个核心概念：

### 电磁波与波长

无线电波是电磁波的一种。电磁波在空间中以光速传播，其波长与频率的关系为：

$$\lambda = \frac{c}{f}$$

其中 $\lambda$ 为波长（米），$c$ 为光速（约 3 × 10⁸ m/s），$f$ 为频率（Hz）。

例如：
- 7 MHz（40 米波段）对应波长约 42.86 米
- 144 MHz（2 米波段）对应波长约 2.08 米
- 430 MHz（70 厘米波段）对应波长约 0.70 米

### 谐振

天线工作的核心原理是**谐振**。当天线的电气长度等于工作频率对应波长的特定比例（如 1/2 波长、1/4 波长）时，天线处于谐振状态，此时：
- 天线阻抗呈纯电阻性，易于与馈线匹配
- 电流分布最优，辐射效率最高

### 关键参数

| 参数 | 含义 | 为什么重要 |
|------|------|-----------|
| 增益 (Gain) | 天线在某方向上集中辐射能量的能力，单位为 dBi 或 dBd | 增益越高，该方向通联距离越远 |
| 方向性 (Directivity) | 天线辐射图案的集中程度 | 定向天线可集中能量于特定方向 |
| 极化 (Polarization) | 电场振动方向（水平/垂直/圆极化） | 收发双方极化不匹配会造成信号损失 |
| 阻抗 (Impedance) | 天线馈电点的交流阻抗 | 需与馈线和发射机匹配 |
| SWR | 驻波比，衡量阻抗匹配程度 | SWR 越接近 1:1 越好 |
| 带宽 (Bandwidth) | SWR 可接受范围内的频率范围 | 带宽越宽，可用频率范围越大 |
