# 应急通信背包

"Go Bag"（应急背包）是预先准备好的应急通信装备包，在紧急情况下可以拎起就走，迅速投入应急通信工作。本页详细介绍应急通信背包的装备配置、电源方案、便携天线选择和防护措施。

## 装备清单

### 通信设备

| 装备 | 说明 | 优先级 |
|------|------|--------|
| VHF/UHF 手持台 | 至少一台双段手持台（如八重洲 FT-65R、宝锋 UV-5R 等），用于本地通信和中继台联络 | 必备 |
| 备用手持台 | 第二台手持台作为备份，或借给没有设备的志愿者 | 推荐 |
| 便携 HF 收发信机 | QRP 或便携 HF 电台（如 Yaesu FT-891、Icom IC-705、Xiegu G90 等），用于远距离通信 | 强烈推荐 |
| 手持台备用电池 | 每台手持台至少准备 2-3 块备用电池 | 必备 |
| 手持台车载/外接天线转接线 | 将手持台连接到外接天线以提升通信效果 | 推荐 |

### 天线系统

| 装备 | 说明 | 优先级 |
|------|------|--------|
| 手持台高增益天线 | 替换原装短天线，可显著提升手持台通信距离（如 NA-771 等） | 必备 |
| 便携 VHF/UHF 天线 | 卷尺八木天线或 J-Pole 天线，轻便易架设 | 推荐 |
| HF 线天线 | 端馈半波天线（EFHW）或偶极天线，重量轻、收纳方便 | 推荐 |
| 天线绳和绝缘子 | 用于将线天线架设到树木或杆子上 | 推荐 |
| 抛线器 / 弹弓 | 将天线绳抛到高处树枝上的工具 | 推荐 |
| 伸缩杆（钓鱼竿） | 6-10 米碳纤维或玻璃纤维伸缩杆，用作天线支撑 | 推荐 |

### 馈线与连接器

| 装备 | 说明 | 优先级 |
|------|------|--------|
| 同轴电缆（RG-58 或 RG-8X） | 5-10 米，带接头，用于连接电台和天线 | 必备 |
| 转接头套装 | SMA/BNC/PL-259/SO-239 各类转接头，确保不同设备间可以互联 | 必备 |
| SWR 表 / 天线分析仪 | 便携型，用于现场调试天线（如 NanoVNA） | 推荐 |

### 电源系统

详见下方"电源方案"章节。

### 辅助装备

| 装备 | 说明 | 优先级 |
|------|------|--------|
| 纸质频率表 | 打印的本地应急频率、中继台频率表，不依赖电子设备 | 必备 |
| 纸和笔 | 记录通信日志和消息，至少准备防水笔记本和铅笔 | 必备 |
| 耳机/耳麦 | 在嘈杂环境中接收信号，也避免打扰他人 | 必备 |
| 手电筒/头灯 | 夜间操作照明，准备备用电池 | 必备 |
| 多功能工具（瑞士军刀等） | 用于现场设备维修和天线架设 | 必备 |
| 电工胶带 / 扎带 | 固定电缆、临时修补 | 推荐 |
| 万用表 | 检测电池电压、线路通断 | 推荐 |
| USB 数据线和读卡器 | 用于数字模式通信时连接电脑 | 推荐 |
| 小型笔记本电脑或平板 | 运行数字模式软件（FT8、Winlink 等） | 可选 |
| 地图（纸质） | 不依赖 GPS 的纸质本地地图 | 推荐 |

## 电源方案

电源是应急通信中最关键的因素之一。没有电，再好的设备也无法工作。建议采用多种电源方案组合，确保冗余。

### 锂电池包

| 方案 | 说明 |
|------|------|
| 大容量锂铁磷酸（LiFePO4）电池 | 推荐 12V/20Ah 以上容量，LiFePO4 安全性高、循环寿命长、放电平台稳定。品牌如 Bioenno 等 |
| 使用建议 | 20Ah 的 LiFePO4 电池可支持 5W QRP 电台连续工作约 20-30 小时（含收听时间） |
| 注意事项 | 提前充满电，每 3 个月检查一次电量，长期存放应保持约 50% 电量 |

### 太阳能充电

| 方案 | 说明 |
|------|------|
| 便携太阳能板 | 推荐 30W-100W 折叠太阳能板，配合太阳能充电控制器为 12V 电池充电 |
| 选择要点 | 选择单晶硅面板效率更高；折叠式方便携带；带有 USB 输出的可同时为手机充电 |
| 充电控制器 | 必须使用 MPPT 或 PWM 太阳能充电控制器，避免过充损坏电池 |
| 实际效率 | 在晴朗天气下，50W 太阳能板实际输出约 30-40W，一天可为 12V/10Ah 电池充满电 |
| 注意事项 | 阴天和雨天发电效率大幅降低，不能完全依赖太阳能 |

### 其他电源

| 方案 | 说明 |
|------|------|
| 移动电源（充电宝） | 适合为手持台（通过 USB 充电器）和手机供电，建议 20000mAh 以上 |
| 车载电源 | 如果有汽车可用，通过点烟器接口取电，注意不要耗尽汽车电瓶 |
| AA/AAA 电池 | 为手持台准备干电池盒（多数手持台有可选配件），AA 碱性电池保质期长、获取方便 |
| 手摇发电机 | 作为最后的备用电源，效率低但不依赖任何外部能源 |
| 小型汽油/丙烷发电机 | 功率充足，但体积大、有噪音，适合固定应急通信站 |

### 电源管理建议

1. **功率控制**：在保证通信质量的前提下使用最低功率（QRP），延长电池使用时间
2. **关闭不必要的功能**：关闭电台背光、降低音量、关闭不需要的扫描功能
3. **监听为主**：发射比接收耗电大得多，多监听少发射
4. **轮换使用**：准备多套电池轮换使用，一套使用时另一套充电
5. **记录用电**：记录电源使用情况，估算剩余可用时间

## 便携天线方案

### VHF/UHF 便携天线

| 天线类型 | 说明 | 增益 | 适用场景 |
|----------|------|------|----------|
| 高增益橡皮天线 | 替换手持台原装天线，如 NA-771（约 40cm） | 2-3 dBi | 日常携带、快速部署 |
| 卷尺八木天线 | 用卷尺制作的轻型定向天线，可折叠 | 7-10 dBi | 需要定向通信或联系较远中继台 |
| J-Pole 天线 | 用同轴电缆或铜管制作，全向辐射 | 3-5 dBi | 固定地点使用，效果优于手持天线 |
| Slim Jim 天线 | J-Pole 的变体，可用梯形线制作，卷起来非常小巧 | 3-5 dBi | 便携首选，重量极轻 |
| 1/4 波长地网天线 | 简单的垂直天线加径向地线 | 2 dBi | 快速架设的固定点天线 |

### HF 便携天线

| 天线类型 | 说明 | 频段 | 适用场景 |
|----------|------|------|----------|
| 端馈半波天线（EFHW） | 一端通过 49:1 变压器馈电的半波天线，长度约 20 米可覆盖 40-10 米波段 | 多频段 | 最推荐的便携 HF 天线 |
| 偶极天线 | 经典的半波偶极，用同轴电缆中心馈电 | 单频段/多频段 | 简单可靠 |
| 随机线天线 + 调谐器 | 任意长度的导线配合天线调谐器使用 | 多频段 | 最灵活的方案 |
| 垂直天线（钓竿天线） | 将导线绕在伸缩杆上或沿杆架设 | 多频段 | 占地面积小 |
| 磁环天线 | 小型磁环天线，适合空间极度受限的场合 | 可调 | 室内或阳台使用 |

### 天线架设技巧

1. **尽量架高**：天线越高效果越好，利用树木、建筑物或伸缩杆
2. **远离金属**：天线应远离金属建筑、栏杆、电线等
3. **注意方向**：偶极天线的最大辐射方向垂直于天线导线方向
4. **快速调谐**：使用 NanoVNA 等便携天线分析仪快速调整天线长度
5. **做好标记**：在天线上标记好各频段对应的长度，现场部署时节省时间

## 防水与防护措施

应急通信往往在恶劣天气条件下进行，设备防护至关重要。

### 背包选择

- 选择防水或带防雨罩的背包（40-60 升容量）
- 内部使用防水袋或密封袋分类收纳
- 背包应有良好的背负系统，因为装备总重可能达到 10-15 公斤

### 设备防水

| 措施 | 说明 |
|------|------|
| 密封袋 | 将电台、电池等放入密封袋（Ziploc 袋或专业防水袋）中 |
| 防水盒 | 使用 Pelican 等品牌的防水硬盒存放精密设备 |
| 保鲜膜 | 临时防水措施，用保鲜膜包裹设备面板和接头 |
| 干燥剂 | 在密封容器中放入干燥剂，防止湿气损坏电子元件 |
| 接头防护 | 未使用的接头盖上防尘帽，防止进水和腐蚀 |

### 其他防护

- **防震**：用泡沫或衣物包裹设备，减少运输中的震动
- **防晒**：太阳能板除外，其他设备和电池应避免长时间暴晒
- **防尘**：在沙尘环境中使用设备时，尽量将接口朝下或遮盖
- **温度**：锂电池在低温下性能下降，注意保温；高温下注意散热

## 背包整理建议

### 分层打包法

```
顶层（最先取用）：
├── 手持台 + 备用电池
├── 耳机
├── 频率表和笔记本
└── 手电筒

中层（主要设备）：
├── HF 收发信机
├── 电源（LiFePO4 电池）
├── 馈线和转接头
└── 笔记本电脑（如需要）

底层（天线和支撑）：
├── 天线（线天线、卷起的馈线）
├── 伸缩杆（外挂于背包侧面）
├── 天线绳和抛线器
└── 太阳能板（外挂或另行携带）

外挂：
├── 伸缩杆
├── 太阳能板
└── 防雨罩
```

### 定期检查

建议每 **3 个月** 进行一次应急背包检查：

- [ ] 所有电池充满电
- [ ] 设备开机测试正常
- [ ] 天线和馈线无损伤
- [ ] 接头连接无松动或腐蚀
- [ ] 频率表信息是否需要更新
- [ ] 纸笔等消耗品是否需要补充
- [ ] 干燥剂是否需要更换
- [ ] 太阳能充电系统测试
