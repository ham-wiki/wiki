# 应急通信基础

业余无线电在应急救灾中发挥着不可替代的作用。本页介绍业余无线电在应急通信中的角色定位、常用频率、标准通信流程以及需要遵循的基本原则。

## 业余无线电在应急中的角色

### 历史作用

在国内外的多次重大灾害中，业余无线电都发挥了关键作用：

- **2008 年汶川地震**：公共通信全面中断后，业余无线电成为部分灾区最早恢复的通信手段
- **2013 年雅安地震**：业余无线电爱好者迅速建立应急通信网络，协助传递救灾信息
- **国际案例**：2011 年日本大地震、2005 年美国卡特里娜飓风等灾害中，业余无线电均承担了重要通信任务

### 主要任务

业余无线电在应急通信中承担的任务包括：

1. **灾情传递**：将灾区情况向外界传报
2. **资源协调**：协助协调救援物资和人员调配
3. **人员寻找**：帮助传递失踪人员和寻亲信息
4. **通信中继**：为救援队伍之间建立通信链路
5. **健康与安全信息**：传递公共卫生和安全信息

## 应急频率

### 国内常用应急频率

以下是国内业余无线电常用的应急和呼叫频率，建议熟记：

| 频段 | 频率 | 模式 | 用途 |
|------|------|------|------|
| 2 米（VHF） | 145.000 MHz | FM | 国内 VHF 呼叫频率 |
| 70 厘米（UHF） | 438.500 MHz | FM | 国内 UHF 常用联络频率 |
| 2 米 | 144.200 MHz | SSB | VHF SSB 呼叫频率 |
| 40 米（HF） | 7.050 MHz | LSB | 国内 HF 日间常用联络频率 |
| 40 米 | 7.030 MHz | CW | 40 米 CW 呼叫频率 |
| 20 米（HF） | 14.270 MHz | USB | 国际应急联络频率 |
| 80 米（HF） | 3.500-3.535 MHz | CW/LSB | 夜间近距离 HF 联络 |

::: warning 注意
具体应急频率可能因地区和时间有所调整，请关注 CRAC 和当地无线电协会的最新公告。在应急通信中，应优先使用当地协调的应急频率。
:::

## 应急通信流程

### 第一阶段：灾害发生（0-2 小时）

1. **确保自身安全**：首先保证自己和家人的人身安全
2. **评估通信能力**：检查你的设备是否完好，电源是否充足
3. **监听**：开机监听本地应急频率和呼叫频率，了解情况
4. **不要盲目发射**：在不了解情况时不要占用频率，先听后说

### 第二阶段：建立联络（2-6 小时）

1. **报告灾情**：如果你处于灾区且有能力通信，向应急通信网报告你所在位置的情况
2. **灾情报告要素**：
   - 你的呼号和位置
   - 灾害类型和程度
   - 人员伤亡情况（如已知）
   - 基础设施受损情况（道路、电力、通信）
   - 是否需要紧急救援
3. **建立通信网**：如果你是有经验的操作者，可以担任网控台（Net Control）组织通信

### 第三阶段：持续保障（6 小时以上）

1. **轮值守听**：与其他火腿协商轮值，确保频率上持续有人值守
2. **信息记录**：准确记录所有收发的信息，包括时间、呼号、内容
3. **电源管理**：合理使用电源，确保通信能力的持续性
4. **转发信息**：将灾区信息传递给外界，将外界指令传回灾区

### 通信网（Net）的基本运作

应急通信通常采用通信网（Net）的形式组织：

- **网控台（NCS, Net Control Station）**：负责组织和协调通信网的运行
- **值守台**：在频率上值守，随时准备参与通信
- **移动台/便携台**：在灾区移动，收集和传递信息

通信网运作规则：

1. 网控台宣布通信网开启，说明目的和频率
2. 各台报到（check-in），报告自己的呼号、位置和通信能力
3. 所有通信通过网控台协调，未经允许不得插入
4. 紧急信息（涉及生命安全）可随时打断
5. 信息传递采用标准格式，确保准确无误

## 应急通信基本原则

### 通信纪律

- **简洁准确**：信息要简明扼要，避免不必要的闲聊
- **使用标准用语**：使用国际通用的通信术语和字母解释法
- **复述确认**：重要信息必须复述确认，确保无误
- **记录在案**：所有重要信息都要书面记录

### 字母解释法（NATO Phonetic Alphabet）

在应急通信中，使用标准字母解释法拼读关键信息可以减少误解：

| 字母 | 读法 | 字母 | 读法 |
|------|------|------|------|
| A | Alpha | N | November |
| B | Bravo | O | Oscar |
| C | Charlie | P | Papa |
| D | Delta | Q | Quebec |
| E | Echo | R | Romeo |
| F | Foxtrot | S | Sierra |
| G | Golf | T | Tango |
| H | Hotel | U | Uniform |
| I | India | V | Victor |
| J | Juliet | W | Whiskey |
| K | Kilo | X | X-ray |
| L | Lima | Y | Yankee |
| M | Mike | Z | Zulu |

### 消息格式

标准应急消息应包含以下要素：

```text
消息编号：____
优先级：紧急 / 优先 / 常规
发自：（呼号和姓名）
发往：（目标呼号或机构）
时间：（UTC 或北京时间）
内容：（具体信息，尽量简洁）
签名：（发送人呼号）
```

## 相关组织和资源

- **CRAC 应急通信委员会**：关注 CRAC 官网获取国内应急通信相关信息
- **ARES（Amateur Radio Emergency Service）**：ARRL 下属的应急通信志愿者组织
- **RACES（Radio Amateur Civil Emergency Service）**：美国民防业余无线电应急服务
- **各地业余无线电协会**：加入当地协会，参与应急通信培训和演练

::: tip 建议
即使你平时主要进行 DX 或竞赛等常规操作，也建议了解应急通信的基本流程。在关键时刻，每一个持有执照的业余无线电爱好者都可能成为生命线。
:::
