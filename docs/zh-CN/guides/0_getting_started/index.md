# 入门指南

欢迎来到业余无线电的世界！本章将带你从零开始，了解业余无线电（Amateur Radio）的方方面面，帮助你迈出成为一名 HAM 的第一步。

## 什么是业余无线电？

业余无线电（Amateur Radio）是一项历史悠久的无线电通信活动。全球数百万持有执照的业余无线电爱好者——我们通常自称为 **HAM**——利用无线电波进行通信、实验和技术探索。业余无线电不同于商业广播或专业通信，它是一种以个人兴趣、技术研究和公共服务为目的的非营利性无线电通信活动。

## "HAM" 的由来

关于 HAM 这个称呼的起源，流传着多种说法：

- **早期电台呼号说**：20 世纪初，哈佛大学的 Albert Hyman、Bob Almy 和 Poogie Murray 三人组建了一个业余电台，取三人姓氏首字母组成呼号 **H-A-M**。他们的电台曾与一家商业电台发生频率干扰纠纷，在国会听证会上 "HAM" 一词因此广为人知。
- **业余操作员的谐称**：在早期无线电通信中，专业报务员将技术不够熟练的业余操作员戏称为 "ham-fisted"（笨手笨脚的），后来 HAM 逐渐从贬义变为业余无线电爱好者的自豪称号。

无论起源如何，今天 **HAM** 已是全球业余无线电爱好者通用的身份标识。

## 为什么要玩业余无线电？

业余无线电的魅力是多方面的：

### 技术探索
业余无线电涉及电子学、电磁波传播、天线设计、数字信号处理等众多技术领域。你可以动手制作自己的收发信机、设计和架设天线、探索不同频段的电波传播特性。这是一个将理论知识转化为实践的绝佳平台。

### 全球通联
通过短波（HF）通信，你可以与世界各地的 HAM 直接交流，无需互联网或卫星中继。在传播条件良好时，仅用几瓦功率就能跨越大洋与另一个大洲的电台建立联系——这种体验是其他通信方式无法替代的。

### 应急通信
在地震、台风、洪水等自然灾害中，当电话网络和互联网瘫痪时，业余无线电往往是最后可用的通信手段。许多国家的应急管理体系都将业余无线电纳入应急通信保障方案。

### 社交与社区
业余无线电拥有活跃的全球社区。你可以通过本地中继与同城 HAM 日常交流，参加各类竞赛（Contest）和活动，结识志同道合的朋友。

### 卫星与太空通信
业余无线电拥有专属的业余卫星（OSCAR），你甚至可以通过国际空间站（ISS）上的业余电台与宇航员通联。

## 业余无线电能做什么？

以下是业余无线电常见的活动和应用方向：

| 活动类型 | 说明 |
|---------|------|
| **语音通联** | 使用 FM、SSB 等模式进行语音通话 |
| **摩尔斯电码（CW）** | 最经典的通信方式，至今仍广受欢迎 |
| **数字模式** | FT8、RTTY、PSK31 等数字通信模式 |
| **卫星通信** | 通过业余卫星进行远距离通信 |
| **月面反射（EME）** | 将信号反射月球表面实现通联 |
| **APRS** | 自动分组报告系统，用于位置追踪和短消息 |
| **应急通信** | 灾害时提供应急通信支援 |
| **竞赛（Contest）** | 在规定时间内尽可能多地通联 |
| **SOTA/POTA** | 山峰/公园便携通联活动 |
| **自制设备** | DIY 收发信机、天线等设备 |
| **无线电测向（Fox Hunting）** | 使用定向天线寻找隐藏发射源 |
