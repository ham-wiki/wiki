# 第一步

恭喜你已经了解了业余无线电的基础知识！现在是时候采取行动了。本文将手把手带你走过从考取执照到完成第一次通联的全过程。

## 第一步：考取业余无线电操作证

在中国，操作业余无线电台必须持有有效的业余无线电台操作证书。未经许可擅自发射无线电信号是违法行为。

### 操作证等级

| 等级 | 报名条件 | 可用频段 | 最大功率 |
|------|---------|---------|---------|
| A 类（初级） | 年满 18 周岁的中国公民 | 144 MHz、430 MHz | 25W |
| B 类（中级） | 持有 A 类证满一定期限 | HF + VHF/UHF | 100W |
| C 类（高级） | 持有 B 类证满一定期限 | 全部业余频段 | 1000W |

> **提示**：未满 18 周岁的未成年人可在监护人指导下参加考试和操作，具体政策以当地无线电管理机构规定为准。

### 考试内容

**A 类考试**主要涵盖：

- 无线电管理相关法律法规
- 业余无线电基础知识
- 无线电安全和操作规范
- 基本的电磁兼容知识

**B 类考试**在 A 类基础上增加：

- 更深入的电子学和电路知识
- HF 传播理论
- 天线原理
- 更多的操作规范和礼仪

考试形式通常为**机考**，题目从公开的题库中随机抽取。

### 备考建议

1. **获取题库**：中国无线电协会（CRSA）网站上有公开的题库下载
2. **使用备考 APP**：多款手机应用提供模拟考试功能，如 "业余无线电考试" 等
3. **加入学习群组**：通过本地 HAM 社区找到备考群组，和其他考生一起学习
4. **理解而非死记**：虽然题库是固定的，但理解原理比死记硬背更有价值——这些知识在未来操作中会真正用到
5. **预计备考时间**：A 类考试认真备考通常 1-2 周即可通过

### 报名流程

1. 关注当地无线电管理机构或无线电协会的考试通知
2. 按要求提交报名材料（身份证、照片等）
3. 在指定时间和地点参加考试
4. 考试通过后领取操作证书

### 设台申请

拿到操作证后，还需要向当地无线电管理机构申请设置业余无线电台，获得电台执照和呼号，才能合法发射。

流程概要：

1. 准备设台申请材料（操作证、设备技术资料等）
2. 提交申请（部分地区支持网上办理）
3. 审批通过后获得**电台执照**和**呼号**
4. 持照合法操作

## 第二步：购买第一台电台

### A 类入门推荐设备

作为 A 类操作员，你只能使用 VHF（144 MHz）和 UHF（430 MHz）频段。以下是常见的入门设备类型：

#### 手持电台（手台）

手台是最经济、最便携的入门选择。

**选购要点**：

- **功率**：通常 5-8W，足够通过本地中继
- **双频段**：选择支持 144/430 MHz 双频段的手台
- **品牌建议**：
  - **八重洲（Yaesu）**：如 FT-65、FT-60，经典可靠
  - **建伍（Kenwood）**：如 TH-D75，功能丰富
  - **艾可慕（ICOM）**：如 IC-T10，品质优秀
  - **国产品牌**：泉盛、宝锋等，价格实惠，适合预算有限的入门者
- **预算参考**：国产手台几十到几百元，日系品牌手台通常 500-2000 元

> **重要提醒**：请确保购买的手台覆盖业余频段（144/430 MHz），而非仅覆盖商业频段。同时要确认设备符合无线电管理要求。

#### 车载电台（车台）

如果你有车，车台是很好的选择。

- **功率**：通常 25-75W，通信距离明显优于手台
- **天线**：配合车载天线效果显著提升
- **品牌推荐**：八重洲 FTM-300DR、艾可慕 IC-2730 等
- **预算参考**：1000-3000 元

### 天线的重要性

**天线比功率更重要**。一根好天线的效果远远超过增加发射功率。

- **手台**：原装橡皮天线效率较低，建议购买加长天线或信号棒
- **家用**：在窗台或阳台架设一根简单的双频段天线（如钻石 X-50、X-300 等），配合馈线连接到电台
- **车载**：车顶磁吸天线或钻孔安装天线

### 其他配件

- **馈线**：连接电台和天线的同轴电缆（推荐 RG-58 或更好的 RG-213、LMR-400）
- **电源**：车台/基地台需要 13.8V 直流电源
- **SWR 表**：检测天线匹配状况
- **耳机/话筒**：提高操作舒适度

## 第三步：加入当地中继

### 什么是中继站（Repeater）

中继站是安装在高处（山顶、高楼顶）的自动转发设备。它接收来自一个频率的信号，经放大后在另一个频率上重新发射。由于中继站位置高、天线好、功率大，大大扩展了手台和车台的通信范围。

### 中继站的基本参数

使用中继站需要设置以下参数：

- **下行频率**：你接收中继信号的频率（也是你在电台上设置的接收频率）
- **上行频率**：你发射到中继的频率（设置频偏后自动计算）
- **频偏（Offset）**：上行和下行频率之差
  - 2 米波段通常为 ±600 kHz
  - 70 厘米波段通常为 ±5 MHz
- **亚音（CTCSS/DCS）**：一种低频编码信号，用于防止中继被无关信号触发
  - CTCSS：连续的低频音调（如 88.5 Hz、100.0 Hz 等）
  - DCS：数字编码静噪

### 如何找到本地中继

1. **询问当地 HAM**：最直接的方式
2. **网络查询**：各地业余无线电协会或爱好者论坛通常有中继列表
3. **扫描频率**：在中继常用频率范围内扫描，听到有信号的频率再确认参数
4. **手机 APP**：一些应用收录了全国中继信息

### 设置示例

假设你所在城市有一个中继站，参数为：

- 下行频率：439.750 MHz
- 频偏：-5 MHz（即上行频率为 434.750 MHz）
- CTCSS：88.5 Hz

在电台上的设置步骤：

1. 将频率调至 439.750 MHz
2. 设置频偏方向为负（-），偏移量为 5 MHz
3. 设置发射亚音为 88.5 Hz
4. 保存为信道

## 第四步：第一次通联

### 通联前的准备

1. **确认设备工作正常**：电池充足（或电源连接好）、天线连接牢固
2. **监听**：在发射之前，先监听一段时间。了解中继上谁在通话、通话的方式和礼仪
3. **准备好你的呼号**：你会频繁用到它

### 通联的基本流程

#### 呼叫 CQ（通用呼叫）

如果中继上没有人在通话，你可以发起呼叫：

```text
CQ CQ CQ，这里是 BG5XXX（你的呼号），
BG5XXX 呼叫 CQ，请回答。
```

#### 回应 CQ

如果你听到有人呼叫 CQ：

```text
BG5XXX（对方呼号），这里是 BH7YYY（你的呼号），你好，请回答。
```

#### 通联内容

建立联系后，通联通常包括以下内容交换：

1. **信号报告**：告诉对方你收到他信号的质量
   - 在 FM 中通常用描述性语言："信号很好"、"信号满格"、"有点弱"
   - 也可以用 RS 报告（Readability 1-5，Signal 1-9）
2. **基本信息**：你的名字、QTH（所在位置）、使用的设备和天线
3. **自由交谈**：兴趣爱好、天气、技术话题等
4. **结束通联**：

```text
好的，73（Best Regards），BG5XXX（对方呼号），这里是 BH7YYY，通联结束。
```

### 通联礼仪

- **先听后发**：发射前确认频率上没有其他人在通话
- **报呼号**：每次通联开始和结束时报出自己的呼号
- **简洁明了**：尤其在中继上，不要长时间独占频率
- **礼貌用语**：73（Best Regards）是 HAM 之间的通用祝福语
- **不谈政治和商业**：业余无线电不得用于政治宣传或商业目的
- **松开 PTT 再听**：说完一段话后松开发射键，留出间隙让对方或其他人插入
- **紧急通信优先**：如果有人发出紧急呼叫，立即停止非紧急通联并让出频率

## 常用 Q 码和缩语

Q 码是一套国际通用的三字母缩写代码，最初用于 CW（摩尔斯电码）通信，现在也广泛用于语音通联中。

### 最常用 Q 码

| Q 码 | 含义（作为问题） | 含义（作为回答/陈述） |
|------|----------------|-------------------|
| **QTH** | 你的位置在哪里？ | 我的位置是…… |
| **QSL** | 你能确认收到吗？ | 我确认收到 |
| **QRZ** | 谁在呼叫我？ | 你被……呼叫 |
| **QSY** | 我要改变发射频率吗？ | 请改变到……频率 |
| **QRM** | 你受到人为干扰吗？ | 我受到人为干扰 |
| **QRN** | 你受到天电干扰吗？ | 我受到天电干扰（自然噪声） |
| **QRP** | 我要减小功率吗？ | 请减小功率 / 小功率操作 |
| **QRO** | 我要增大功率吗？ | 请增大功率 |
| **QSO** | 你能直接与……通信吗？ | 一次完整的通联 |
| **QRV** | 你准备好了吗？ | 我准备好了 |
| **QRT** | 我要停止发射吗？ | 我停止发射（关机） |
| **QSB** | 我的信号有衰落吗？ | 你的信号有衰落 |
| **QTR** | 现在几点了？ | 现在是……（UTC 时间） |

### 常用数字和缩语

| 缩语 | 含义 |
|------|------|
| **73** | Best Regards，良好祝愿（最常用的告别语） |
| **88** | Love and Kisses，亲吻（用于 YL/XYL） |
| **CQ** | 通用呼叫，寻找任何愿意通联的电台 |
| **DX** | 远距离通联 |
| **OM** | Old Man，对男性 HAM 的称呼 |
| **YL** | Young Lady，对女性 HAM 的称呼 |
| **XYL** | Ex-Young Lady，HAM 的妻子 |
| **FB** | Fine Business，很好 |
| **HI** | 笑声（相当于 "哈哈"） |
| **rig** | 电台设备 |
| **shack** | 电台操作间 |
| **de** | 来自（如 "de BG5XXX" 表示 "来自 BG5XXX"） |
| **Roger** | 收到，明白 |
| **QSL card** | 通联确认卡片 |

### 信号报告系统

#### RST 报告（用于 CW 和 SSB）

- **R（Readability，可辨度）**：1-5
  - R5 = 完全可辨
  - R4 = 基本可辨
  - R3 = 有困难
  - R2 = 几乎不可辨
  - R1 = 不可辨
- **S（Signal Strength，信号强度）**：1-9
  - S9 = 极强信号
  - S5 = 中等信号
  - S1 = 几乎不可闻
- **T（Tone，音调，仅用于 CW）**：1-9
  - T9 = 纯净的正弦波音调

示例："你的信号报告是 59"（可辨度 5，信号强度 9 = 非常好的信号）

## 下一步做什么？

完成第一次通联后，你已经正式成为一名 HAM 了！以下是一些建议的进阶方向：

### 短期目标

- 熟悉本地中继，结识更多 HAM 朋友
- 学习编程电台的各种功能
- 参加本地业余无线电活动和聚会
- 开始记录你的通联日志（Logbook）

### 中期目标

- 备考 B 类操作证，获得 HF 操作资格
- 学习架设更好的天线
- 尝试 APRS、数字语音（DMR/D-STAR/C4FM）等新技术
- 参加 SOTA（山峰通联）或 POTA（公园通联）等便携活动

### 长期目标

- 探索 HF 短波通信，体验全球通联的乐趣
- 学习 CW（摩尔斯电码）
- 参加国际竞赛（Contest）
- 尝试卫星通信
- 自制（DIY）天线甚至收发信机
- 考取 C 类操作证，探索微波频段
