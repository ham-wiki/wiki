# 中国 CRAC 考试指南

## 概述

在中国大陆，业余无线电的管理依据是《中华人民共和国无线电管理条例》和工信部发布的《业余无线电台管理办法》（工信部 \[2012\] 43号令）。业余无线电操作者必须取得**业余无线电台操作技术能力验证**（俗称"操作证书"）后，方可申请设置业余无线电台并获得呼号。

考试由**中国无线电协会（CRAC）**组织实施。

- CRAC 官网：[https://www.crac.org.cn](https://www.crac.org.cn)
- 考试报名系统：[https://www.crac.org.cn（在线考试平台入口）](https://www.crac.org.cn)

## A/B/C 类操作证书区别

中国的业余无线电操作证书分为 A、B、C 三类，权限逐级递增：

### A 类（入门级）

- **适合人群**：零基础入门者
- **允许频率**：仅限 VHF/UHF 部分频段（如 144-146 MHz、430-440 MHz）
- **最大发射功率**：25W
- **可用模式**：FM 调频为主
- **典型应用**：使用手持对讲机（手台）进行本地通联、通过中继台通信
- **考试难度**：较低，题库约 374 题，考试随机抽取 30 题，答对 25 题即通过

### B 类（中级）

- **适合人群**：希望使用 HF 短波频段的爱好者
- **允许频率**：在 A 类基础上增加 HF 短波频段（如 7 MHz、14 MHz、21 MHz、28 MHz 等）
- **最大发射功率**：100W
- **可用模式**：FM、SSB、CW、数字模式等
- **典型应用**：短波远程通联（DX）、参加竞赛（Contest）、数字模式通信（FT8 等）
- **考试难度**：中等，题库约 687 题（含 A 类题目），考试随机抽取 50 题，答对 40 题即通过
- **前置条件**：须持有 A 类证书满 6 个月方可报考（以实际政策为准）

### C 类（高级）

- **适合人群**：高级爱好者、技术研究者
- **允许频率**：所有业余频段
- **最大发射功率**：1000W
- **可用模式**：所有合法模式
- **典型应用**：卫星通信、EME（月面反射通信）、微波实验等
- **考试难度**：较高，涉及较深的电子学和电磁理论知识
- **前置条件**：须持有 B 类证书

### 对比表

| 项目 | A 类 | B 类 | C 类 |
| --- | --- | --- | --- |
| 允许频段 | VHF/UHF 部分 | HF + VHF/UHF | 全部业余频段 |
| 最大功率 | 25W | 100W | 1000W |
| 题库总量 | ~374 题 | ~687 题 | 待定 |
| 考试题数 | 30 题 | 50 题 | 待定 |
| 通过分数线 | 25/30 | 40/50 | 待定 |
| 前置条件 | 无 | 持有 A 类 | 持有 B 类 |

::: warning 注意
C 类考试实施时间和具体方案请关注 CRAC 官网最新公告，政策可能有所调整。
:::

## 考试内容

### A 类考试知识点

1. **无线电管理法规**：无线电管理条例相关内容、业余电台管理办法、频率使用规定
2. **基础电学知识**：欧姆定律、功率计算、电阻/电容/电感基础
3. **无线电通信常识**：频率与波长的关系、调制方式（AM/FM/SSB）、天线基础
4. **操作规范**：呼叫程序、Q 简语、通联礼仪、紧急通信规定
5. **安全知识**：射频安全、电气安全、雷电防护

### B 类考试增加内容

1. **更深入的电路理论**：滤波器、振荡器、混频器原理
2. **HF 传播知识**：电离层传播、太阳活动对传播的影响、传播预测
3. **天线理论**：各类天线（偶极子、八木、垂直天线）的特性与架设
4. **发射机与接收机原理**：超外差接收机结构、自动增益控制、频率稳定度
5. **电磁兼容**：干扰的产生与抑制、滤波技术

## 报名流程

### 第一步：注册账号

1. 访问 CRAC 官网 [https://www.crac.org.cn](https://www.crac.org.cn)
2. 进入"业余无线电台操作技术能力验证"板块
3. 注册个人账号，填写真实姓名、身份证号、联系方式等信息
4. 上传证件照片（白底免冠证件照）

### 第二步：选择考试场次

1. 登录后查看可用的考试场次（通常各省市无线电协会定期组织）
2. 选择你所在地区的考试时间和地点
3. 部分地区支持线上机考，具体以公告为准
4. 缴纳考试费用（通常为几十元人民币）

### 第三步：参加考试

1. 携带身份证原件按时到达考场
2. 考试形式为闭卷机考（电脑答题），题型全部为单选题
3. 考试时间：A 类约 30 分钟，B 类约 50 分钟
4. 当场出成绩

### 第四步：获取证书

1. 考试通过后，CRAC 会在其系统中记录你的合格信息
2. 可在 CRAC 官网下载电子版操作能力证书
3. 该证书是后续申请设台和呼号的前置条件

## 设台审批流程

取得操作证书后，还需向当地无线电管理机构申请**设置业余无线电台**。

### 申请条件

- 持有相应类别的 CRAC 操作证书
- 年满 18 周岁（未满 18 周岁需监护人同意，且仅能申请 A 类电台）
- 具有固定的设台地址

### 申请材料

1. 业余无线电台设置申请表
2. 操作技术能力证书（CRAC 证书编号）
3. 身份证复印件
4. 设备的型号核准信息（设备须取得国家无线电发射设备型号核准）

### 审批流程

1. 向设台地所在地的省（区、市）无线电管理机构提交申请
2. 管理机构审核材料（通常 20 个工作日内）
3. 审核通过后，颁发**业余无线电台执照**

::: tip 提示
许多省份已开通网上办理，可通过当地无线电管理机构的官网或政务服务平台在线提交申请。
:::

## 呼号申请

### 呼号的结构

中国大陆业余无线电呼号格式为 **BV/BY + 数字 + 字母**，常见格式如：

- **个人呼号**：如 `BV2ABC`、`BY1XYZ`
- 前缀 B 后的字母代表不同类别（如 BV、BG、BH、BI 等分别对应不同级别和用途）
- 数字代表所在无线电管理区域（0-9 对应不同省份区域）

常见个人呼号前缀：
- **BA**：A 类个人电台
- **BD**：A 类个人电台（早期分配段）
- **BG**：B 类个人电台
- **BH**：B 类个人电台
- **BV**：C 类个人电台
- **BY**：集体电台/特殊电台

::: info 说明
呼号前缀分配规则可能随政策调整而变化，以实际核发为准。不同时期获得的呼号前缀可能不同。
:::

### 呼号申请流程

1. 在设台审批通过后，管理机构会为你指配呼号
2. 呼号由管理机构按照分配规则指定，个人一般无法自选
3. 呼号与电台执照绑定，执照有效期通常为 5 年
4. 执照到期前需办理续期手续，否则呼号可能被收回

### 呼号使用规范

- 每次通联开始和结束时必须报出自己的呼号
- 长时间通联中，至少每 10 分钟报出一次呼号
- 不得使用他人呼号或虚假呼号
- 不得在未取得执照的情况下发射

## 常见问题

### Q：我可以先买设备再考证吗？

**A**：可以购买和拥有业余无线电设备，但在取得操作证书和电台执照之前，不得进行发射操作。建议先考证。

### Q：A 类证书能用 HF 短波设备吗？

**A**：A 类证书只允许在 VHF/UHF 指定频段操作，不能使用 HF 短波频段。如需使用短波，必须考取 B 类证书。

### Q：考试难吗？需要多长时间准备？

**A**：A 类考试难度不高，认真学习题库一到两周通常即可通过。B 类考试需要更多的理论基础，建议准备一到两个月。详细备考建议请参考 [备考攻略](./1_2_exam_tips.md)。

### Q：外籍人士可以在中国考试吗？

**A**：可以。外籍人士持有效护照即可报名参加 CRAC 考试，通过后同样可以申请设台和呼号。

### Q：操作证书有有效期吗？

**A**：操作证书（能力验证）本身长期有效，但业余电台执照有有效期（通常 5 年），需要按时续期。
