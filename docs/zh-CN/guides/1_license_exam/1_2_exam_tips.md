# 备考攻略

## 题库来源

CRAC 考试的核心特点是**从公开题库中随机抽题**，这意味着只要把题库吃透，通过考试的概率极高。

### 官方题库

- **CRAC 官网题库**：中国无线电协会官网发布的最新版本题库是唯一的官方来源。考试题目全部从该题库中抽取。
  - 网址：[https://www.crac.org.cn](https://www.crac.org.cn)
  - A 类题库约 374 题，B 类题库约 687 题（包含 A 类全部题目）
- 题库会不定期更新，备考前务必确认自己使用的是最新版本

### 题库获取方式

1. **CRAC 官网下载**：通常提供 PDF 或 Excel 格式的题库文件
2. **备考 App**：多款 App 内置了最新题库（见下文推荐）
3. **社区整理版本**：各 HAM 论坛和 QQ 群中经常有热心火腿整理的带解析版题库

::: warning 注意
务必使用最新版题库。旧版题库可能包含已删除或修改的题目，影响备考效果。
:::

## 学习方法

### A 类备考策略（建议 1-2 周）

A 类考试面向入门者，难度较低。推荐以下学习路径：

1. **第一遍：通读题库**（2-3 天）
   - 不急于记忆答案，先将所有题目浏览一遍
   - 重点理解每道题考查的知识点
   - 对完全不理解的题目做标记

2. **第二遍：分类刷题**（3-4 天）
   - 按知识模块分类练习：法规类、电学基础类、通信常识类、操作规范类、安全类
   - 理解原理而非死记硬背，这样即使题目表述略有变化也不怕

3. **第三遍：错题强化**（2-3 天）
   - 集中攻克标记的难题和错题
   - 利用 App 的错题本功能反复练习

4. **模拟考试**（1-2 天）
   - 用 App 或网站进行模拟考试
   - 目标：连续三次模拟考试都能达到 28 分以上（满分 30）

### B 类备考策略（建议 1-2 个月）

B 类考试增加了大量电路理论和传播知识，需要更系统的学习：

1. **夯实基础**（第 1-2 周）
   - 复习基本电学知识：欧姆定律、功率公式、分贝（dB）计算
   - 学习电子元器件基础：电阻、电容、电感的特性与应用
   - 推荐配合教材系统学习

2. **专题突破**（第 3-4 周）
   - 电路理论：滤波器类型与特性、谐振电路
   - 天线与传播：天线增益、方向性、电离层传播原理
   - 收发信机原理：超外差结构、各功能模块

3. **题库精练**（第 5-6 周）
   - 系统刷完全部 B 类题库
   - 建立错题本，定期回顾

4. **冲刺阶段**（第 7-8 周）
   - 反复模拟考试
   - 目标：连续模拟考试达到 45 分以上（满分 50）

## 重点知识梳理

### 必考法规知识

以下法规知识点几乎每次考试都会涉及，务必牢记：

- **业余业务的定义**：以自我训练、相互通信和技术研究为目的，不以营利为目的
- **禁止行为**：不得发送与业余业务无关的信号、不得进行商业通信、不得发送广播节目、不得使用非法呼号
- **紧急通信**：在紧急情况下可以使用任何频率和方式进行求救通信
- **频率使用**：不同类别操作者只能在授权频段内操作
- **干扰处理**：业余业务不得对其他业务产生有害干扰，遇到干扰时应主动避让

### 必考电学基础

- **欧姆定律**：`U = I × R`（电压 = 电流 × 电阻）
- **功率计算**：`P = U × I = I² × R = U² / R`
- **分贝计算**：`dB = 10 × log(P2/P1)`，功率增加一倍约为 +3dB，增加十倍为 +10dB
- **频率与波长**：`λ = c / f`（波长 = 光速 / 频率），300MHz 对应 1 米波长
- **串并联电阻**：串联相加，并联用倒数公式

### 必考通信知识

- **Q 简语**：QTH（位置）、QSL（确认收到）、QRZ（谁在呼叫我）、QSY（改变频率）、QRM（人为干扰）、QRN（天电干扰）等
- **字母解释法（NATO音标）**：Alpha, Bravo, Charlie... 用于在语音通信中准确拼读字母
- **信号报告 RST**：R（可辨度 1-5）、S（信号强度 1-9）、T（音调 1-9，仅用于 CW）
- **通联基本流程**：CQ呼叫 → 对方回应 → 交换信号报告和基本信息 → 互致73（再见）

## 常见易错题解析

### 易错点一：分贝（dB）计算

**典型题目**：一个功率放大器将信号功率从 5W 放大到 50W，增益是多少 dB？

**正确答案**：10dB

**解析**：`10 × log(50/5) = 10 × log(10) = 10 × 1 = 10dB`

**易错原因**：容易将功率 dB 和电压 dB 公式混淆。功率用 `10log`，电压用 `20log`。

### 易错点二：波长与频率换算

**典型题目**：业余无线电中"2米波段"对应的频率范围大约是？

**正确答案**：144-148 MHz

**解析**：`f = 300 / λ = 300 / 2 = 150 MHz`（近似值），所以 2 米波段大约在 144-148 MHz 范围。

**易错原因**：容易把"2米"误认为 200MHz 或其他数值。记住公式 `f(MHz) = 300 / λ(m)`。

### 易错点三：天线馈电阻抗

**典型题目**：半波偶极子天线在谐振时的馈电阻抗约为？

**正确答案**：约 73 欧姆

**易错原因**：容易与 50 欧姆（常用馈线特性阻抗）混淆。半波偶极子天线谐振阻抗约 73Ω，而 50Ω 是同轴电缆的标准阻抗。

### 易错点四：法规中的数字

需要特别记忆的法规数字：

- 业余电台执照有效期：**5 年**
- A 类最大发射功率：**25W**
- B 类最大发射功率：**100W**
- 操作中报出呼号的最长间隔：**10 分钟**
- 设台申请审批时限：**20 个工作日**

### 易错点五：紧急通信规则

**典型题目**：在紧急情况下，业余电台可以怎样操作？

**正确答案**：可以使用任何频率和方式进行紧急求救通信

**易错原因**：平时操作有严格的频率和功率限制，但紧急情况（生命财产安全受到威胁）时例外。注意"紧急"的定义——仅限于危及生命安全的真正紧急情况，不包括一般的通信需求。

## 考前检查清单

考试当天，请确认以下事项：

- [ ] 携带有效身份证原件
- [ ] 确认考试时间和地点
- [ ] 提前到达考场（建议提前 30 分钟）
- [ ] 手机调至静音或关机
- [ ] 保持平常心，题库已刷熟就不必紧张

::: tip 最后的建议
A 类考试的关键是**把题库刷三遍以上**。B 类考试除了刷题，还需要**理解原理**。不要死记硬背答案序号（A/B/C/D），因为考试时选项顺序可能会变化，要理解每个选项的含义。
:::
