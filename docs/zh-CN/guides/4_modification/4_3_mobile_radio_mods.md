# 车载台改装

车载台（移动电台）相比手持台拥有更大的发射功率和更好的接收灵敏度，是车载通信和基站搭建的常用设备。本文介绍车载台的常见改装方法，包括扩频、跳线设置和编程软件使用。

::: danger 法律警告
车载台的发射功率通常远高于手持台（25W - 75W），非法使用造成的干扰范围更大，法律后果也更严重。请务必在取得合法执照后，仅在许可频段内使用。
:::

## 车载台扩频方法

### 软件扩频

大多数车载台可以通过编程软件修改频率范围。

#### 通用步骤

1. **获取编程线**：车载台通常使用专用编程线，接口可能是 RJ45、RJ11、USB 或专用接头。购买时注意选择与电台型号匹配的编程线。
2. **安装驱动和软件**：安装编程线驱动和对应的编程软件（官方软件或 CHIRP）。
3. **读取电台数据**：连接编程线，从电台读取当前配置。
4. **修改频率范围**：在软件中找到频率范围限制的设置，扩展到需要的范围。
5. **写入电台**：将修改后的配置写回电台。

#### TYT TH-9800 扩频示例

TH-9800 是一款常见的四频段车载台，扩频相对简单：

1. 使用 USB 编程线连接电台和电脑。
2. 打开 TH-9800 官方写频软件或 CHIRP。
3. 读取电台数据。
4. 在 CHIRP 中，进入 `Settings` → `Other Settings`。
5. 修改各频段的频率范围上下限。
6. 写入电台，重启生效。

### 硬件跳线扩频

部分车载台通过主板上的跳线（Jumper）或贴片电阻来设定频率范围版本。改变跳线状态可以切换频率范围。

::: warning 注意
硬件跳线改装需要拆开电台外壳，可能导致保修失效。操作前请仔细阅读相关资料，确认跳线位置和对应关系。
:::

#### 跳线改装通用步骤

1. **查阅资料**：在网上搜索你的电台型号 + "modification" 或 "MARS/CAP mod"，找到跳线图。
2. **拆开外壳**：断开电源和天线，拆下外壳螺丝，小心取下外壳。
3. **定位跳线**：根据资料找到主板上的跳线位置，通常是标记为 J1、J2 等的焊盘或贴片电阻。
4. **修改跳线**：
   - 如果是焊盘跳线：使用烙铁在焊盘之间搭焊（闭合）或去除焊锡（断开）。
   - 如果是贴片电阻：使用烙铁移除或移动对应的贴片电阻。
5. **复原外壳**：装回外壳，连接电源和天线。
6. **复位电台**：部分电台在跳线修改后需要进行恢复出厂设置才能生效。

#### 八重洲 FT-8900R 跳线示例

FT-8900R 的扩频跳线位于主板正面：

1. 拆开电台上盖（4 颗螺丝）。
2. 找到主板上标记为 "JP1001" 附近的跳线区域。
3. 根据需要的频率版本，使用烙铁桥接或断开相应焊盘。
4. 装回外壳后进行恢复出厂设置：按住特定按键组合开机（参考说明书）。

#### 建伍 TM-V71A 跳线示例

TM-V71A 的扩频非常简单：

1. 拆开电台上盖。
2. 找到标记为 "RM11" 的贴片电阻（0 欧姆电阻）。
3. 使用烙铁移除该电阻。
4. 装回外壳。
5. 按住 `TM-V71A` 的 `CALL` 键同时开机，执行全复位。

### 编程要点

无论使用什么软件，编程车载台时应注意以下要点：

1. **正确选择串口**：在设备管理器中确认编程线占用的 COM 口号。
2. **匹配通信速率**：部分电台要求特定的波特率（常见 9600 或 4800）。
3. **先读后写**：始终先从电台读取数据，修改后再写入，避免丢失原有配置。
4. **设置亚音频**：中继台接入通常需要设置 CTCSS（模拟亚音）或 DCS（数字亚音）。
5. **设置偏移**：使用中继台时需要设置正确的频率偏移（Offset）方向和大小。

## 车载台安装注意事项

改装和编程完成后，车载台的安装同样重要：

### 电源接线

- **直连电瓶**：车载台应使用随机附带的电源线直接连接到汽车电瓶，不要接点烟器。
- **加装保险丝**：确认电源线上的保险丝完好，正负极不要接反。
- **线径足够**：50W 电台工作电流可达 10A 以上，电源线线径应不小于随机附带线材的规格。

### 天线安装

- **接地良好**：车载天线需要良好的接地面（车顶金属面），磁吸天线底座比夹边天线效果更好。
- **馈线质量**：使用低损耗同轴电缆（如 RG-58 或更好的 RG-213）。
- **驻波调试**：安装天线后使用驻波表调试，确保驻波比低于 1.5:1。

### 散热

- **通风良好**：车载台安装位置应保证良好的空气流通。
- **避免阳光直射**：夏季车内温度极高，避免将电台安装在阳光直射的位置。

## 常见问题

### 编程线无法识别

- 确认驱动已安装。车载台编程线常见芯片：FTDI FT232、CP2102、CH340、PL2303。
- PL2303 老版芯片在 Windows 10/11 上可能不兼容，需安装特定版本驱动。

### 扩频后部分频率无法发射

- 这是正常现象。硬件的发射带宽有限，超出硬件能力范围的频率即使设置了也无法有效发射。
- 发射功率在频率范围边缘通常会明显下降。

### 跳线修改后电台不开机

- 检查是否有焊锡桥接到相邻焊盘导致短路。
- 使用放大镜仔细检查焊接质量。
- 恢复原始跳线状态，确认电台可以正常工作后再重新操作。
