# 改装教程

本章节介绍业余无线电设备的常见改装方法，包括固件刷写、扩频、功率调整、天线更换以及编程软件的使用。

## 重要声明

::: danger 法律警告
在中国大陆，使用无线电发射设备必须遵守《中华人民共和国无线电管理条例》。请务必注意以下事项：

1. **必须持有合法执照**：操作业余无线电台需要取得中国无线电协会（CRAC）颁发的业余无线电台操作证书，并向当地无线电管理机构申请设台执照。
2. **遵守频率规定**：仅可在业余无线电业务分配的频段内发射，严禁占用公共安全、航空、军事等频率。
3. **功率限制**：不同等级操作证书对应不同的发射功率上限，A 类不超过 25W，B 类不超过 100W，C 类按照核定功率执行。
4. **禁止干扰**：任何改装不得对其他合法无线电业务造成有害干扰。
5. **设备核准**：经过改装的设备可能不再符合型号核准要求，在正式发射前请确认合规性。
:::

::: warning 安全注意事项

- 改装过程中可能涉及焊接、拆机等操作，请注意人身安全。
- 刷写固件存在变砖风险，请提前备份原始固件。
- 功率提升可能导致设备过热甚至损坏，请充分了解设备额定参数。
- 如不确定操作后果，建议先在报废设备上练习。
:::

## 改装前的准备

在开始任何改装之前，建议你做好以下准备工作：

1. **了解你的设备**：阅读设备说明书，了解原始参数和功能。
2. **备份当前配置**：使用编程线和软件备份电台中的频率、设置等数据。
3. **准备工具**：常用工具包括编程线（USB-C 或 K 头）、十字螺丝刀、防静电手环、烙铁（如需硬件改装）。
4. **查阅资料**：在动手前充分阅读相关教程和社区讨论，确认改装方案的可行性。
5. **评估风险**：明确改装可能带来的后果（保修失效、设备损坏等），做好心理准备。
