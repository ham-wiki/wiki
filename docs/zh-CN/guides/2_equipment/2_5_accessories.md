# 配件与周边

业余无线电不仅仅是一台电台——馈线、接头、仪表、电源等配件同样重要。好的配件能让你的电台系统发挥最佳性能，而劣质或不匹配的配件则可能导致信号损失甚至设备损坏。

## 馈线（同轴电缆）

馈线是连接电台和天线之间的传输线，其质量直接影响发射效率和接收灵敏度。

### 同轴电缆基础知识

同轴电缆由内导体、绝缘层、外导体（屏蔽层）和外护套四层结构组成。其核心参数包括：

- **特性阻抗**：业余无线电标准为 50 欧姆（广播电视为 75 欧姆，注意区分）。
- **损耗（衰减）**：信号通过馈线时的能量损失，以 dB/100m 表示。频率越高、线径越细，损耗越大。
- **功率容量**：馈线能承受的最大射频功率。
- **屏蔽效果**：抵抗外部干扰的能力。

### 常见同轴电缆型号

| 型号 | 外径 | 阻抗 | 损耗 (144MHz) | 损耗 (430MHz) | 功率容量 | 适用场景 |
|------|------|------|---------------|---------------|----------|----------|
| **RG-58** | 5mm | 50Ω | ~5.3 dB/100m | ~9.3 dB/100m | 300W | 短距离 VHF/UHF，手持台延长线 |
| **RG-213（8D-FB）** | 10mm | 50Ω | ~2.7 dB/100m | ~5.0 dB/100m | 700W | 中等距离馈线，HF 主馈线 |
| **5D-FB** | 7.5mm | 50Ω | ~3.2 dB/100m | ~5.8 dB/100m | 500W | 车载台和短距离固定台 |
| **10D-FB** | 13mm | 50Ω | ~1.6 dB/100m | ~2.9 dB/100m | 1kW | 长距离固定台主馈线 |
| **LMR-400** | 10mm | 50Ω | ~2.0 dB/100m | ~3.7 dB/100m | 800W | 优质馈线，性能/柔软度平衡好 |
| **Ecoflex 15** | 14.6mm | 50Ω | ~1.0 dB/100m | ~1.8 dB/100m | 2kW+ | 超低损耗，长距离/UHF 高要求场景 |

### 选购建议

- **HF 短波**（30MHz 以下）：馈线损耗影响相对较小，RG-213 或 8D-FB 即可满足大多数需求。
- **VHF/UHF**（144/430MHz）：频率越高损耗越大，馈线尽量选粗的低损耗型号。如果馈线超过 10 米，建议至少使用 8D-FB 或 LMR-400。
- **短距离连接**（< 3米）：RG-58 或 5D-FB 足够。
- **不要贪便宜**：劣质馈线的实际损耗可能远大于标称值，屏蔽效果也差。购买时选择知名品牌（如 Andrew/CommScope、Messi & Paoloni、日本藤仓等）。

### 馈线损耗计算

损耗是累积的。例如，一根 20 米长的 RG-58 在 430MHz 的损耗约为：

```
9.3 dB/100m × 20m = 1.86 dB
```

1.86 dB 意味着约 35% 的功率在馈线中变成了热量。如果你发射 50W，到达天线的只有约 32.5W。

如果换成 LMR-400：
```
3.7 dB/100m × 20m = 0.74 dB
```

损耗只有约 15%，50W 中约 42.5W 到达天线。差距显而易见。

## 射频接头（连接器）

射频接头用于连接馈线与设备、天线、仪表等。不同设备使用不同类型的接头，了解常见接头类型是基本功。

### 常见接头类型

#### SMA（SubMiniature version A）

- **阻抗**：50Ω
- **频率范围**：DC - 18GHz
- **尺寸**：小型
- **用途**：手持台天线接口、SDR 设备、小型仪器
- **注意**：SMA 分为公头（中心针）和母头（中心孔）。不同品牌手持台的机身接口可能是 SMA-Male 或 SMA-Female，购买天线时务必确认。
  - **宝锋/泉盛**：机身为 SMA-Male（公头），天线需要 SMA-Female（母头）
  - **八重洲/ICOM/建伍**：机身为 SMA-Female（母头），天线需要 SMA-Male（公头）
- **反极性 SMA（RP-SMA）**：Wi-Fi 设备常用，中心针和孔反过来，与标准 SMA 不兼容

#### BNC（Bayonet Neill-Concelman）

- **阻抗**：50Ω
- **频率范围**：DC - 4GHz
- **尺寸**：中型
- **用途**：测试仪器、部分老式手持台、实验室设备
- **特点**：卡口式快速连接/断开，比螺纹接头操作更方便。在需要频繁插拔的场合（如测试）非常实用。

#### N 型（N-Type）

- **阻抗**：50Ω
- **频率范围**：DC - 11GHz
- **尺寸**：中大型
- **用途**：基站天线、固定台馈线系统、UHF/微波设备
- **特点**：防水性好（螺纹连接+密封垫），插入损耗低，功率容量大。是 VHF/UHF 固定天线系统的理想选择。

#### PL-259 / SO-239（UHF 连接器）

- **阻抗**：非恒定阻抗（名义 50Ω）
- **频率范围**：DC - 300MHz（更高频率性能下降）
- **尺寸**：大型
- **用途**：短波电台、车载台、HF 天线
- **特点**：PL-259 是公头（插头），SO-239 是母头（插座）。这是业余无线电中最古老、最普遍的接头类型。几乎所有 HF 短波台和大多数 VHF/UHF 车载台都使用 SO-239 作为天线接口。
- **注意**：严格来说，UHF 连接器在 VHF 以上频率的阻抗匹配不够理想，但在业余无线电的功率和频率范围内影响可以接受。

### 接头选型对照

| 设备类型 | 常见接口 | 推荐馈线接头 |
|----------|----------|-------------|
| 手持台 | SMA | SMA |
| 车载台 | SO-239（M型） | PL-259 |
| HF 短波台 | SO-239 | PL-259 |
| VHF/UHF 固定天线 | N 型 | N 型 |
| SDR 接收器 | SMA / BNC | SMA / BNC |
| 测试仪器 | BNC / N 型 | BNC / N 型 |

### 转接头

不同接头之间可以通过转接头（Adapter）互转。常备几个转接头非常实用：

- SMA-Male ↔ BNC-Female
- PL-259 ↔ N-Male
- SMA-Male ↔ SMA-Male（直通）
- BNC-Male ↔ PL-259

注意：每多一个转接头都会引入少量损耗和潜在的接触不良风险，不宜过多串联。

## 测量仪表

### SWR 表（驻波比表）

驻波比（SWR, Standing Wave Ratio）是衡量天线系统阻抗匹配程度的核心指标。

- **SWR = 1.0**：完美匹配，所有功率都传送到天线。
- **SWR = 1.5**：很好，约 4% 的功率被反射。
- **SWR = 2.0**：可以接受，约 11% 的功率被反射。
- **SWR = 3.0**：需要调整天线，约 25% 的功率被反射。
- **SWR > 3.0**：天线系统有问题，可能损坏发射机功放。

**推荐型号**：
- **Diamond SX-27P**：VHF/UHF 通过式功率/SWR 表，约 200-400 元。
- **Daiwa CN-801**：经典的 HF/VHF 交叉指针 SWR/功率表，约 500-1000 元。
- **NanoVNA**：矢量网络分析仪（见下文），可以精确测量 SWR，功能远超传统 SWR 表。

### NanoVNA（矢量网络分析仪）

NanoVNA 是近年来业余无线电领域最革命性的测量工具之一。它是一台小巧的矢量网络分析仪（VNA），可以测量天线和馈线系统的各项射频参数。

- **价格**：约 100-400 元
- **频率范围**：NanoVNA V2（S-A-A-2）可达 3GHz 甚至 6GHz
- **功能**：
  - 测量天线 SWR 和阻抗（Smith 圆图）
  - 测量馈线损耗
  - 测量滤波器频率响应
  - 测量天线谐振频率
  - TDR（时域反射）定位馈线故障点
- **推荐型号**：NanoVNA V2 Plus4 / LiteVNA，约 200-400 元。屏幕尺寸 4 寸以上的版本操作更方便。
- **配套软件**：NanoVNA Saver（开源，全平台），可以在电脑上绘制更详细的图表。

### 功率计

测量电台的实际发射功率。

- **通过式功率计**：串联在馈线中，实时显示正向功率和反射功率。如 Diamond SX-27P。
- **终端式功率计**：接在馈线末端（配合假负载），精度更高。如 Bird 43（经典但昂贵）。

## 假负载（Dummy Load）

假负载是一个纯电阻性的射频终端，将射频能量完全转化为热量而不辐射。在以下场景中需要使用：

- **设备测试和调试**：不产生辐射干扰。
- **功率测量**：配合功率计使用。
- **发射机调试**：调试功放等部件时避免向空中发射信号。

**推荐型号**：
- **Diamond DL-50A**：50W 连续，VHF/UHF，约 100-200 元。
- **MFJ-260C**：300W 间歇，HF/VHF，油冷式，约 200-400 元。
- **自制假负载**：用大功率碳膜电阻并联到 50Ω 也可以 DIY。

## 电源

### 固定台电源

短波台和车载台（用作固定台时）需要外接 13.8V 直流电源。选择电源时注意：

- **电压**：标准 13.8V DC，波纹要小。
- **电流容量**：100W 短波台满功率发射时约需要 22-25A，电源至少选 30A 留有余量。
- **类型**：
  - **线性电源**：输出纯净，射频干扰极低，但体积大、笨重、效率低。经典之选。
  - **开关电源**：体积小、重量轻、效率高，但可能产生射频噪声。选择优质品牌的射频专用开关电源可以减轻此问题。

**推荐型号**：
- **Diamond GZV-4000**：40A 开关电源，低噪声设计，约 600-1000 元。
- **Alinco DM-330MV**：30A 开关电源，性能可靠，约 500-800 元。
- **MeanWell RSP-500-13.5**：工业级开关电源，500W/36A，需自行加装接线端子和外壳，约 300-500 元。性价比极高但需要动手能力。
- **二手线性电源**：如 Astron RS-35M，输出干净但笨重，二手价格合理。

### 便携电源

户外便携操作时的供电方案：

- **锂铁磷酸电池（LiFePO4）**：电压平台 12.8V，接近 13.8V，适合直接给电台供电。Bioenno 等品牌有专门为业余无线电设计的产品。
- **户外移动电源**：大容量移动电源（如 EcoFlow、Jackery 等），12V 输出口可供电台使用，注意确认输出电流是否足够。
- **太阳能板**：配合控制器和电池使用，适合长时间野外操作。

## 其他实用配件

### 天线调谐器（ATU）

在电台内置调谐器能力不足时，外置天线调谐器可以扩展天线的匹配范围。

- **手动调谐器**：如 MFJ-949E，需要手动调节电容和电感。
- **自动调谐器**：如 LDG AT-600ProII、Yaesu FC-50，按下按钮自动匹配。
- **用途**：在使用非谐振天线（如随机长线、G5RV 等）时特别有用。

### 滤波器

- **带通滤波器（BPF）**：抑制工作频段以外的信号，减少互调干扰。竞赛多机操作时必备。
- **低通滤波器（LPF）**：抑制发射信号的谐波，保护其他频段不受干扰。
- **陷波滤波器（Notch）**：消除特定频率的干扰信号。

### 键控器（CW Key / Keyer）

CW（莫尔斯电码）操作的必备工具：

- **手键（Straight Key）**：传统电键，手动控制长短点。
- **自动键（Paddle）**：配合电子键控器，左右拨动产生长点和短点。如 Bencher BY-1。
- **电子键控器**：控制自动键的速度和点划比。大多数现代电台内置此功能。

### 耳机

长时间守听和竞赛操作时，一副好耳机非常重要。降噪耳机可以隔绝环境噪音，让你听到更微弱的信号。

### 接地系统

良好的接地对于降低噪声、保护设备安全非常重要。固定台站应建立可靠的射频接地，使用粗铜带或铜编织线连接到接地棒。
