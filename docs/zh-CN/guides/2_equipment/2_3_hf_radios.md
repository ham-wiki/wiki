# 短波电台

短波通信（HF，High Frequency，1.8MHz - 30MHz）是业余无线电最核心、最迷人的领域。借助电离层的反射，短波信号可以传播到数千乃至上万公里以外，实现真正的全球通联。这种不依赖任何基础设施的远距离通信能力，是业余无线电区别于其他通信方式的根本所在。

## 短波电台入门

### 你需要什么等级的操作证？

在中国大陆，操作短波电台通常需要 **B 类或 C 类** 业余无线电操作证书（A 类仅限 VHF/UHF 以上频段，功率不超过 25W）。B 类允许使用 30MHz 以下频段，最大功率 100W。

### 短波通信的基本模式

| 模式 | 说明 | 特点 |
|------|------|------|
| **SSB（单边带）** | 语音通信的主要模式 | 低频段用 LSB，高频段用 USB，频谱效率高 |
| **CW（等幅报）** | 莫尔斯电码通信 | 带宽极窄，弱信号下表现最好，DX 利器 |
| **FT8 / FT4** | WSJT-X 弱信号数字模式 | 自动化程度高，极弱信号下可完成通联 |
| **RTTY** | 无线电传 | 经典数字模式，竞赛常用 |
| **AM（调幅）** | 传统语音模式 | 带宽大，效率低，主要在部分老式电台和 10m 频段使用 |
| **FM** | 调频 | 短波中仅在 29MHz（10m 频段）使用 |

### 短波频段概览

| 频段 | 频率范围 | 特点 |
|------|----------|------|
| 160m | 1.800-2.000 MHz | "顶频段"，夜间传播，噪声大，天线尺寸大 |
| 80m | 3.500-3.900 MHz | 夜间本地/区域通联良好 |
| 40m | 7.000-7.200 MHz | 全天候频段，白天区域，夜间远程 |
| 30m | 10.100-10.150 MHz | 仅限 CW 和数字模式，安静的 DX 频段 |
| 20m | 14.000-14.350 MHz | "DX 之王"，白天远程通联首选 |
| 17m | 18.068-18.168 MHz | WARC 频段，无竞赛，适合悠闲通联 |
| 15m | 21.000-21.450 MHz | 太阳活动高年份表现优秀 |
| 12m | 24.890-24.990 MHz | WARC 频段，传播条件好时有惊喜 |
| 10m | 28.000-29.700 MHz | 太阳活动高峰期可实现全球通联 |

## 主流短波电台推荐

### 入门级（3000 - 8000 元）

#### ICOM IC-7300

- **价格**：约 5500-7500 元
- **频段**：HF + 50MHz（6m）
- **功率**：100W
- **特点**：当前最受推荐的入门短波台。采用直接采样 SDR 架构，内置频谱瀑布图显示，触摸屏操作直观。接收性能优秀，内置自动天线调谐器，USB 声卡接口方便数字模式。自 2016 年发布以来一直是入门短波台的标杆。
- **优点**：性能/价格比极高，操作界面友好，频谱显示直观，数字模式连接方便
- **缺点**：不含 VHF/UHF，没有内置电池（纯固定台/需外接电源）
- **评价**：如果只买一台短波台，IC-7300 是绝大多数人的最佳选择

#### 八重洲 FT-710 AESS

- **价格**：约 5500-7000 元
- **频段**：HF + 50MHz
- **功率**：100W
- **特点**：Yaesu 对标 IC-7300 的直接采样 SDR 短波台。4.3 寸触摸屏，频谱显示，内置 AESS 环境感知系统自动优化音频。支持 3 个天线接口，内置调谐器。
- **优点**：多天线接口灵活性高，音频处理出色
- **缺点**：软件成熟度稍逊于 IC-7300

#### 八重洲 FT-991A

- **价格**：约 6000-8000 元
- **频段**：HF + 50MHz + 144MHz + 430MHz（全频段）
- **功率**：100W（HF/50MHz），50W（144/430MHz）
- **特点**：唯一一台覆盖 HF 到 UHF 全频段的紧凑型全模式电台。内置调谐器，触摸屏频谱显示，C4FM 数字模式。一台机器解决所有频段需求。
- **优点**：全频段覆盖，一机多用，体积紧凑
- **缺点**：在任何单一频段上性能都不如同价位的专用机型
- **适合**：空间有限或希望一台搞定所有频段的用户

### 中端（8000 - 20000 元）

#### ICOM IC-7610

- **价格**：约 15000-18000 元
- **频段**：HF + 50MHz
- **功率**：100W
- **特点**：双接收机、双频谱显示的高性能 SDR 短波台。可以同时独立接收两个频段，竞赛和 DX 追踪时极为方便。出色的动态范围和抗阻塞能力，是中端短波台的标杆。
- **适合**：竞赛爱好者、认真的 DX 追踪者

#### 建伍 TS-890S

- **价格**：约 18000-22000 元
- **频段**：HF + 50MHz
- **功率**：100W
- **特点**：建伍的旗舰短波台，采用下变频+直接采样混合架构，接收动态范围极高。7 寸大屏幕，频谱瀑布显示，内置天线调谐器，做工顶级。
- **适合**：追求极致接收性能和做工品质的用户

### 高端/旗舰（20000 元以上）

#### ICOM IC-7851

- **价格**：约 50000-60000 元
- **功率**：200W
- **特点**：ICOM 旗舰，200W 直接输出，四接收机，极致的接收性能。

#### Flex Radio FLEX-6600 / 6700

- **价格**：约 30000-50000 元
- **特点**：纯 SDR 架构，无传统面板，完全通过电脑软件（SmartSDR）控制。极宽的频谱和瀑布图显示，支持远程操作。
- **适合**：喜欢 SDR 和远程操作的技术派用户

## 便携与 QRP 电台

QRP（低功率）通信是业余无线电中一个独特的分支，通常指使用 5W 以下功率进行通联。用最小的功率跨越最远的距离，这种挑战本身就充满乐趣。

### ICOM IC-705

- **价格**：约 6000-8000 元
- **频段**：HF + 50MHz + 144MHz + 430MHz
- **功率**：10W（外部电源）/ 5W（内置电池）
- **特点**：全频段便携电台的标杆产品。内置电池、GPS、蓝牙、Wi-Fi，彩色触摸屏，频谱显示，D-STAR。重量仅 1kg 左右，是户外便携短波操作（POTA/SOTA）的理想选择。
- **适合**：户外便携操作、SOTA（山顶通联）、POTA（公园通联）

### Xiegu（协谷）G90

- **价格**：约 2000-3000 元
- **频段**：HF（0.5-30MHz）
- **功率**：20W
- **特点**：国产短波台的优秀代表，内置自动天线调谐器，可拆卸面板，频谱显示。性价比极高的入门短波台。
- **适合**：预算有限的短波入门者

### Xiegu（协谷）X6100

- **价格**：约 3500-5000 元
- **频段**：HF + 50MHz
- **功率**：10W
- **特点**：内置电池的便携短波台，Linux 系统，4.3 寸触摸屏，频谱瀑布图，Wi-Fi。全模式支持。
- **适合**：便携操作爱好者

### Elecraft KX2 / KX3

- **价格**：约 5000-8000 元（KX2）/ 7000-10000 元（KX3）
- **频段**：HF（KX2 含 80-10m），KX3 可扩展至 VHF
- **功率**：10-15W
- **特点**：美国 Elecraft 出品的经典 QRP 电台，接收性能远超其体积，CW 操作体验极佳。模块化设计，可选配自动天线调谐器和 2m 模块。
- **适合**：CW 爱好者、追求极致便携性能的用户

### QDX / QMX（QRP Labs）

- **价格**：约 200-500 元（套件）
- **频段**：HF（多频段）
- **功率**：5W
- **特点**：超低价格的数字模式（FT8/FT4/WSPR）QRP 收发信机套件。QMX 还支持 CW。需要自己焊接组装。
- **适合**：喜欢 DIY、主要玩 FT8 的用户

## SDR 收发信机

SDR（软件定义无线电）技术已经深度融入现代短波电台。前面提到的 IC-7300、FT-710 等实际上都采用了 SDR 架构。除此之外，还有一些纯 SDR 形态的收发信机：

- **Flex Radio 系列**：无传统面板，纯软件操作，适合远程站。
- **Apache ANAN 系列**：基于开源 openHPSDR 协议的 SDR 收发信机。
- **Hermes Lite 2**：开源 SDR 收发信机项目，5W 输出，价格约 1000-2000 元，适合实验和学习。

## 短波天线简介

短波电台的性能很大程度上取决于天线。关于天线的详细内容将在天线章节单独介绍，这里做简要概述：

- **偶极天线（Dipole）**：最基本的短波天线，半波长偶极在谐振频率上效率很高，制作简单，成本极低。
- **端馈天线（EFHW）**：半波长端馈天线，只需一个挂点，便于架设，是便携操作的热门选择。
- **垂直天线**：占地面积小，全向发射，适合空间有限的城市环境。如 Diamond CP-6、Hustler 系列。
- **八木天线（Yagi）**：定向高增益天线，DX 和竞赛利器，需要旋转器。
- **磁环天线**：体积小，适合公寓和阳台使用，但效率和带宽有限。

## 短波入门建议

1. **先听后发**：拿到 B 类操作证前，可以先用接收设备或 WebSDR 网站（如 websdr.org）熟悉各频段的活动情况。
2. **从 FT8 开始**：FT8 是目前最流行的短波数字模式，信号弱也能完成通联，非常适合入门。只需电台 + 电脑 + WSJT-X 软件。
3. **参加竞赛**：短波竞赛是快速提升操作技能的好方法，每个周末都有各种规模的竞赛。
4. **加入社群**：加入当地的业余无线电协会，参加集体通联活动，向老火腿学习经验。
