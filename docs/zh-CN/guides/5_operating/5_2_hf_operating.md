# 短波操作入门

短波（HF，High Frequency）通信是业余无线电最经典、最迷人的玩法。借助电离层的反射，你可以用几十瓦的功率与地球另一端的电台取得联系，这种跨越距离的魅力是其他通信方式无法比拟的。

## 短波频段概览

业余无线电的短波频段覆盖 1.8 MHz 到 30 MHz，各频段有不同的传播特性：

| 波段 | 频率范围 | 特点 |
|------|---------|------|
| 160 米 | 1.800–2.000 MHz | 夜间传播，噪声大，需要大天线 |
| 80 米 | 3.500–3.900 MHz | 夜间和傍晚传播好，国内通联常用 |
| 40 米 | 7.000–7.200 MHz | 全天候可用，白天中距离、夜间远距离，最活跃的频段之一 |
| 30 米 | 10.100–10.150 MHz | 仅限 CW 和数字模式，传播稳定 |
| 20 米 | 14.000–14.350 MHz | DX（远距离通联）黄金频段，白天传播优秀 |
| 17 米 | 18.068–18.168 MHz | 白天传播好，竞赛不使用此频段 |
| 15 米 | 21.000–21.450 MHz | 太阳活动高峰期白天传播好 |
| 12 米 | 24.890–24.990 MHz | 与 15 米类似，竞赛不使用 |
| 10 米 | 28.000–29.700 MHz | 太阳活动高峰期可有惊人传播，低谷期几乎无法通联 |

> **注意：** 中国 A 类（初级）操作证持有者只能使用部分短波频段和有限功率。请参照最新的频率划分表确认你的操作权限。

## 短波通联的基本流程

### 1. 选择频率和模式

短波通联最常用的模式有：

- **SSB（单边带）** — 语音通联最常用的模式
  - **LSB（下边带）** — 通常用于 7 MHz 及以下频段
  - **USB（上边带）** — 通常用于 14 MHz 及以上频段（10 MHz 也用 USB）
- **CW（连续波 / 莫尔斯电码）** — 效率最高的模式，微弱信号下表现最好
- **数字模式** — FT8、RTTY 等（详见数字模式章节）

### 2. 监听与调谐

在发射前，花时间监听：

- 熟悉频段的活动情况
- 了解当前的传播条件
- 找到你想呼叫的电台或空闲频率

### 3. 发起 CQ 呼叫

CQ 是国际通用的"一般性呼叫"，表示你想和任何电台通联。

**SSB 语音 CQ 呼叫格式：**

```
CQ CQ CQ，这里是 Bravo Hotel One Alpha Bravo Charlie，
BH1ABC 呼叫 CQ 并守听。
```

或使用英文：

```
CQ CQ CQ, this is Bravo Hotel One Alpha Bravo Charlie,
BH1ABC calling CQ and standing by.
```

**CQ 呼叫要点：**

- CQ 叫 2-3 遍即可，不要连续呼叫太多次
- 务必使用字母解释法清晰地拼读呼号
- 呼叫后松开 PTT 认真监听
- 如果 5-10 秒无人回复，可以再次呼叫
- 如果多次呼叫无人回复，可以换个频率或稍后再试

### 4. 回复 CQ 呼叫

当你听到感兴趣的 CQ 呼叫时：

```
BH1ABC，这里是 BV2XYZ，Bravo Victor Two X-ray Yankee Zulu，收到请回答。
```

要点：先说对方呼号，再说自己呼号，清晰拼读。

### 5. 交换信息

标准的短波通联至少需要交换以下信息：

- **呼号** — 双方的呼号
- **信号报告** — RST 报告（见下文）
- **QTH** — 所在位置（通常说到城市即可）
- **名字** — 你的名字或昵称

一个典型的通联过程：

```
"BV2XYZ，谢谢回复。你的信号报告是 59，我的 QTH 是北京，
我叫小明。请给我你的信号报告，Over。"

"BH1ABC，谢谢。你的信号报告也是 59，我的 QTH 是台北，
我叫大卫。很高兴通联，73。BV2XYZ Over。"

"BV2XYZ，谢谢通联，73。BH1ABC 清除频率。"
```

## 信号报告系统（RST）

RST 是业余无线电中用于评估信号质量的标准系统：

### R — 可辨度（Readability）

| 等级 | 含义 |
|------|------|
| R1 | 不可辨认 |
| R2 | 偶尔可辨认 |
| R3 | 困难辨认 |
| R4 | 可辨认，略有困难 |
| R5 | 完全可辨认 |

### S — 信号强度（Signal Strength）

| 等级 | 含义 |
|------|------|
| S1 | 微弱，几乎不可感知 |
| S2 | 非常微弱 |
| S3 | 微弱 |
| S4 | 尚可 |
| S5 | 中等 |
| S6 | 良好 |
| S7 | 中强 |
| S8 | 强 |
| S9 | 非常强 |

### T — 音调（Tone，仅用于 CW）

| 等级 | 含义 |
|------|------|
| T1 | 极粗糙的交流声 |
| T5 | 有明显纹波的音调 |
| T7 | 接近纯净，略有纹波 |
| T9 | 完美纯净的音调 |

**使用示例：**

- SSB 语音通联：`"你的信号报告是 59"` — 完全可辨认，信号非常强
- CW 通联：`"RST 599"` — 完全可辨认、信号非常强、音调完美

> **实际情况：** 在日常通联中，很多 HAM 习惯性地给出 "59" 报告。在竞赛中更是如此。建议在非竞赛通联中尽量给出真实的信号报告，这对双方都有价值。

## QSL 卡片

QSL 卡片是业余无线电的传统，用于确认双方的通联。QSL 来自 Q 码"QSL"，意为"我确认收到"。

### QSL 卡片的内容

一张标准的 QSL 卡片通常包含：

- 你的呼号（醒目位置）
- 通联日期和 UTC 时间
- 频率 / 频段
- 通信模式（SSB/CW/FT8 等）
- 信号报告
- 你的 QTH（位置）
- 你的姓名
- 卡片正面通常有个性化设计（风景照、设备照等）

### QSL 卡片交换方式

1. **直接邮寄（Direct）** — 直接寄给对方，通常附上回邮信封和邮资（SAE/SASE）
2. **通过 QSL Bureau** — 通过各国业余无线电协会的 QSL 局中转，费用低但速度慢（数月到数年）
3. **eQSL** — 在线电子 QSL 确认（eqsl.cc）
4. **LoTW（Logbook of The World）** — ARRL 运营的电子日志确认系统，被广泛认可
5. **QRZ.com** — 也提供在线 QSL 确认功能
6. **HRDLOG** — 另一个在线日志和确认平台

> **建议：** 对于追求奖状（Award）的 HAM，LoTW 是最权威的确认方式。建议同时使用 LoTW 和纸质 QSL 卡片。

## 通联日志（Log）

记录通联日志是每个 HAM 的基本习惯，也是法规要求。

### 日志应记录的内容

每条通联记录至少包含：

- 日期和 UTC 时间
- 对方呼号
- 频率 / 频段
- 通信模式
- 信号报告（发出和收到）
- 其他备注（QTH、姓名、天气、天线等）

### 常用日志软件

| 软件 | 平台 | 特点 |
|------|------|------|
| **N1MM Logger+** | Windows | 竞赛日志的首选，功能强大 |
| **Log4OM** | Windows | 免费，功能全面，界面友好 |
| **Ham Radio Deluxe** | Windows | 综合平台，集成电台控制 |
| **MacLoggerDX** | macOS | Mac 平台最佳选择 |
| **CQRLOG** | Linux | 开源免费，Linux 平台首选 |
| **QRZ.com Logbook** | Web | 在线日志，随时随地可用 |
| **HamRS** | 跨平台 | 新兴的跨平台开源日志软件 |

### ADIF 格式

ADIF（Amateur Data Interchange Format）是业余无线电日志的标准交换格式。几乎所有日志软件都支持 ADIF 导入导出，你可以用它在不同软件之间迁移数据，或上传到 LoTW、eQSL 等平台。

## 短波操作进阶建议

### 传播预测

了解当前的传播条件能大幅提高通联效率：

- **太阳黑子数（SFI）** — 太阳活动越活跃，高频段传播越好
- **K 指数和 A 指数** — 反映地磁活动，数值低传播好
- **传播预测工具** — VOACAP、DX Toolbox、PSKReporter 等
- **DX Cluster** — 实时查看全球 HAM 的通联报告

### 天线的重要性

在短波操作中，天线往往比功率更重要：

- **偶极天线（Dipole）** — 最基础也最有效的天线，适合新手
- **端馈天线（EFHW）** — 单端馈电，架设方便
- **垂直天线（Vertical）** — 占地小，低仰角辐射适合 DX
- **八木天线（Yagi）** — 高增益定向天线，DX 利器

### 操作纪律

- 遵守频段规划，不同模式使用指定频段
- 注意发射功率限制
- CQ 呼叫前确认频率空闲，可先发"Is this frequency in use?"
- 保持耐心，不要在他人通联中间强行插入
- 记录每一次通联，养成良好的日志习惯
