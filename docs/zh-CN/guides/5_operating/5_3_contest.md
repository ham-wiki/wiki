# 业余无线电竞赛

业余无线电竞赛（Contest）是在规定时间内尽可能多地与其他电台取得联系并交换信息的活动。竞赛是提高操作技能、测试设备性能和体验无线电乐趣的绝佳方式。

## 竞赛的基本概念

### 什么是竞赛

竞赛通常持续 24 或 48 小时，参赛者在规定时间内尽可能多地完成有效通联（QSO），并根据通联数量和交换的信息计算得分。

### 基本术语

- **QSO** — 一次完成的通联
- **Exchange（交换信息）** — 竞赛中必须交换的特定信息，如信号报告、区域编号等
- **Multiplier（乘数）** — 额外的得分倍数，通常基于联系到的不同国家、区域等
- **Score（得分）** = QSO 总点数 x 乘数
- **Category（类别）** — 参赛组别，如单人单波段、单人全波段、多人等
- **Band（波段）** — 竞赛使用的频段
- **Rate（速率）** — 每小时完成的通联数量
- **Run（守频呼叫）** — 在一个频率上持续呼叫 CQ
- **S&P（Search and Pounce）** — 搜索并回复其他电台的 CQ

## 主要国际竞赛

### CQ World Wide DX Contest（CQ WW）

- **时间：** 每年 10 月最后一个完整周末（SSB）、11 月最后一个完整周末（CW）
- **时长：** 48 小时
- **频段：** 160m / 80m / 40m / 20m / 15m / 10m
- **交换信息：** RS(T) + CQ Zone（CQ 分区号）
- **乘数：** 不同的 CQ 分区 + 不同的国家/地区（每个波段分别计算）
- **特点：** 全球规模最大的业余无线电竞赛，参与者最多

### CQ WPX Contest

- **时间：** 3 月最后一个完整周末（SSB）、5 月最后一个完整周末（CW）
- **时长：** 48 小时
- **频段：** 160m / 80m / 40m / 20m / 15m / 10m
- **交换信息：** RS(T) + 流水号（从 001 开始递增）
- **乘数：** 不同的呼号前缀（Prefix），如 BH1、BV2、JA1 等
- **特点：** 以呼号前缀为乘数，鼓励联系不同前缀的电台

### ARRL DX Contest

- **时间：** 2 月第三个完整周末（CW）、3 月第一个完整周末（SSB）
- **时长：** 48 小时
- **频段：** 160m / 80m / 40m / 20m / 15m / 10m
- **交换信息：**
  - 美国/加拿大电台发送：RS(T) + 州/省缩写
  - DX 电台（包括中国）发送：RS(T) + 功率
- **特点：** 美国/加拿大 vs 世界其他地区的竞赛

### IARU HF World Championship

- **时间：** 7 月第二个完整周末
- **时长：** 24 小时
- **频段：** 160m / 80m / 40m / 20m / 15m / 10m
- **交换信息：** RS(T) + ITU Zone 或 IARU 协会缩写（总部台）
- **特点：** IARU 官方赛事，各国协会总部台是高分乘数

### CQ World Wide RTTY Contest

- **时间：** 9 月最后一个完整周末
- **时长：** 48 小时
- **模式：** RTTY / 数字模式
- **交换信息：** RST + CQ Zone
- **特点：** 最大的数字模式竞赛

### 其他重要竞赛

| 竞赛 | 时间 | 特点 |
|------|------|------|
| ARRL Sweepstakes | 11月 | 仅限美国/加拿大境内通联 |
| All Asian DX Contest | 6月(CW)/9月(SSB) | 亚洲 vs 非亚洲 |
| WAE DX Contest | 8-9月 | 欧洲 vs 非欧洲，有 QTC 规则 |
| JIDX Contest | 4月(CW)/11月(SSB) | 日本 vs 世界 |
| CQ 160m Contest | 1-2月 | 仅限 160 米波段 |

## 竞赛规则要点

### 参赛类别

大多数竞赛提供以下类别：

**按操作员数量：**

- **单人操作（Single Operator, SO）** — 一个人完成所有操作
- **多人操作（Multi-Operator）** — 团队协作
  - 多人单发射（Multi-Single）— 多个操作员但同时只有一个发射信号
  - 多人两发射（Multi-Two）— 同时最多两个发射信号
  - 多人不限（Multi-Multi）— 每个波段一个发射信号

**按功率：**

- **大功率（High Power）** — 通常 >100W，上限视当地法规
- **低功率（Low Power）** — 通常 ≤100W
- **QRP** — 通常 ≤5W

**按波段：**

- **全波段（All Band）** — 使用所有竞赛波段
- **单波段（Single Band）** — 仅使用一个波段

**按辅助设备：**

- **辅助型（Assisted）** — 可使用 DX Cluster、Skimmer 等
- **非辅助型（Unassisted / Classic）** — 不使用任何外部频率信息来源

### 通用规则

1. 所有时间使用 **UTC**
2. 同一电台在同一波段上只能计一次有效通联
3. 在不同波段上联系同一电台可以重复计分
4. 必须在日志中记录准确的时间、频率、呼号和交换信息
5. 赛后需在规定时间内提交电子日志（Cabrillo 格式）

## 竞赛技巧

### 赛前准备

1. **设备检查** — 提前测试电台、天线、电脑、日志软件
2. **天线调试** — 确保所有波段天线驻波正常
3. **软件设置** — 安装并配置好竞赛日志软件（如 N1MM+）
4. **频率分配** — 了解竞赛中各模式的频率使用惯例
5. **作息计划** — 48 小时竞赛中，合理安排休息时间
6. **传播预测** — 了解竞赛期间的传播条件，规划波段切换策略

### 操作技巧

**Run（守频呼叫）：**

- 找到一个空闲频率，持续呼叫 CQ Contest
- 保持节奏稳定，呼叫间隔不要太长
- 标准 CQ：`"CQ Contest, BH1ABC"` 简短有力
- 快速记录、快速确认、快速呼叫下一个

**S&P（搜索回复）：**

- 在频段上缓慢调谐，寻找新电台
- 听到一个新电台后等待他完成当前通联，然后迅速回复
- 适合竞赛初期或新手

**波段切换策略：**

- 白天高频段（15m/10m）传播好时要抓住机会
- 夜间转向低频段（40m/80m/160m）
- 20m 频段通常全天都有传播
- 关注 Rate（每小时通联速率），当 Rate 下降时考虑换波段

### 信号交换效率

竞赛中的交换要尽可能简短高效：

```text
"CQ Contest BH1ABC"
"BV2XYZ"
"BV2XYZ 59 24"          (59 = 信号报告, 24 = CQ Zone)
"59 33"                  (对方的报告)
"TU BH1ABC"             (Thank You, 继续下一个)
```

## 中国 HAM 竞赛

### CRAC（中国无线电协会）竞赛

中国无线电协会（CRAC）定期组织面向国内 HAM 的竞赛活动：

- **CRAC HF 竞赛** — 每年举办，分 CW 和 SSB 两场
- **内容：** 中国国内电台之间以及中国与海外电台之间的通联
- **交换信息：** 通常为 RS(T) + 流水号或区域代码

### CQ WW 中的中国参赛

中国大陆属于 **CQ Zone 24**，ITU Zone 33/42/43/44。在国际竞赛中，中国大陆使用的呼号前缀（B、BT、BY 等）对于其他地区的参赛者来说是有价值的乘数，因此你会发现在大型竞赛中，很容易被海外电台叫到。

### 竞赛中的中国优势

- 中国所在时区的传播窗口与欧美竞赛大站形成互补
- 中国前缀是多数竞赛中的稀缺乘数
- 中国 HAM 数量增长迅速，竞赛参与度越来越高

## 竞赛日志软件

| 软件 | 费用 | 特点 |
|------|------|------|
| **N1MM Logger+** | 免费 | 最流行的竞赛日志，支持几乎所有竞赛 |
| **Win-Test** | 付费 | 专业级竞赛日志，大站首选 |
| **TR4W** | 免费 | 轻量级，类似经典的 TR Log |
| **SkookumLogger** | 免费 | macOS 平台竞赛日志 |
| **TLF** | 免费 | Linux 终端下的竞赛日志 |

### Cabrillo 日志格式

竞赛结束后需要提交 Cabrillo 格式的日志。这是一种标准化的纯文本格式，包含竞赛信息头和通联记录。几乎所有竞赛日志软件都能直接生成 Cabrillo 文件。

提交方式通常为通过竞赛主办方的网站在线上传或发送电子邮件。

## 新手参赛建议

1. **从小竞赛开始** — 先参加短时间、规则简单的竞赛熟悉流程
2. **先做 S&P** — 刚开始参赛时，以搜索回复为主，积累经验
3. **不追求成绩** — 重在参与，享受过程，提升技能
4. **赛后分析** — 赛后查看成绩排名，分析自己的操作数据
5. **使用 Assisted 类别** — 新手可以借助 DX Cluster 找到更多电台
6. **加入社群** — 和有经验的竞赛选手交流，学习技巧

竞赛是业余无线电中最有激情的活动之一。无论你的目标是拿到第一名还是仅仅享受通联的乐趣，竞赛都能让你在短时间内获得大量操作经验。
