# Q 码与缩语

Q 码和通信缩语是业余无线电通信中的"通用语言"。它们能够跨越语言障碍，让全世界的 HAM 高效地交换信息。

## Q 码

Q 码（Q Code）最初由国际电信联盟（ITU）制定，用于商业和海上无线电通信。业余无线电沿用了其中一部分，并赋予了一些特定含义。每个 Q 码由三个字母组成，以字母 Q 开头。

Q 码既可以作为问句（后加问号），也可以作为陈述句使用。

### 常用 Q 码速查表

| Q 码 | 问句含义 | 陈述句含义 |
|------|---------|-----------|
| **QRA** | 你的电台名称是什么？ | 我的电台名称是…… |
| **QRB** | 你离我有多远？ | 我们之间的距离约为……公里 |
| **QRG** | 你能告诉我准确频率吗？ | 你的准确频率是……kHz（MHz） |
| **QRH** | 我的频率有漂移吗？ | 你的频率有漂移 |
| **QRI** | 我的发射音调怎样？ | 你的音调是……（T1-T9） |
| **QRK** | 我的信号可辨度如何？ | 你的信号可辨度是……（R1-R5） |
| **QRL** | 这个频率有人使用吗？ | 这个频率正在使用中，请勿干扰 |
| **QRM** | 你受到人为干扰吗？ | 我受到人为干扰（1-5级） |
| **QRN** | 你受到天电干扰吗？ | 我受到天电/大气噪声干扰（1-5级） |
| **QRO** | 要我增加发射功率吗？ | 请增加发射功率 |
| **QRP** | 要我减小发射功率吗？ | 请减小发射功率；也指小功率操作（通常 ≤5W） |
| **QRQ** | 要我发得更快吗？ | 请发得更快（CW） |
| **QRS** | 要我发得更慢吗？ | 请发得更慢（CW） |
| **QRT** | 要我停止发射吗？ | 我即将停止发射 / 关机 |
| **QRU** | 你有事情要告诉我吗？ | 我没有事情要告诉你 |
| **QRV** | 你准备好了吗？ | 我已准备好 |
| **QRX** | 你什么时候再呼叫我？ | 我将在……时间再呼叫你 |
| **QRZ** | 谁在呼叫我？ | 你被……呼叫（在……kHz 上） |
| **QSA** | 我的信号强度是多少？ | 你的信号强度是……（S1-S9） |
| **QSB** | 我的信号有衰落吗？ | 你的信号有衰落（fading） |
| **QSL** | 你能确认收讫吗？ | 我确认收讫；也指 QSL 确认卡片 |
| **QSO** | 你能和……通联吗？ | 我能和……通联；也泛指一次通联 |
| **QSP** | 你能中转消息吗？ | 我将为你中转消息给…… |
| **QST** | — | 致全体业余电台的通告（CQ 性质的公告） |
| **QSX** | 你在哪个频率上收听？ | 我在……kHz 上收听（异频操作） |
| **QSY** | 要我换频率吗？ | 请换到……kHz 上 |
| **QTH** | 你的位置在哪里？ | 我的位置在…… |
| **QTR** | 现在的准确时间是？ | 现在的准确时间是…… |

### Q 码使用示例

**语音通联中的 Q 码使用：**

```text
"我的 QTH 是上海。"          → 我的位置在上海。
"你的信号有 QSB。"           → 你的信号有衰落。
"QRM 很严重。"              → 人为干扰很大。
"QSY 到 7.050 好吗？"       → 我们换到 7.050 MHz 好吗？
"QRL？"                    → 这个频率有人使用吗？
"73，QRT 了。"              → 再见，我要关机了。
```

**CW 通联中的 Q 码使用（更加常见和高效）：**

```text
QTH BEI JING              → 我在北京
UR RST 599                → 你的信号报告是 599
QSB                       → 有衰落
QRZ?                      → 谁在叫我？
QSL VIA BURO              → 请通过 QSL Bureau 寄卡
```

### QRM 和 QRN 等级

| 等级 | QRM（人为干扰） | QRN（天电干扰） |
|------|----------------|----------------|
| 1 | 无干扰 | 无噪声 |
| 2 | 轻微干扰 | 轻微噪声 |
| 3 | 中等干扰 | 中等噪声 |
| 4 | 严重干扰 | 严重噪声 |
| 5 | 极度干扰，无法通信 | 极度噪声，无法通信 |

## 常用通信缩语

除了 Q 码之外，业余无线电还使用大量英文缩写。这些缩写在 CW 通联中尤为常用，在语音通联中也经常出现。

### 常用缩写一览

| 缩写 | 全称 | 含义 |
|------|------|------|
| **73** | Best Regards | 美好的祝愿（通联结束时使用） |
| **88** | Love and Kisses | 爱与亲吻（女性 HAM 间或向女性致意） |
| **33** | — | 友谊（部分地区使用） |
| **55** | — | 祝你好运（用于竞赛） |
| **CQ** | Calling Any Station | 一般性呼叫 |
| **CW** | Continuous Wave | 连续波 / 莫尔斯电码 |
| **DX** | Distance | 远距离通联 |
| **FB** | Fine Business | 很好，太棒了 |
| **HI** | — | 笑声（相当于 "哈哈"） |
| **OM** | Old Man | 对男性 HAM 的称呼 |
| **YL** | Young Lady | 对女性 HAM 的称呼 |
| **XYL** | Ex-Young Lady | 妻子 |
| **SK** | End of Contact | 通联结束（CW 中使用） |
| **TU** | Thank You | 谢谢 |
| **DE** | From | 这里是（我是） |
| **UR** | Your | 你的 |
| **ES** | And | 和 |
| **PSE** | Please | 请 |
| **RPT** | Repeat | 重复 |
| **BK** | Break | 插入 / 中断 |
| **AGN** | Again | 再一次 |
| **SRI** | Sorry | 对不起 |
| **WX** | Weather | 天气 |
| **ANT** | Antenna | 天线 |
| **RIG** | — | 电台设备 |
| **PWR** | Power | 功率 |
| **OP** | Operator | 操作员 |
| **FREQ** | Frequency | 频率 |
| **RX** | Receive | 接收 |
| **TX** | Transmit | 发射 |
| **SWR** | Standing Wave Ratio | 驻波比 |

### 数字简码

在 CW 和早期通信中，数字也有简化发送方式：

| 数字 | CW 简码 | 说明 |
|------|---------|------|
| 0 | T | 仅在特定场景下使用 |
| 1 | A | 如 599 可发为 5NN |
| 9 | N | 最常用的简码 |
| 5 | — | 通常不简化 |

例如，CW 竞赛中信号报告 "599" 通常发送为 "5NN"。

## NATO 字母解释法

字母解释法（Phonetic Alphabet）用于在语音通信中清楚地拼读字母，避免因信号不佳而产生混淆。业余无线电普遍采用 NATO/ICAO 标准字母解释法。

| 字母 | 解释词 | 近似发音 |
|------|--------|---------|
| A | Alpha | AL-fah |
| B | Bravo | BRAH-voh |
| C | Charlie | CHAR-lee |
| D | Delta | DEL-tah |
| E | Echo | EK-oh |
| F | Foxtrot | FOKS-trot |
| G | Golf | GOLF |
| H | Hotel | hoh-TEL |
| I | India | IN-dee-ah |
| J | Juliet | JEW-lee-et |
| K | Kilo | KEE-loh |
| L | Lima | LEE-mah |
| M | Mike | MIKE |
| N | November | no-VEM-ber |
| O | Oscar | OSS-car |
| P | Papa | pah-PAH |
| Q | Quebec | keh-BEK |
| R | Romeo | ROH-me-oh |
| S | Sierra | see-AIR-ah |
| T | Tango | TANG-go |
| U | Uniform | YOU-nee-form |

| W | Whiskey | WISS-key |
| X | X-ray | EKS-ray |
| Y | Yankee | YANG-kee |

### 数字读法

| 数字 | 读法 | 近似发音 |
|------|------|---------|
| 0 | Zero | ZEE-roh |
| 1 | One | WUN |
| 2 | Two | TOO |
| 3 | Three | TREE |
| 4 | Four | FOW-er |
| 5 | Five | FIFE |
| 6 | Six | SIX |
| 7 | Seven | SEV-en |
| 8 | Eight | AIT |
| 9 | Nine | NIN-er |

### 使用示例

拼读呼号 **BH1ABC**：

```text
Bravo Hotel One Alpha Bravo Charlie
```

拼读呼号 **BV2XYZ**：

```text
Bravo Victor Two X-ray Yankee Zulu
```

> **提示：** 在实际操作中，有些 HAM 会使用非标准的解释词（如用 "America" 代替 "Alpha"、用 "Boston" 代替 "Bravo"）。虽然在日常通联中可以接受，但建议尽量使用标准 NATO 字母解释法，尤其是在 DX 通联和竞赛中，这样全世界的 HAM 都能准确理解。

### 中文呼号的拼读习惯

在中国 HAM 的日常国内通联中，有时会使用中文来解释呼号中的字母，例如：

- B — "北京的 B"
- H — "火腿的 H"

这种方式仅限于国内中文通联使用。在任何国际通联中，都应使用标准 NATO 字母解释法。

## 实用速查

### 通联开始

```text
CQ CQ CQ de BH1ABC BH1ABC BH1ABC K
（CQ CQ CQ 这里是 BH1ABC 守听）
```

### 通联中

```text
UR RST 599 599  QTH BEIJING  NAME XIAO MING
（你的信号报告 599  我在北京  我叫小明）
```

### 通联结束

```text
TU fer QSO  73  SK  BH1ABC
（谢谢通联  73  结束  BH1ABC）
```

掌握这些 Q 码、缩语和字母解释法，将使你的通联更加顺畅高效。建议将常用的 Q 码和缩语制作成速查卡，放在电台旁边随时参考，直到完全熟记为止。
