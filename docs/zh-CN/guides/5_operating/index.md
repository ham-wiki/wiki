# 操作指南

欢迎来到业余无线电操作指南章节。无论你是刚刚拿到操作证书的新手，还是希望拓展操作技能的老火腿（HAM），本章节都将为你提供实用的操作知识。

## 本章内容

业余无线电的魅力在于"动手实践"。拥有了设备和执照之后，真正的乐趣才刚刚开始。本章将覆盖以下核心操作技能：

- **[FM 中继操作](./5_1_fm_repeater.md)** — 中继器是新手入门最常接触的通信方式。了解中继原理、亚音设置、偏移频率以及中继礼仪，让你自信地发起第一次呼叫。
- **[短波操作入门](./5_2_hf_operating.md)** — 短波（HF）通联是业余无线电最经典的玩法。学习如何发起 CQ 呼叫、交换信号报告、记录通联日志以及交换 QSL 卡片。
- **[业余无线电竞赛](./5_3_contest.md)** — 竞赛（Contest）是提升操作技能的最佳途径。了解主要国际竞赛、竞赛规则与技巧，以及中国 HAM 的竞赛活动。
- **[Q 码与缩语](./5_4_q_codes.md)** — Q 码和通信缩语是业余无线电的"通用语言"。掌握常用 Q 码、缩写词以及北约音标字母，让你的通联更加高效。

## 操作前的准备

在开始操作之前，请确认以下事项：

1. **取得合法执照** — 在中国大陆，你需要通过工业和信息化部组织的业余无线电台操作技术能力验证考试，取得相应等级的操作证书。
2. **设置电台** — 确保你的电台已经正确设置，并按照规定进行了备案登记。
3. **了解频率规划** — 熟悉中国业余无线电频率划分，避免在未授权的频段上发射。
4. **遵守法规** — 遵守《业余无线电台管理办法》及相关法律法规，文明操作。

准备好了吗？让我们从最基础的 FM 中继操作开始吧！
