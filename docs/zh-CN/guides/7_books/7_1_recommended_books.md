# 推荐书籍

本页整理了业余无线电领域的经典书籍，按类别分组，适合不同阶段的爱好者参考选读。

## 入门类

适合零基础或刚接触业余无线电的朋友。

| 书名 | 说明 |
|------|------|
| 《业余无线电通信》 | 国内经典入门读物，内容涵盖无线电基础理论、设备使用和操作规范，可作为 ARRL Handbook 的中文参考 |
| 《无线电爱好者读本》 | 以通俗易懂的方式介绍无线电原理、收发信机结构和基本操作，适合完全零基础的读者 |
| 《业余无线电手册》 | 系统介绍业余无线电各个方面，包括通信模式、频率规划、电台设置等 |
| 《无线电基础知识》 | 从电磁波基本概念讲起，逐步深入到调制、解调和无线电电路 |

## 天线类

天线是业余无线电台最关键的组成部分之一，好的天线胜过好的功放。

| 书名 | 说明 |
|------|------|
| 《ARRL Antenna Book》 | 天线领域的"圣经"，详细讲解各类天线的原理、设计、搭建和调试，内容极为全面（英文） |
| 《天线工程手册》 | 国内天线领域的权威参考书，涵盖天线基础理论、各类天线的设计方法和工程实践 |
| 《Practical Antenna Handbook》(Joseph Carr) | 偏实践的天线书籍，包含大量可动手制作的天线方案（英文） |
| 《小型天线手册》 | 专注于空间受限情况下的天线解决方案，对城市中的火腿尤其实用 |

## 考试类

针对中国业余无线电操作证书考试（A/B/C 类）的复习资料。

| 书名 | 说明 |
|------|------|
| 《业余无线电台操作证书考试参考书（A 类）》 | 针对 A 类（入门级）考试，包含法规、基础知识和操作规范 |
| 《业余无线电台操作证书考试参考书（B 类）》 | 针对 B 类（中级）考试，增加了电路分析、天线理论等内容 |
| 《业余无线电台操作证书考试参考书（C 类）》 | 针对 C 类（高级）考试，涉及更深入的技术理论和国际规则 |
| 《业余无线电台管理办法》及相关法规汇编 | 了解国内业余无线电管理的法律法规，考试必备 |

::: tip 备考建议
考试题库可在 CRAC（中国无线电协会）官网下载，建议结合题库和参考书一起复习。实际考试题目均来自公开题库。
:::

## 经典英文书籍

以下为国际业余无线电界公认的经典著作，英文阅读能力允许的情况下强烈推荐。

| 书名 | 说明 |
|------|------|
| 《The ARRL Handbook for Radio Communications》 | 业余无线电领域最权威的综合性参考书，每年更新，涵盖理论、电路设计、数字通信、天线、测量等所有方面 |
| 《The ARRL Antenna Book》 | 天线设计与搭建的权威指南，包含大量实测数据和实用设计方案 |
| 《Amateur Radio Techniques》(Pat Hawker, G3VA) | 英国 RSGB 出版的经典之作，收集了大量实用技巧和创新设计，风格简洁实用 |
| 《The Radio Amateur's Handbook》 | 早期经典版本，虽然部分内容已过时，但基础理论讲解依然出色 |
| 《RSGB Radio Communication Handbook》 | 英国无线电学会出版的综合手册，与 ARRL Handbook 齐名 |

## 电子学基础

业余无线电离不开电子学知识，以下书籍帮助你建立扎实的电子学功底。

| 书名 | 说明 |
|------|------|
| 《电子学》（The Art of Electronics, Horowitz & Hill） | 被誉为电子学领域的"圣经"，从基本元器件讲到复杂电路系统，既有理论深度又注重实践，中文版翻译质量较好 |
| 《模拟电子技术基础》（童诗白） | 国内高校经典教材，系统讲解模拟电路的分析与设计方法 |
| 《通信电子电路》 | 专注于通信系统中的电子电路，包括振荡器、混频器、功放等，与业余无线电直接相关 |
| 《实用电子元器件与电路基础》(Paul Scherz) | 图文并茂，适合自学，从元器件认识到电路搭建循序渐进 |

## 其他推荐

| 书名 | 说明 |
|------|------|
| 《电波传播概论》 | 了解短波、超短波等不同频段的传播特性，对远距离通信（DX）非常有帮助 |
| 《数字信号处理》相关教材 | SDR（软件定义无线电）时代，DSP 知识越来越重要 |
| 《卫星通信基础》 | 如果你对业余卫星通信感兴趣，这是很好的入门资料 |

::: info 购书建议
- 英文原版书籍可在 ARRL 官方商店（arrl.org）或 Amazon 购买
- 国内书籍可在主要电商平台搜索，部分经典书籍可能已绝版，可尝试二手书平台
- 很多 ARRL 出版物提供电子版（PDF），方便随时查阅
:::
