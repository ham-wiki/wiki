## 软件工具

### 日志软件（Logging）

日志软件用于记录和管理你的通联记录（QSO），是每个火腿必备的工具。

| 软件 | 平台 | 说明 |
|------|------|------|
| Log4OM | Windows | 功能全面的免费日志软件，支持 ADIF 导入导出、LOTW/eQSL 同步、DX Cluster 集成、奖状追踪等 |
| N1MM Logger+ | Windows | 竞赛（Contest）日志软件的标杆，支持几乎所有主流竞赛规则，实时评分和多人联网竞赛 |
| WSJT-X | Windows/macOS/Linux | FT8/FT4/JT65 等弱信号数字模式的官方软件，内置日志功能 |
| JS8Call | Windows/macOS/Linux | 基于 FT8 技术的键盘对键盘通信软件，适合消息传递和应急通信 |
| CloudLog | Web（自托管） | 开源的基于 Web 的日志软件，支持多台设备访问，适合喜欢自托管的用户 |
| Ham Radio Deluxe | Windows | 综合性业余无线电软件套件，包含日志、电台控制、卫星追踪等（付费） |
| CQRLOG | Linux | Linux 平台上优秀的开源日志软件 |

### 天线模拟软件

在搭建天线之前，使用模拟软件进行仿真可以大大提高成功率。

| 软件 | 平台 | 说明 |
|------|------|------|
| MMANA-GAL | Windows | 免费的天线分析与优化软件，基于矩量法（MoM），界面友好，上手容易，适合业余爱好者 |
| 4NEC2 | Windows | 基于 NEC-2 引擎的免费天线建模软件，功能强大，支持 3D 可视化、自动优化和频率扫描 |
| EZNEC | Windows | 商业天线建模软件，由 W7EL 开发，在业余无线电界广泛使用，操作简便（付费） |
| AN-SOF | Windows | 专业天线仿真软件，支持复杂地面建模（付费，有免费版本） |
| OpenFEM | 多平台 | 开源有限元分析工具，可用于天线仿真的高级应用 |

### 传播预测软件

了解电波传播条件，选择合适的频段和时间进行通信。

| 软件 | 平台 | 说明 |
|------|------|------|
| VOACAP Online | Web | 在线 HF 传播预测工具，基于 VOACAP 引擎，输入频率、功率、天线等参数即可预测传播概率 |
| VOACAP | Windows | 离线版本的 VOACAP 传播预测软件，由美国之音（VOA）开发，功能全面 |
| DX Atlas | Windows | 实时显示全球日夜分界线、灰线、MUF 等信息，直观了解传播条件（付费） |
| W6ELProp | Windows | 免费的 HF 传播预测软件，操作简单 |
| WSPR (Weak Signal Propagation Reporter) | 多平台 | 通过发送和接收微弱信号来实测传播路径，是传播研究的有力工具 |

::: tip 建议
- 善用搜索引擎，以你感兴趣的具体话题作为关键词搜索
- 加入本地业余无线电协会或俱乐部，面对面交流是最高效的学习方式
- 很多软件都是免费或开源的，建议先试用再决定是否购买商业软件
:::
