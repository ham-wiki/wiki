# Online Resources

The internet has transformed amateur radio, providing access to information, communities, tools, and real-time data that was unimaginable a generation ago. This page compiles the most useful online resources for amateur radio operators.

## Websites and Databases

### General Amateur Radio

| Website | URL | Description |
|---|---|---|
| **QRZ.com** | `https://www.qrz.com` | The largest amateur radio callsign database. Look up any callsign worldwide. Also hosts forums, logbooks, and awards tracking. |
| **ARRL** | `https://www.arrl.org` | The American Radio Relay League -- the US national amateur radio organization. News, technical information, license exam resources, and advocacy. |
| **RSGB** | `https://rsgb.org` | Radio Society of Great Britain -- the UK national organization. |
| **eHam.net** | `https://www.eham.net` | Reviews, forums, articles, and classifieds for amateur radio. The equipment review section is especially valuable before purchasing gear. |
| **RadioReference** | `https://www.radioreference.com` | Comprehensive database of radio frequencies (amateur, public safety, commercial). |

### Repeater and Frequency Databases

| Website | URL | Description |
|---|---|---|
| **RepeaterBook** | `https://www.repeaterbook.com` | The most comprehensive amateur radio repeater database worldwide. Searchable by location, band, features, and more. |
| **Hearing Ham** | `https://hearham.com` | Real-time repeater activity monitoring. See which repeaters are active right now. |

### Propagation and Conditions

| Website | URL | Description |
|---|---|---|
| **PSK Reporter** | `https://pskreporter.info` | Real-time map of digital mode signal reports worldwide. See where your FT8 signal is being received, or check what bands are open. |
| **DX Summit** | `https://dxsummit.fi` | Real-time DX cluster spots. See what DX stations are active and on what frequencies. |
| **VOACAP** | `https://www.voacap.com` | HF propagation prediction tool. Enter your location and target, and it predicts the best band and time for communication. |
| **SolarHam** | `https://www.solarham.net` | Solar and space weather data relevant to radio propagation. Solar flux, K-index, auroral maps. |
| **N0NBH Solar Banners** | `https://www.hamqsl.com/solar.html` | The ubiquitous solar condition banners seen on many ham radio websites. |

### Awards and Logging

| Website | URL | Description |
|---|---|---|
| **Logbook of The World (LoTW)** | `https://lotw.arrl.org` | ARRL's electronic QSL confirmation system. Required for DXCC and other major awards. |
| **eQSL** | `https://www.eqsl.cc` | Electronic QSL card exchange service. |
| **Club Log** | `https://clublog.org` | DX logging, statistics, and OQRS (Online QSL Request System). Invaluable for DXers. |
| **QRZ Logbook** | `https://logbook.qrz.com` | Built-in logging on QRZ.com with QSL confirmation features. |

### APRS and Tracking

| Website | URL | Description |
|---|---|---|
| **aprs.fi** | `https://aprs.fi` | The primary web-based APRS viewer. Track any APRS station in real-time. |
| **APRS Direct** | `https://www.aprsdirect.com` | Alternative APRS viewer with a clean interface. |

## Forums and Communities

### Reddit

| Subreddit | Description |
|---|---|
| **r/amateurradio** | The main amateur radio subreddit. News, questions, show-and-tell, and discussion. |
| **r/HamRadio** | Secondary ham radio subreddit; overlapping content with r/amateurradio. |
| **r/RTLSDR** | Software-defined radio community focused on RTL-SDR dongles. |
| **r/QuanshengUVK5** | Dedicated to the UV-K5 and custom firmware. |
| **r/EmComm** | Emergency communications discussion. |

### Other Forums

- **QRZ.com Forums** -- Active forums covering all aspects of amateur radio. Can be opinionated but contains a wealth of knowledge.
- **Groups.io** -- Hosts many amateur radio mailing lists and groups (CHIRP support, specific radio models, digital modes, etc.).
- **Facebook Groups** -- Numerous amateur radio groups for every interest. Search for your specific radio model or operating interest.
- **Discord Servers** -- Growing number of amateur radio Discord servers for real-time discussion. Search on Disboard or ask on Reddit.
