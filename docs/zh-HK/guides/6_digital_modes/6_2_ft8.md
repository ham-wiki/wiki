# FT8 模式

FT8（Franke-Taylor design, 8-FSK modulation）係由 Joe Taylor（K1JT）同 Steve Franke（K9AN）喺 2017 年開發嘅數碼通信模式。FT8 徹底改變咗 HF 短波通信嘅玩法，成為目前最受歡迎嘅 HF 數碼模式。

## FT8 嘅特點

- **極強嘅弱信號性能**：可以喺 -24dB 信噪比下解碼（人耳完全聽唔到）
- **固定時序**：每次傳輸 12.64 秒，一個 QSO 約需 1-2 分鐘
- **低功率有效**：5W 甚至更低功率都可以完成全球通信
- **自動化**：軟件自動編碼、解碼、呼叫
- **時間精確**：需要電腦時鐘精確到 1 秒以內

## 點樣運作

### 時間結構

FT8 嘅通信以 15 秒為一個周期：

- 偶數周期（0, 15, 30, 45 秒）
- 奇數周期（7.5, 22.5, 37.5, 52.5 秒）

一方喺偶數周期發射，另一方喺奇數周期發射。

### 標準 QSO 流程

```text
A 發射：CQ VR2XYZ OL62        （CQ呼叫 + 呼號 + 網格定位）
B 發射：VR2XYZ BH4ABC PM01     （回覆 + 雙方呼號 + 網格定位）
A 發射：BH4ABC VR2XYZ -15      （確認 + 信號報告）
B 發射：VR2XYZ BH4ABC R-12     （確認收到 + 信號報告）
A 發射：BH4ABC VR2XYZ RR73     （確認 + 73）
B 發射：VR2XYZ BH4ABC 73       （73 結束）
```

整個 QSO 大約需要 90 秒。

## 所需設備

### 硬件

1. **HF 電台**：任何支持 USB 模式嘅 HF 電台
2. **電腦**：運行 WSJT-X 軟件
3. **電台-電腦介面**：
   - 現代電台（如 IC-7300）直接用 USB 線連接
   - 舊款電台需要 SignaLink USB 或者 digirig 等音頻介面
4. **天線**：任何 HF 天線都可以

### 軟件

#### WSJT-X（必需）

- 官方網站：[wsjt.sourceforge.io](https://wsjt.sourceforge.io)
- 免費、開源
- 支持 Windows / macOS / Linux
- 包含 FT8、FT4、JT65、WSPR 等多種模式

#### JTDX（替代選擇）

- 基於 WSJT-X 嘅分支版本
- 某啲方面嘅解碼性能略好

#### 輔助軟件

- **JTAlert**：信號提醒、自動日誌
- **GridTracker**：實時地圖顯示
- **PSKReporter**：線上信號報告查看

## WSJT-X 設定

### 第一次設定

1. **安裝 WSJT-X**
2. **開啟 File → Settings**

#### Station 設定

- **My Call**：填入你嘅呼號
- **My Grid**：填入你嘅網格定位（例如 OL72 代表香港）
- **可以喺 Google 搜索 "grid square locator" 搵到你嘅網格**

#### Radio 設定

- 選擇你嘅電台型號
- 設定串口（CAT 控制）
- 設定 PTT 方式（CAT / VOX / RTS / DTR）

#### Audio 設定

- 輸入（Input）：選擇電台嘅音頻輸出
- 輸出（Output）：選擇電台嘅音頻輸入
- 如果用 USB 直連：選擇電台嘅 USB 音頻設備

### 重要設定

#### 時間同步

FT8 要求電腦時鐘精確到 ±1 秒以內：

- Windows：用 Dimension 4 或 Meinberg NTP
- macOS / Linux：系統自帶嘅 NTP 通常足夠
- 檢查方法：喺 WSJT-X 嘅瀑布圖上，信號應該喺 0-1 秒嘅範圍內開始

#### 音頻級別

- 發射時嘅音頻唔好太大（ALC 指針唔應該有明顯偏移）
- 推薦用 Power 滑桿控制輸出
- 典型功率：20-50W（唔需要滿功率）

## 操作流程

### CQ 呼叫

1. 選擇一個無人使用嘅音頻頻率位置
2. 點擊「Enable TX」
3. 選擇「CQ」訊息
4. 等待軟件喺下一個適當嘅時間周期自動發射
5. 收到回覆後，軟件會自動切換到下一個步驟

### 回覆其他人嘅 CQ

1. 喺瀑布圖或者信號列表中雙擊想要通聯嘅電台
2. 點擊「Enable TX」
3. 軟件會自動發送回覆
4. 跟隨標準流程完成 QSO

### 自動序列

WSJT-X 支持「Auto Seq」（自動序列）功能：

- 勾選後，軟件會自動跟隨 QSO 流程
- 你只需要選擇要通聯嘅電台，軟件會處理其餘步驟

## FT8 嘅爭議

FT8 喺業餘無線電界有一啲爭議：

**支持者認為**：

- 令低功率同差天線嘅操作員都可以享受 DX
- 拓展咗業餘無線電嘅參與人群
- 喺傳播條件差嘅時候仍然可以通信

**反對者認為**：

- 缺乏人與人之間嘅真正交流
- 太過自動化，失去咗無線電嘅樂趣
- 將 HF 頻段嘅活動集中喺幾個窄頻率上

無論點樣，FT8 已經成為 HF 通信嘅重要組成部分。建議新手體驗一下，但亦唔好錯過 SSB 語音同 CW 嘅樂趣。

## FT4 模式

FT4 係 FT8 嘅快速版本：

- 每次傳輸只需 7.5 秒（FT8 為 12.64 秒）
- 一個 QSO 約需 45 秒
- 主要用於競賽
- 信號需要比 FT8 稍強（-21dB vs -24dB）

## PSKReporter

[PSKReporter](https://pskreporter.info) 係一個實時信號報告網站：

- WSJT-X 會自動上報你接收到嘅信號
- 你可以查看邊啲地方嘅電台收到咗你嘅信號
- 好有用嘅傳播判斷工具
- 可以驗證你嘅天線同電台是否正常工作
