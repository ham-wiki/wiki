# APRS 系統

APRS（Automatic Packet Reporting System，自動封包報告系統）係由 Bob Bruninga（WB4APR）開發嘅業餘無線電數據通信系統。APRS 可以實時傳輸位置、天氣數據、短消息等資訊，喺應急通信同戶外活動中有廣泛應用。

## APRS 嘅功能

- **位置追蹤**：實時顯示電台嘅地理位置
- **天氣報告**：連接氣象站發送天氣數據
- **短消息**：電台之間發送簡短文字訊息
- **遙測數據**：傳輸感測器數據
- **公告**：發佈一般性嘅公告訊息
- **物件/項目**：喺地圖上標記特定位置

## APRS 嘅工作原理

```
你嘅電台（帶 GPS）
    ↓ (144.390 MHz 美國 / 144.640 MHz 亞太)
APRS Digipeater（轉發器）
    ↓
APRS iGate（互聯網網關）
    ↓
APRS-IS（互聯網伺服器）
    ↓
aprs.fi / 其他地圖顯示
```

### 關鍵組件

#### Digipeater（數碼轉發器）
- 接收 APRS 封包並轉發
- 擴展 APRS 嘅覆蓋範圍
- 安裝喺高處（山頂、大廈頂）

#### iGate（互聯網網關）
- 將無線電上嘅 APRS 數據橋接到互聯網
- 反過來亦可以將互聯網上嘅數據發送到無線電

#### APRS-IS（互聯網伺服器）
- 收集同分發全球嘅 APRS 數據
- 提供查詢同顯示服務

## APRS 頻率

| 地區 | 頻率 |
|------|------|
| 北美 | 144.390 MHz |
| 歐洲 | 144.800 MHz |
| 亞太（包括香港） | 144.640 MHz |
| 日本 | 144.660 MHz |
| 中國 | 144.640 MHz |
| 澳洲 | 145.175 MHz |

所有 APRS 通信使用 **1200 bps AFSK**（FM 模式）。

## APRS 設備方案

### 方案一：專用 APRS 電台

部分電台內置 APRS 功能：

| 電台 | 類型 | APRS 功能 |
|------|------|-----------|
| 建伍 TH-D75A | 手持機 | 內置 TNC + GPS |
| 建伍 TM-D710G | 車機 | 內置 TNC + GPS |
| 八重洲 FT-5DR | 手持機 | APRS 支持 |
| 八重洲 FTM-300DR | 車機 | APRS 支持 |
| 八重洲 FTM-400XDR | 車機 | APRS 支持 |

### 方案二：電台 + 外部 TNC

用一部普通嘅 FM 電台加上一個 TNC（終端節點控制器）：

| TNC | 價格（HK$） | 特點 |
|-----|------------|------|
| Mobilinkd TNC4 | 800-1200 | 藍牙連接，配合手機 App |
| Argent Data Tracker3 | 500-800 | GPS 追蹤器 + TNC |
| Byonics TinyTrak4 | 600-900 | 細小輕便 |

### 方案三：手機 + 電台

用手機作為 TNC 同顯示：
- **APRSDroid**（Android）：手機 App，連接到電台嘅音頻介面
- 優點：成本低，功能豐富
- 缺點：連接可能較複雜

### 方案四：純互聯網 APRS

唔需要電台，直接透過互聯網發送 APRS 數據：
- APRS.fi 網頁介面
- APRSDroid 嘅網絡模式
- 呢個唔算「真正」嘅業餘無線電操作，但可以用嚟學習

## APRS 封包格式

一個典型嘅 APRS 位置封包：

```
VR2XYZ>APRS,WIDE1-1,WIDE2-1:=2216.98N/11409.51E-PHG2360 VR2XYZ APRS
```

分解：
- `VR2XYZ`：發送者呼號
- `APRS`：目標（通用）
- `WIDE1-1,WIDE2-1`：路徑（轉發設定）
- `=2216.98N/11409.51E`：位置（北緯 22°16.98'，東經 114°09.51'）
- `-`：圖標（房屋）
- `PHG2360`：功率/高度/增益/方向性
- 後面嘅文字：註釋

### 路徑設定

路徑決定咗你嘅封包會被轉發幾多次：

| 路徑 | 意義 | 適用場景 |
|------|------|----------|
| 無路徑 | 只有直接收到嘅電台先睇到 | 非常近距離 |
| WIDE1-1 | 只被附近嘅 Digipeater 轉發一次 | 城市環境 |
| WIDE1-1,WIDE2-1 | 被轉發最多兩次 | 一般用途 |
| WIDE1-1,WIDE2-2 | 被轉發最多三次 | 偏遠地區 |

::: warning 唔好設定太長嘅路徑
過長嘅路徑會導致頻道擁塞。喺城市環境中，`WIDE1-1` 通常已經足夠。
:::

### 信標速率

你嘅位置信標嘅發射間隔：
- **固定電台**：每 10-30 分鐘
- **車載移動**：每 1-5 分鐘
- **Smart Beaconing**：根據速度同方向自動調整

## 查看 APRS 數據

### aprs.fi
- 網站：[aprs.fi](https://aprs.fi)
- 全球 APRS 數據嘅即時地圖
- 可以搜索呼號、查看軌跡
- 最常用嘅 APRS 查看工具

### APRS Direct
- 網站：[aprsdirect.com](https://aprsdirect.com)
- 另一個 APRS 數據顯示平台

### 手機 App
- **APRSDroid**（Android）
- **APRS.fi**（iOS/Android）

## APRS 嘅實際應用

### 戶外活動追蹤
- 行山、單車、越野時報告位置
- 家人朋友可以喺 aprs.fi 追蹤你嘅位置
- 配合 SOTA/POTA 活動

### 應急通信
- 災害時報告位置同狀態
- 建立臨時通信網絡
- 傳送簡短嘅求助訊息

### 天氣監測
- 連接家用氣象站
- 自動上報溫度、濕度、氣壓、風速等
- 數據匯集到天氣網絡

### 車隊管理
- 追蹤多部車嘅位置
- 適合車隊出遊或者活動保障

## 喺香港使用 APRS

香港嘅 APRS 網絡相對活躍：
- 使用頻率：144.640 MHz
- 有多個 Digipeater 同 iGate 覆蓋
- 可以喺 aprs.fi 搜索「VR2」查看活躍嘅香港電台
