# 數碼模式

數碼模式係業餘無線電中增長最快嘅領域。透過將信號數碼化，數碼模式可以喺傳統語音通信難以達到嘅條件下完成通信，同時提供更清晰嘅音質同更多嘅功能。

## 數碼模式嘅分類

### VHF/UHF 數碼語音

- **DMR**（Digital Mobile Radio）：開放標準，設備選擇多
- **D-STAR**（Digital Smart Technologies for Amateur Radio）：ICOM 主導
- **C4FM / System Fusion**：八重洲（Yaesu）主導
- **P25**：主要用於公共安全通信

### HF 數碼模式

- **FT8 / FT4**：弱信號通信，自動化程度高
- **PSK31**：低帶寬鍵盤通信
- **RTTY**：電傳打字機模式
- **JS8Call**：基於 FT8 嘅鍵盤聊天
- **Winlink**：無線電電子郵件

### 數據通信

- **APRS**：位置報告同短消息
- **Packet Radio**：封包無線電
- **Winlink**：HF/VHF 電子郵件

## 數碼模式嘅優勢

1. **弱信號性能**：FT8 可以喺 -24dB SNR 下完成通信
2. **頻譜效率**：佔用帶寬更窄
3. **音質一致**：數碼語音唔會有類比信號嘅漸進衰減
4. **附加功能**：GPS 定位、短消息、數據傳輸
5. **全球連網**：透過互聯網網關擴展覆蓋
6. **自動化**：減少人手操作嘅需求
