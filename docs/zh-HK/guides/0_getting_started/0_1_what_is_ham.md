# 咩係業餘無線電

## 定義

業餘無線電（Amateur Radio），又叫做 HAM Radio，係一種以個人興趣、自我訓練同技術研究為目的嘅無線電通信活動。業餘無線電愛好者（通常被稱為「火腿」或者 HAM）利用分配俾業餘無線電業務嘅頻率進行通信、實驗同技術探索。

根據國際電信聯盟（ITU）嘅定義，業餘無線電業務係「供業餘無線電愛好者進行自我訓練、相互通信同技術研究之用嘅無線電通信業務」。

## 「HAM」嘅由來

關於 HAM 呢個名稱嘅由來，有幾種講法：

- **早期電台操作員名字縮寫說**：據講係由三位早期業餘無線電先驅嘅姓氏首字母組成——Hyman、Almay 同 Murray
- **業餘者（ham-fisted）說**：早期專業電報員用 "ham" 嚟形容技術生疏嘅業餘操作員，後來業餘愛好者反而以此為榮
- **Home Amateur Mechanic 縮寫說**：代表「家庭業餘技師」

無論點樣，HAM 呢個稱呼已經成為業餘無線電愛好者嘅代名詞。

## 歷史發展

### 早期歷史（1890年代-1920年代）

業餘無線電嘅歷史可以追溯到無線電發明嘅初期：

- **1895年**：馬可尼（Guglielmo Marconi）成功進行咗無線電通信實驗
- **1901年**：馬可尼完成咗第一次跨大西洋無線電傳輸
- **1900年代初**：世界各地開始出現業餘無線電愛好者，佢哋自己製造接收機同發射機
- **1914年**：美國業餘無線電中繼聯盟（ARRL）成立，係世界上最大嘅業餘無線電組織
- **1927年**：喺華盛頓召開嘅國際無線電會議正式為業餘無線電業務分配咗頻率

### 黃金年代（1930年代-1970年代）

- **1930年代**：短波通信技術成熟，業餘無線電愛好者開始進行遠距離（DX）通信
- **第二次世界大戰**：大量業餘無線電愛好者投入軍事通信服務，戰後佢哋帶著豐富嘅經驗返回業餘無線電圈
- **1960年代**：業餘無線電衛星 OSCAR-1 發射，開啟咗業餘衛星通信嘅新時代
- **1970年代**：中繼器（Repeater）系統普及，FM 通信成為主流

### 數碼時代（1980年代至今）

- **1980年代**：封包無線電（Packet Radio）出現
- **1990年代**：數碼模式開始發展，APRS 系統面世
- **2000年代**：軟件定義無線電（SDR）技術興起
- **2017年**：FT8 模式面世，徹底改變咗短波通信嘅玩法

## 業餘無線電喺香港

香港嘅業餘無線電活動有著豐富嘅歷史：

- 香港嘅業餘無線電由通訊事務管理局辦公室（OFCA）監管
- 香港業餘無線電會（HARTS）係本地主要嘅業餘無線電組織
- 香港嘅呼號前綴為 **VR2**
- 香港火腿活躍喺 HF、VHF 同 UHF 各頻段

## 業餘無線電可以做啲咩

### 日常通信
透過本地中繼站同其他火腿傾偈，交流技術心得同生活趣事。

### 遠距離通信（DX）
利用短波頻段同世界各地嘅火腿建立通信聯繫，收集唔同國家同地區嘅 QSL 卡。

### 應急通信
喺自然災害或者緊急情況下，業餘無線電往往係最後仍然可以運作嘅通信手段。

### 衛星通信
透過業餘無線電衛星進行通信，甚至可以同國際太空站（ISS）上面嘅太空人通話。

### 競賽
參加各種業餘無線電競賽（Contest），喺限定時間內盡可能多咁同其他電台建立聯繫。

### 技術實驗
自製電台、天線同各種無線電設備，探索無線電技術嘅各個領域。

### SOTA / POTA
帶住便攜裝備去山頂（Summits on the Air）或者公園（Parks on the Air）進行戶外通信活動。

## 點解要玩業餘無線電

1. **學習電子同無線電技術**：深入了解無線電通信嘅原理同實踐
2. **建立全球友誼**：同世界各地嘅愛好者交流
3. **服務社會**：喺緊急情況下提供通信支援
4. **享受戶外活動**：結合行山、露營同無線電通信
5. **持續挑戰自己**：不斷學習新技術、新模式
6. **不依賴基礎設施**：喺無手機信號嘅地方都可以通信

業餘無線電唔單止係一種興趣，更加係一種技能同一個社群。無論你嘅背景同年齡點樣，都可以喺業餘無線電嘅世界裏面搵到屬於自己嘅樂趣。
