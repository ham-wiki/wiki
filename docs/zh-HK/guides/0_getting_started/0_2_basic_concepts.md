# 基礎概念

喺開始業餘無線電之旅之前，有啲基本嘅物理同技術概念係必須了解嘅。呢篇文章會用淺白嘅語言介紹業餘無線電最核心嘅概念。

## 無線電波

無線電波係電磁波嘅一種，以光速（約每秒 30 萬公里）傳播。無線電波嘅兩個最基本特性就係**頻率**同**波長**。

## 頻率（Frequency）

頻率係指無線電波每秒鐘振動嘅次數，單位係赫茲（Hz）。

| 單位 | 縮寫 | 數值 |
|------|------|------|
| 赫茲 | Hz | 1 Hz |
| 千赫 | kHz | 1,000 Hz |
| 兆赫 | MHz | 1,000,000 Hz |
| 吉赫 | GHz | 1,000,000,000 Hz |

例如，FM 廣播電台嘅頻率大約喺 88-108 MHz，而業餘無線電常用嘅 2 米頻段喺 144-148 MHz。

## 波長（Wavelength）

波長係指一個完整波形嘅長度。頻率同波長之間有一個簡單嘅反比關係：

$$\lambda = \frac{c}{f}$$

其中：
- λ（lambda）= 波長（米）
- c = 光速（約 300,000,000 米/秒）
- f = 頻率（赫茲）

**簡化公式**：波長（米）= 300 ÷ 頻率（MHz）

例如：
- 145 MHz → 波長 ≈ 300 ÷ 145 ≈ 2.07 米（所以叫「2 米頻段」）
- 435 MHz → 波長 ≈ 300 ÷ 435 ≈ 0.69 米（所以叫「70 厘米頻段」）
- 7 MHz → 波長 ≈ 300 ÷ 7 ≈ 42.9 米（所以叫「40 米頻段」）

## 調制方式（Modulation）

調制係指將語音、數據等訊息「載」上無線電波嘅方法。常見嘅調制方式有：

### FM（調頻 - Frequency Modulation）
- 透過改變載波嘅頻率嚟傳送訊息
- 音質較好，抗干擾能力強
- 常用於 VHF/UHF 本地通信同中繼操作
- 佔用帶寬較闊（通常 12.5kHz 或 25kHz）

### AM（調幅 - Amplitude Modulation）
- 透過改變載波嘅振幅嚟傳送訊息
- 帶寬較窄，適合遠距離通信
- 常用於航空通信同部分 HF 通信

### SSB（單邊帶 - Single Sideband）
- AM 嘅改良版本，只發射一個邊帶
- 分為 USB（上邊帶）同 LSB（下邊帶）
- 頻譜效率高，係 HF 語音通信嘅主流模式
- 慣例：7 MHz 以下用 LSB，7 MHz 以上用 USB

### CW（連續波 - Continuous Wave）
- 即摩斯電碼通信
- 帶寬極窄（約 100-500 Hz），穿透力強
- 喺弱信號條件下表現出色
- 需要學習摩斯電碼

### 數碼模式
- FT8、FT4、PSK31、RTTY 等
- 透過電腦軟件進行編碼同解碼
- 部分模式可以喺極弱信號條件下完成通信

## 功率（Power）

發射功率以瓦特（W）為單位。功率越大，理論上通信距離越遠，但同時亦會產生更多嘅干擾同消耗更多能量。

| 功率等級 | 典型功率 | 應用場景 |
|----------|----------|----------|
| QRP（低功率） | ≤ 5W | 便攜操作、技術挑戰 |
| 手持機 | 1-8W | 本地通信 |
| 車機 | 25-75W | 車載操作、中繼通信 |
| 基地台 | 50-200W | 家用基地台 |
| 高功率 | 200-1500W | 競賽、DX 通信 |

::: tip 功率並非一切
喺業餘無線電界有句話：「最好嘅放大器係一支好天線。」好多時候，改善天線系統比增加發射功率更有效。功率每增加一倍，信號只會提升約 3dB（大約半個 S 值），而一支高增益天線可以輕易提供 6-10dB 嘅增益。
:::

## 分貝（dB）

分貝係無線電通信中經常用到嘅相對單位，用嚟表示兩個功率或者電壓之間嘅比值。

常用嘅分貝值：

| 分貝值 | 功率比 | 意義 |
|--------|--------|------|
| 0 dB | 1:1 | 無變化 |
| 3 dB | 2:1 | 功率加倍 |
| 6 dB | 4:1 | 功率四倍 |
| 10 dB | 10:1 | 功率十倍 |
| 20 dB | 100:1 | 功率一百倍 |
| -3 dB | 1:2 | 功率減半 |

常見嘅分貝單位：
- **dBm**：以 1 毫瓦為參考點嘅功率值
- **dBi**：天線增益，以理想各向同性天線為參考
- **dBd**：天線增益，以半波偶極天線為參考（dBi ≈ dBd + 2.15）

## 駐波比（SWR - Standing Wave Ratio）

SWR 係衡量天線系統匹配程度嘅重要指標。當發射機嘅輸出阻抗同天線系統嘅阻抗唔匹配嗰陣，部分能量會被反射回發射機，形成駐波。

| SWR | 反射功率 | 狀態 |
|-----|----------|------|
| 1.0:1 | 0% | 完美匹配 |
| 1.5:1 | 4% | 優秀 |
| 2.0:1 | 11% | 良好 |
| 3.0:1 | 25% | 需要調整 |
| 5.0:1 | 44% | 差，需要立即處理 |
| ∞:1 | 100% | 完全反射（斷路或短路） |

::: warning 注意
SWR 過高唔單止會降低發射效率，仲可能損壞發射機嘅末級功率放大器。大部分現代電台都有 SWR 保護功能，會喺 SWR 過高嗰陣自動降低輸出功率。建議將 SWR 控制喺 2.0:1 以下。
:::

### 點樣降低 SWR

1. **調整天線長度**：天線嘅物理長度會影響其諧振頻率
2. **使用天線調諧器（ATU）**：可以匹配唔同阻抗嘅天線
3. **檢查饋線同接頭**：接頭鬆脫或者饋線損壞都會導致 SWR 升高
4. **調整天線高度同位置**：周圍環境會影響天線嘅阻抗

## 阻抗（Impedance）

阻抗係交流電路中嘅「電阻」，單位係歐姆（Ω）。喺業餘無線電系統中，標準阻抗係 **50Ω**。發射機、饋線同天線都應該係 50Ω，先可以達到最佳匹配。

常見嘅同軸電纜阻抗：
- **RG-58**：50Ω，較幼，適合短距離
- **RG-8 / RG-213**：50Ω，較粗，損耗較低
- **RG-174**：50Ω，極幼，適合設備內部連接
- **RG-59 / RG-6**：75Ω，用於電視系統，唔適合業餘無線電

## 傳播方式

無線電波嘅傳播方式因頻率而異：

### 地波傳播
- 沿著地球表面傳播
- 主要適用於中波同低頻
- 傳播距離有限

### 天波傳播（電離層反射）
- 無線電波被電離層反射回地面
- 主要適用於 HF（短波）頻段
- 可以實現全球通信
- 受日照、太陽活動同季節影響

### 視距傳播
- 以直線方式傳播
- 主要適用於 VHF/UHF 頻段
- 傳播距離受地形同天線高度限制
- 中繼器可以擴展覆蓋範圍

### 對流層傳播
- 利用對流層嘅溫度逆轉層進行折射
- 可以使 VHF/UHF 信號傳播到異常遠嘅距離
- 屬於偶發現象
