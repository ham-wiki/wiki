# 頻段概覽

業餘無線電愛好者可以使用多個唔同嘅頻段，每個頻段都有獨特嘅傳播特性同用途。國際電信聯盟（ITU）將全球劃分為三個區域，唔同區域嘅頻率分配可能略有不同。中國屬於 ITU 第三區。

## 頻段分類

### HF（高頻 / 短波）頻段：1.8 - 30 MHz

HF 頻段係業餘無線電最具魅力嘅頻段，因為可以透過電離層反射實現遠距離甚至全球通信。

| 頻段名稱 | 頻率範圍 | 特性 |
|----------|----------|------|
| 160 米 | 1.800 - 2.000 MHz | 「頂頻段」，夜間傳播較好，天線尺寸大 |
| 80 米 | 3.500 - 3.900 MHz | 夜間近距離通信良好，噪音較多 |
| 40 米 | 7.000 - 7.300 MHz | 全天候可用，日間數百公里，夜間可達數千公里 |
| 30 米 | 10.100 - 10.150 MHz | WARC 頻段，僅限 CW 同數碼模式，唔可以用於競賽 |
| 20 米 | 14.000 - 14.350 MHz | DX 通信嘅黃金頻段，日間傳播條件最佳 |
| 17 米 | 18.068 - 18.168 MHz | WARC 頻段，適合日間 DX 通信 |
| 15 米 | 21.000 - 21.450 MHz | 太陽活動高峰期表現優秀 |
| 12 米 | 24.890 - 24.990 MHz | WARC 頻段，太陽活動高峰期開放 |
| 10 米 | 28.000 - 29.700 MHz | 太陽活動高峰期可以全球通信，低谷期幾乎無用 |

::: tip 太陽黑子周期
HF 頻段嘅傳播條件同太陽黑子活動周期（約 11 年）密切相關。太陽活動高峰期，高頻段（10、12、15 米）傳播條件極佳；低谷期則要依靠低頻段（40、80 米）。
:::

### VHF（甚高頻）頻段：30 - 300 MHz

| 頻段名稱 | 頻率範圍 | 特性 |
|----------|----------|------|
| 6 米 | 50 - 54 MHz | 「魔幻頻段」，偶爾出現遠距離傳播 |
| 2 米 | 144 - 148 MHz | 最常用嘅 VHF 頻段，中繼器眾多 |

**2 米頻段**係大部分火腿最常用嘅頻段，原因包括：
- 設備價格便宜、選擇多
- 本地中繼器覆蓋廣泛
- 手持機體積細、攜帶方便
- 天線尺寸適中

### UHF（超高頻）頻段：300 MHz - 3 GHz

| 頻段名稱 | 頻率範圍 | 特性 |
|----------|----------|------|
| 70 厘米 | 430 - 440 MHz | 第二常用頻段，穿透力較好 |
| 23 厘米 | 1240 - 1300 MHz | 微波入門頻段 |

**70 厘米頻段**嘅特點：
- 天線更加細小
- 建築物穿透性較 2 米好
- 常用於 DMR、D-STAR 等數碼中繼
- 同 2 米一齊係雙頻手持機嘅標準配置

### 微波頻段：> 1 GHz

包括 23 厘米（1.2 GHz）、13 厘米（2.4 GHz）、9 厘米（3.4 GHz）等更高頻段。微波通信需要專門嘅設備同高增益天線，屬於較為進階嘅領域。

## 中國（CRAC）頻率分配

中國業餘無線電愛好者嘅頻率使用受中國無線電協會（CRAC）同工業和信息化部管理。以下係常用頻率：

### A 類操作證可用頻段
- **2 米 FM**：144.000 - 146.000 MHz
- **70 厘米 FM**：430.000 - 440.000 MHz

### B 類操作證額外可用頻段
- **160 米**：1.800 - 2.000 MHz
- **80 米**：3.500 - 3.900 MHz
- **40 米**：7.000 - 7.200 MHz
- **20 米**：14.000 - 14.350 MHz
- **15 米**：21.000 - 21.450 MHz
- **10 米**：28.000 - 29.700 MHz
- 以及其他頻段

### C 類操作證
- 可使用全部業餘頻段
- 最高功率限制較高

## 香港（OFCA）頻率分配

香港嘅業餘無線電頻率分配由通訊事務管理局辦公室（OFCA）管理。香港火腿可以使用嘅頻段同 ITU 第三區分配大致相同，但有部分限制。詳情請參考 OFCA 發出嘅業餘電台牌照條款。

## 頻段使用計劃（Band Plan）

每個頻段都有約定俗成嘅使用計劃，規定邊啲頻率段用於咩模式。例如 2 米頻段：

| 頻率範圍 | 用途 |
|----------|------|
| 144.000 - 144.035 MHz | EME（月面反射）CW |
| 144.035 - 144.150 MHz | CW |
| 144.150 - 144.400 MHz | SSB |
| 144.400 - 144.500 MHz | 信標 |
| 145.000 - 145.800 MHz | FM 單工同中繼 |
| 145.800 - 146.000 MHz | 衛星通信 |

::: warning 注意
具體嘅頻段計劃可能因地區而異。請務必查閱你所在地區嘅官方頻段計劃，避免干擾其他業務。
:::

## 點樣揀頻段

對於初學者，建議由以下頻段開始：

1. **2 米 / 70 厘米 FM**：入門嘅最佳選擇，設備便宜，本地活動豐富
2. **40 米 SSB**：如果想體驗短波通信，40 米係全天候可用嘅好選擇
3. **20 米 SSB**：想進行國際通信，20 米係 DX 嘅黃金頻段

隨住經驗增加，你可以逐步探索更多頻段同模式，搵到最適合自己嘅玩法。
