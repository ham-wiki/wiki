# 第一步

決定咗要入坑業餘無線電之後，跟住呢個路線圖一步一步嚟，你就可以順利開始你嘅火腿之旅。

## 第一步：了解法規要求

喺大部分國家同地區，操作業餘無線電發射設備都需要持有有效嘅執照。唔同地區嘅要求如下：

### 中國大陸

1. 通過 CRAC 業餘無線電操作能力驗證考試
2. 取得業餘無線電台操作證書（A/B/C 類）
3. 設置業餘無線電台審批（獲得呼號）

### 香港

1. 向 OFCA 申請業餘電台牌照
2. 需要通過相關考試
3. 獲批後取得 VR2 開頭嘅呼號

### 澳門

- 由郵電局管理

::: tip 可以唔考牌就玩嗎？
嚴格嚟講，如果你只係接收（收聽），大部分地區係唔需要執照嘅。你可以用一部 SDR 接收器或者普通收音機收聽業餘無線電通信，呢個係入門前了解業餘無線電嘅好方法。但係，一旦你想發射（傳送信號），就必須持有有效嘅執照。
:::

## 第二步：學習基礎知識

### 自學資源

- 閱讀本知識庫嘅 [基礎概念](./0_2_basic_concepts.md) 同 [頻段概覽](./0_3_bands_overview.md)
- 參考 [推薦書籍](../7_books/7_1_recommended_books.md)
- 觀看 YouTube 上嘅業餘無線電教學影片
- 加入相關嘅討論群組同論壇

### 需要掌握嘅知識

- 無線電基礎理論（頻率、波長、功率）
- 電子學基礎（歐姆定律、電路基本概念）
- 天線基礎知識
- 無線電法規同操作規範
- 安全操作知識

## 第三步：考取執照

詳細嘅考試資訊請參考 [考試與執照](../1_license_exam/) 章節。以下係一啲基本建議：

### 中國大陸 CRAC 考試

- A 類考試相對簡單，適合初學者
- 可以用手機 App 刷題備考
- 考試以選擇題為主
- 通過後可以操作 VHF/UHF 頻段

### 備考建議

1. 下載 CRAC 題庫 App 進行練習
2. 重點理解法規部分，呢啲係必考嘅
3. 電子學同無線電理論唔使死記，理解原理更重要
4. 同已經有牌嘅火腿交流，佢哋嘅經驗好有用

## 第四步：購買第一部電台

### 新手推薦裝備

對於大部分初學者，一部 **VHF/UHF 雙頻手持機**係最佳嘅第一部電台：

**入門級選擇**：

- 寶鋒 UV-5R 系列（預算極低）
- 泉盛 UV-K5（可刷韌體，功能豐富）
- 泉盛 UV-K6

**中階選擇**：

- 八重洲 FT-65R / FT-4XR
- 建伍 TH-D75A
- ICOM IC-T10

**進階選擇**：

- 八重洲 FT-5DR（C4FM 數碼）
- ICOM ID-52A（D-STAR 數碼）

### 除咗電台，你仲需要

- **天線**：原裝天線通常效能一般，可以考慮升級
- **SMA 轉接頭**：唔同品牌嘅接頭可能唔同
- **電池**：多備一塊電池或者買車充線
- **耳機 / 手咪**：方便喺唔同場景使用
- **編程線**：用電腦設定頻道比手動輸入快好多

## 第五步：設定電台

拎到電台之後，你需要做以下設定：

### 基本設定

1. **輸入本地中繼器頻率**：查詢你所在地區嘅中繼器列表
2. **設定 CTCSS/DCS 碼**：大部分中繼器都需要亞音頻碼先可以接入
3. **設定呼叫頻率**：儲存常用嘅呼叫頻率
4. **調節音量同靜噪（Squelch）**：確保可以正常收聽

### 使用 CHIRP 編程

CHIRP 係一個免費嘅開源電台編程軟件，支援大部分常見品牌嘅電台。詳情請參考 [CHIRP 編程指南](../4_modification/4_4_chirp_programming.md)。

## 第六步：開始收聽

唔好急住發射！先花啲時間收聽：

1. **監聽本地中繼器**：了解本地火腿嘅通信習慣同禮儀
2. **學習通信用語**：熟悉常用嘅 Q 碼同縮語
3. **了解通信禮儀**：點樣禮貌咁加入一個對話
4. **記錄頻率**：記低活躍嘅頻率同中繼器

## 第七步：第一次發射

當你準備好進行第一次發射嗰陣：

### 發射前檢查

- 確保你已經持有有效嘅執照同呼號
- 確認你嘅電台設定正確
- 選擇一個有活動嘅頻率或者中繼器

### 基本通信流程

1. **先聽**：確認頻率上無其他人喺使用
2. **呼叫**：「各位火腿，呢度係 [你嘅呼號]，有冇收到？」
3. **等待回應**：鬆開 PTT 鍵，等待對方回覆
4. **交流**：交換呼號、信號報告、位置、名稱等基本訊息
5. **結束**：「73（再見），[你嘅呼號] clear」

### 第一次 QSO 嘅小貼士

- 唔使緊張，大部分火腿都好友善
- 講嘢清晰，速度適中
- 每次發射都要報出你嘅呼號
- 如果犯錯，唔使擔心，大家都係由新手開始嘅

## 第八步：加入社群

- **加入本地業餘無線電會**：香港可以加入 HARTS
- **參加聚會（Eyeball QSO）**：面對面交流學習更快
- **加入線上社群**：微信群、Telegram 群組、論壇等
- **參加火腿節（Hamfest）**：了解最新設備同技術

## 進階路線圖

當你掌握咗基本操作之後，可以考慮以下方向：

```text
入門（VHF/UHF FM）
    ├── 升級執照 → B 類 / C 類
    ├── 短波通信（HF SSB/CW）
    ├── 數碼模式（DMR / FT8 / D-STAR）
    ├── 天線製作同實驗
    ├── 便攜操作（SOTA / POTA）
    ├── 衛星通信
    ├── 競賽（Contest）
    ├── 應急通信
    └── 自製設備（QRP / SDR）
```

每一個方向都可以深入研究好耐，呢個就係業餘無線電嘅魅力所在——永遠都有新嘢學，永遠都有新挑戰。
