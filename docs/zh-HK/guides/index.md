## 點樣使用呢個知識庫

建議初學者由 [入門指南](./0_getting_started/) 開始睇起，循序漸進咁了解業餘無線電嘅世界。如果你已經有一定基礎，可以直接跳去你感興趣嘅章節。

每篇文章都盡量用淺白嘅語言解釋技術概念，並且提供實用嘅操作建議。如果你發現任何錯誤或者想補充內容，歡迎透過 GitHub 提交貢獻。

本知識庫嘅內容僅供參考同學習之用。喺進行任何無線電操作之前，請確保你已經取得合法嘅業餘無線電執照，並且遵守當地嘅無線電管理法規。
