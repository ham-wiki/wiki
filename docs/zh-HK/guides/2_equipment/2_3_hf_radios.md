# 短波電台

短波（HF）電台係業餘無線電最令人興奮嘅設備之一。透過電離層反射，HF 電台可以實現全球通信，同世界各地嘅火腿交流。要操作 HF 電台，喺中國需要持有 B 類或以上嘅操作證書。

## HF 電台嘅基本類別

### 桌上型 / 基地台型
- 功能最齊全
- 接收性能最好
- 體積較大，適合固定使用
- 功率通常 100W

### 便攜型
- 體積細小，重量輕
- 功率通常 5-20W
- 適合戶外活動（SOTA/POTA）
- 功能可能有所精簡

### 車載型
- 設計用於車載環境
- 抗震動能力強
- 功率通常 50-100W

## 選購建議

### HF 入門首選

如果你只買一部 HF 電台，強烈推薦 **ICOM IC-7300**。原因：

1. SDR 架構帶嚟嘅優秀接收性能
2. 瀑布圖令操作直覺好多
3. 觸摸屏操作方便
4. 100W 功率足夠大部分用途
5. 社群龐大，教學資源豐富
6. 性價比極高

### 如果想便攜操作

選擇 **八重洲 FT-891**（功率優先）或者 **Xiegu G90**（預算優先）。

### 如果想全頻段覆蓋

考慮 **ICOM IC-705**（HF + VHF + UHF，便攜）或者 **八重洲 FT-991A**（HF + VHF + UHF，基地台）。

## HF 電台配套需求

買咗 HF 電台之後，你仲需要：

1. **天線**：呢個係最重要嘅！一支好嘅天線比一部好嘅電台更重要
   - 入門推薦：半波偶極天線（可以自己 DIY）
   - 詳情請參考 [天線與製作](../3_antenna/) 章節

2. **饋線**：RG-8 或 RG-213 同軸電纜，長度視天線位置而定

3. **天線調諧器**：如果電台無內置，需要外部調諧器

4. **電源供應器**：13.8V、至少 25A（100W 電台需要）

5. **接地系統**：良好嘅接地可以減少噪音同改善安全性

6. **耳機**：HF 操作時用耳機可以更好咁分辨弱信號

7. **麥克風**：原裝手咪通常足夠，進階可以考慮桌面咪

## HF 操作嘅挑戰

### 天線空間
HF 天線通常需要較大嘅空間。40 米頻段嘅半波偶極天線全長約 20 米。如果你住喺公寓或者空間有限，需要考慮妥協方案：
- 磁環天線（佔地少但效率較低）
- 縮短型天線
- 室內天線（效果有限）
- 便攜天線（適合戶外使用）

### 電磁干擾
城市環境中嘅電磁噪音可能好嚴重，影響 HF 接收。解決方法：
- 使用降噪天線
- 安裝濾波器
- 選擇噪音較低嘅時段操作
- 去郊外便攜操作

### 學習曲線
HF 操作比 VHF/UHF FM 複雜得多，需要了解：
- 傳播條件判斷
- SSB 調諧技巧
- 頻段使用計劃
- DX 操作禮儀
