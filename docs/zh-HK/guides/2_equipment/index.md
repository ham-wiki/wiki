## 設備選購嘅基本原則

### 1. 由需求出發
唔好一開始就買最貴嘅設備。先諗清楚你想做咩：
- 只係本地通信？→ 手持機或車機
- 想玩短波 DX？→ HF 電台
- 想探索數碼模式？→ 支持相關功能嘅電台或 SDR

### 2. 預算規劃
業餘無線電設備嘅價格差距好大：
- 入門手持機：幾十至幾百蚊港幣
- 中階設備：幾千蚊
- 高端 HF 電台：幾萬蚊
- 頂級設備：超過十萬蚊

### 3. 可升級性
選擇可以隨住你嘅技術提升而升級嘅設備同系統。

### 4. 品牌同售後
主要嘅業餘無線電設備品牌：
- **ICOM**（日本）：品質穩定，產品線齊全
- **八重洲（Yaesu）**（日本）：功能豐富，性價比高
- **建伍（Kenwood）**（日本）：音質優秀，操作直覺
- **寶鋒（Baofeng）**（中國）：價格極低，入門首選
- **泉盛（Quansheng）**（中國）：性價比高，部分型號可刷韌體
- **Elecraft**（美國）：高端 QRP 同 HF 設備

## 新手推薦購買順序

```
第一步：VHF/UHF 手持機（入門必備）
    ↓
第二步：手持機升級天線（提升效能）
    ↓
第三步：車機或基地台天線（擴展覆蓋）
    ↓
第四步：HF 入門電台（如果考取 B 類）
    ↓
第五步：HF 天線系統（偶極天線或垂直天線）
```

## 喺邊度買

### 線上渠道
- 淘寶 / 天貓（中國品牌為主）
- Amazon / eBay（國際品牌）
- 專業無線電設備網店
- Ham Radio Outlet (HRO)

### 線下渠道
- 本地無線電設備店
- 火腿節（Hamfest）二手市場
- 業餘無線電會嘅交流活動

### 買二手設備嘅建議
- 喺信譽良好嘅平台或者圈內交易
- 要求試機同驗證功能
- 檢查外觀磨損同接頭狀態
- 了解設備嘅市場價格，避免買貴
