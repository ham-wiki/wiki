# 手持機選購指南

手持機（HT，Handy Transceiver）係大部分業餘無線電愛好者嘅第一部電台。佢細小輕便、價格親民，係入門嘅最佳選擇。

## 手持機嘅基本規格

選購手持機嗰陣，要留意以下規格：

### 頻段覆蓋

- **單頻段**：只覆蓋 VHF（144 MHz）或 UHF（430 MHz）
- **雙頻段**：同時覆蓋 VHF 同 UHF（最常見）
- **三頻段/多頻段**：覆蓋更多頻段，包括航空頻段接收等

### 發射功率

- 大部分手持機嘅功率喺 1W 到 8W 之間
- 高功率 = 更遠嘅通信距離，但亦 = 更快消耗電池
- 實際使用中，5W 同 8W 嘅分別唔係好大

### 其他重要規格

- **電池容量**：mAh 越大，續航越長
- **防水等級**：IPX4（防濺水）到 IPX7（可短暫浸水）
- **接收靈敏度**：數值越低（越負）越好
- **天線接口**：SMA-M（公頭）或 SMA-F（母頭），唔同品牌可能唔同

## 入門級手持機

### 寶鋒 UV-5R 系列

**價格**：約 HK$50-150

**優點**：

- 價格極低，壞咗唔心痛
- 雙頻段 VHF/UHF
- 功能基本齊全
- 配件豐富，容易搵到
- 社群龐大，教學資源多

**缺點**：

- 接收靈敏度一般
- 雜散發射可能較大
- 音質中等
- 電池容量偏細
- 操作介面唔太直覺

**適合**：預算有限嘅初學者、備用機、實驗用途

### 泉盛 UV-K5 / UV-K6

**價格**：約 HK$100-250

**優點**：

- 性價比極高
- 支持刷第三方韌體（UV-K5），功能可以大幅擴展
- 接收頻率範圍廣
- 彩色屏幕（部分型號）
- 支持頻譜顯示（刷韌體後）

**缺點**：

- 原廠韌體功能有限
- 需要刷韌體先可以發揮最大潛力
- 做工一般

**適合**：想折騰嘅新手、喜歡 DIY 嘅愛好者

::: tip UV-K5 刷韌體
UV-K5 嘅最大賣點係可以刷第三方韌體（如 Egzumer 韌體），解鎖頻譜分析儀、AM 航空頻段接收等功能。詳情請參考 [泉盛 UV-K5 韌體刷寫](../4_modification/4_1_uv_k5_firmware.md)。
:::

**價格**：約 HK$500-700

- 功能相對基本

### 八重洲 FT-4XR

**價格**：約 HK$400-600

**優點**：

- 體積極細小
- 重量輕，適合便攜
- 操作簡單
- 價格合理

**缺點**：

- 功能較少
- 屏幕細小

### ICOM IC-T10

**價格**：約 HK$800-1200

**優點**：

- ICOM 品質保證

- 軍規級耐用
- 音質清晰
- 操作直覺

**缺點**：

- 價格略高
- 功能相對基本

## 高階手持機

### 八重洲 FT-5DR

**價格**：約 HK$3000-4000

**優點**：

- 支持 C4FM 數碼模式
- 觸摸屏操作
- GPS 內置
- 藍牙功能
- 雙頻同時接收
- Wires-X 網絡連接

**缺點**：

- 價格較高
- 電池消耗較快

### ICOM ID-52A

**價格**：約 HK$4000-5000

**優點**：

- 支持 D-STAR 數碼模式
- 彩色觸摸屏
- GPS 內置
- microSD 卡錄音
- IPX7 防水
- 優秀嘅接收性能

**缺點**：

- 價格高
- 體積較大

### 建伍 TH-D75A

**價格**：約 HK$5000-6000

**優點**：

- 支持 D-STAR 同 APRS
- 三頻段（144/220/430 MHz）
- 內置 TNC
- GPS 內置
- 頻譜顯示
- IF 輸出功能

**缺點**：

- 價格最高
- 體積同重量較大

## 配件建議

### 必備配件

1. **升級天線**：原裝天線通常效能一般，一支好嘅天線可以大幅改善信號
   - 推薦：Nagoya NA-771、Diamond SRH-770S
2. **備用電池**：至少一塊備用電池
3. **編程線**：用電腦設定頻道效率更高

### 建議配件

4. **手咪 / 耳機**：方便操作
2. **車充線**：喺車上充電或供電
3. **皮套 / 保護殼**：保護電台
4. **SMA 轉接頭**：連接外部天線

## 使用建議

### 延長電池壽命

- 唔使嗰陣關機或者用慳電模式
- 避免長時間高功率發射
- 使用低功率就足夠嗰陣就用低功率
- 定期充放電，保持電池健康

### 提升通信效果

- 盡量喺空曠、高處使用
- 天線保持垂直
- 換一支好嘅天線比增加功率更有效
- 喺室內操作時靠近窗邊

### 保養

- 避免跌落同碰撞
- 唔好喺雨中使用非防水機型
- 定期清潔接頭
- 避免高溫環境
