# SDR 軟件定義無線電

軟件定義無線電（Software Defined Radio，SDR）係一種用軟件嚟實現傳統硬件功能嘅無線電技術。SDR 將接收到嘅無線電信號數碼化，然後用電腦軟件進行處理，呢種方式帶嚟咗極大嘅靈活性同可擴展性。

## SDR 嘅基本原理

傳統無線電接收機用硬件電路（濾波器、混頻器、解調器等）嚟處理信號。SDR 嘅做法唔同：

```text
天線 → 放大器 → ADC（模數轉換器） → 電腦軟件處理
```

核心思路：盡早將模擬信號轉換成數碼信號，然後用軟件完成所有嘅信號處理工作。

### SDR 嘅優勢

- **極寬嘅頻率覆蓋**：一個設備可以覆蓋好寬嘅頻率範圍
- **軟件可升級**：唔使更換硬件，只需更新軟件就可以獲得新功能
- **瀑布圖顯示**：直覺地睇到頻譜上嘅信號
- **同時解碼多個信號**：頻寬夠嘅話可以同時監聽多個頻率
- **錄製同回放**：可以錄製 IQ 數據，之後再分析

## 僅接收嘅 SDR 設備

呢啲設備只可以接收信號，唔可以發射，非常適合入門同學習。

### RTL-SDR（V3 / V4）

**價格**：約 HK$50-200

**頻率範圍**：24 MHz - 1.7 GHz（V3），500 kHz - 1.7 GHz（V4）

**優點**：

- 價格極低，入門首選
- USB 供電，即插即用
- 社群龐大，教學資源極豐富
- 可以接收航空、氣象衛星、業餘無線電等
- V4 版本改進咗 HF 接收能力

**缺點**：

- 動態範圍有限
- 8 bit ADC，精度較低
- 帶寬約 2.4 MHz
- 容易被強信號飽和

**適合**：零基礎入門、收聽航空通信、接收氣象衛星圖片、學習信號分析

### Airspy HF+ Discovery

**價格**：約 HK$1500-2000

**頻率範圍**：0.5 kHz - 31 MHz，60 - 260 MHz

**優點**：

- HF 接收性能極佳
- 高動態範圍
- 低底噪
- 體積細小

**缺點**：

- 帶寬較窄（768 kHz）
- 只覆蓋 HF 同部分 VHF

**適合**：認真嘅 HF 短波收聽者、業餘無線電監聽

### SDRplay RSPdx

**價格**：約 HK$1500-2000

**頻率範圍**：1 kHz - 2 GHz

**優點**：

- 頻率覆蓋極寬
- 14 bit ADC
- 三個天線輸入
- 帶寬達 10 MHz
- 配套軟件 SDRuno 功能豐富

**缺點**：

- 價格較高
- SDRuno 只支持 Windows

**適合**：想要一步到位嘅認真玩家

## 收發一體嘅 SDR 電台

呢啲設備可以發射同接收，係真正嘅業餘無線電收發機。

### ADALM-PLUTO（PlutoSDR）

**價格**：約 HK$800-1500

**頻率範圍**：325 MHz - 3.8 GHz（可改裝擴展）

**優點**：

- 可以發射（最大約 10 dBm）
- 支持全雙工
- 開源硬件
- 教育同實驗用途

**缺點**：

- 發射功率極低
- 主要用於學習同實驗

### HackRF One

**價格**：約 HK$1500-2500

**頻率範圍**：1 MHz - 6 GHz

**優點**：

- 超寬頻率覆蓋
- 可以發射（半雙工）
- 開源硬件同軟件
- 20 MHz 帶寬

**缺點**：

- 接收靈敏度一般
- 8 bit ADC
- 發射功率低

**適合**：無線電安全研究、信號分析、教育

## SDR 軟件

### SDR#（SDRSharp）

- **平台**：Windows
- **價格**：免費
- **特點**：介面簡潔，適合入門，支持 RTL-SDR
- **下載**：[airspy.com](https://airspy.com/download/)

### SDR++

- **平台**：Windows / Linux / macOS
- **價格**：開源免費
- **特點**：跨平台，支持多種 SDR 硬件，介面現代
- **下載**：[GitHub](https://github.com/AlexandreRouworourou/SDRPlusPlus)

### GQRX

- **平台**：Linux / macOS
- **價格**：開源免費
- **特點**：基於 GNU Radio，功能強大

### CubicSDR

- **平台**：Windows / Linux / macOS
- **價格**：開源免費
- **特點**：跨平台，介面簡潔

### SDRuno

- **平台**：Windows
- **價格**：免費（SDRplay 設備配套）
- **特點**：功能全面，專為 SDRplay 優化

## SDR 嘅實際應用

### 1. 業餘無線電監聽

用 SDR 配合寬頻天線，可以同時監視一大段頻譜，發現有趣嘅信號。

### 2. 航空通信接收

接收 118-136 MHz 嘅航空通話，追蹤飛機動態。

### 3. 氣象衛星圖片接收

接收 NOAA 同 Meteor-M 氣象衛星嘅圖片信號（137 MHz 附近）。

### 4. ADS-B 飛機追蹤

接收 1090 MHz 嘅 ADS-B 信號，配合 dump1090 等軟件，可以追蹤附近嘅飛機。

### 5. 業餘衛星通信

監聽同操作業餘衛星（配合發射設備）。

### 6. 數碼信號解碼

解碼 DMR、P25、TETRA 等數碼信號（僅接收）。

### 7. 學習同教育

直覺地了解無線電信號嘅調制方式、頻譜特性等。

## 入門建議

如果你從未接觸過 SDR，建議：

1. **買一支 RTL-SDR V4**：花一百幾十蚊就可以開始
2. **安裝 SDR# 或 SDR++**：跟教學完成基本設定
3. **接收 FM 廣播**：驗證系統正常工作
4. **收聽航空通信**：體驗 SDR 嘅魅力
5. **收聽業餘無線電 2 米頻段**：監聽本地中繼
6. **嘗試接收氣象衛星**：挑戰一下，好有滿足感
7. **如果想深入**：升級到更好嘅 SDR 設備

::: tip 天線好重要
SDR 嘅性能好大程度上取決於天線。RTL-SDR 附送嘅小天線效果有限。如果你想獲得更好嘅接收效果，建議自己製作或者購買合適嘅天線。一支簡單嘅偶極天線就可以大幅改善接收效果。
:::
