# 車機選購指南

車機（Mobile Radio）係安裝喺車上或者用作基地台嘅無線電收發機。相比手持機，車機擁有更大嘅功率、更好嘅接收性能同更方便嘅操作介面。

## 車機 vs 手持機

| 特性 | 車機 | 手持機 |
|------|------|--------|
| 功率 | 25-75W | 1-8W |
| 接收靈敏度 | 較好 | 一般 |
| 音質 | 較好（外置喇叭） | 一般 |
| 操作方便度 | 較高（大旋鈕、按鍵） | 一般 |
| 便攜性 | 需要固定安裝 | 隨身攜帶 |
| 天線 | 可接外部高效天線 | 原裝短天線 |
| 電源 | 車載 12V 或外部電源 | 內置電池 |

## 車機安裝

### 安裝位置

車機喺車上嘅安裝位置要考慮：

1. **方便操作**：司機可以安全地操作
2. **唔好阻擋視線**：安全駕駛第一
3. **散熱良好**：車機高功率發射時會發熱
4. **避免陽光直射**：保護屏幕同電子元件

常見安裝位置：

- 中控台下方
- 排檔桿旁邊
- 座椅下方（主機），面板分離安裝

### 電源連接

::: warning 重要
車機一定要直接連接到汽車電池，唔好接喺點煙器或者其他車內電源插座上面。原因：

- 車機高功率發射時電流需求大（可達 10-15A）
- 點煙器嘅保險絲可能頂唔住
- 直接接電池可以減少電噪音干擾
:::

接線步驟：

1. 將隨機附送嘅電源線嘅正極（紅色）接到電池正極
2. 負極（黑色）接到電池負極或者車身接地點
3. 確保保險絲安裝正確
4. 電線要固定好，避免同引擎或者排氣管接觸

### 天線安裝

車載天線嘅選擇同安裝方式：

| 安裝方式 | 優點 | 缺點 |
|----------|------|------|
| 磁吸座天線 | 唔使打孔，可以隨時拆除 | 接地效果較差 |
| 車頂鑽孔天線 | 效能最佳，接地良好 | 需要喺車頂打孔 |
| 後尾箱夾式 | 免打孔，效果尚可 | 接地效果一般 |
| 玻璃貼天線 | 完全唔影響外觀 | 效果最差 |

推薦車載天線：

- **Diamond NR-770H**：雙頻段，性能優秀
- **Comet SB-2**：雙頻段磁吸座天線
- **Nagoya NL-R2**：經濟實惠

## 車機作為基地台使用

如果你唔打算裝喺車上，車機亦可以作為家用基地台：

1. **電源供應**：需要一個 13.8V 直流電源供應器（至少 20A 額定電流）
2. **天線**：連接室外天線效果最好
3. **優點**：比手持機功率大、接收好、操作方便
4. **成本**：車機 + 電源 + 天線嘅總成本通常比專用基地台低

推薦電源供應器：

- MeanWell 13.8V 開關電源（30A）
- Diamond GZV-4000（線性電源，噪音低）
- Alinco DM-330MV

## 選購建議

### 新手推薦

如果你係第一次買車機，建議選擇**八重洲 FTM-6000R** 或者 **ICOM IC-2730A**，原因：

- 品質可靠
- 操作簡單
- 功率充足
- 價格合理

### 如果想玩數碼模式

選擇 **八重洲 FTM-300DR**（C4FM）或者帶 D-STAR 功能嘅 ICOM 型號。

### 如果預算有限

由中國品牌嘅車機入手，配合好嘅天線，效果都唔錯。
