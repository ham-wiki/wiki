# 術語表

業餘無線電涉及大量嘅專業術語同縮寫。呢份術語表整理咗最常用嘅詞彙，方便查閱。

| 術語 | 英文 | 解釋 |
|------|------|------|
| 安培 | Ampere (A) | 電流單位 |

| AMBE | Advanced Multi-Band Excitation | 數碼語音編碼技術，用於 DMR/D-STAR |

| AMS | Automatic Mode Select | 自動模式選擇（C4FM 功能） |
