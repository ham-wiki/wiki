# 書籍與資源

## 學習建議

### 入門階段
- 先睇一本入門書建立整體概念
- 配合題庫 App 準備考試
- 加入本地社群，同有經驗嘅火腿交流

### 進階階段
- 針對你感興趣嘅領域深入閱讀
- 參考英文原版資料獲取最新資訊
- 動手實踐，邊做邊學

### 持續學習
- 訂閱相關嘅 YouTube 頻道同 Podcast
- 參加研討會同講座
- 閱讀最新嘅技術文章
