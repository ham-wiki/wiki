# 業餘無線電競賽

業餘無線電競賽（Contest）係一種喺限定時間內盡可能多咁同其他電台建立通聯嘅比賽活動。競賽係提升操作技巧、測試設備性能同享受通信樂趣嘅絕佳方式。

## 競賽嘅基本概念

### 點樣計分

大部分競賽嘅計分公式：

**總分 = QSO 點數 × 乘數**

- **QSO 點數**：每個有效通聯獲得嘅基本分數
- **乘數（Multiplier）**：通聯到唔同嘅國家、地區、CQ Zone 等可以獲得乘數

### 參賽類別

| 類別 | 說明 |
|------|------|
| Single Operator (SO) | 一個人操作 |
| Single Operator Assisted (SOA) | 一個人操作，可用 DX Cluster |
| Multi-Operator Single TX (MS) | 多人輪流操作一部電台 |
| Multi-Operator Multi TX (MM) | 多人多部電台 |
| QRP | 低功率（≤5W） |
| Low Power | 中功率（≤100W） |
| High Power | 高功率（≤1500W） |

### 交換訊息（Exchange）

每次通聯需要交換嘅訊息因競賽而異，常見嘅包括：
- 信號報告 + CQ Zone（CQ WW）
- 信號報告 + ITU Zone（CQ WPX）
- 信號報告 + 序號（通用）
- 信號報告 + 州/省（國內競賽）

## 主要國際競賽

### CQ World Wide DX Contest (CQ WW)

- **類型**：最大型嘅國際 HF 競賽
- **時間**：每年 10 月（SSB）同 11 月（CW）嘅最後一個完整週末
- **時長**：48 小時
- **頻段**：160/80/40/20/15/10 米
- **交換訊息**：信號報告 + CQ Zone 編號
- **乘數**：唔同嘅 DXCC 實體 + CQ Zone

### CQ WPX Contest

- **時間**：每年 3 月（SSB）同 5 月（CW）
- **時長**：48 小時
- **交換訊息**：信號報告 + 序號
- **乘數**：唔同嘅呼號前綴

### ARRL DX Contest

- **時間**：每年 2 月（CW）同 3 月（SSB）
- **時長**：48 小時
- **特點**：美國/加拿大 vs 世界其他地方

### IARU HF World Championship

- **時間**：每年 7 月
- **時長**：24 小時
- **特點**：有 IARU 總部電台可以通聯

### ARRL Sweepstakes

- **時間**：每年 11 月
- **特點**：北美地區競賽

## 競賽操作技巧

### 準備工作

1. **設備檢查**：確保電台、天線、電腦系統全部正常
2. **軟件設定**：安裝並設定好競賽日誌軟件
3. **天線方向**：了解目標區域嘅方向
4. **休息計劃**：48 小時嘅競賽需要規劃休息時間

### CQ 呼叫（Running）

```
「CQ Contest, VR2XYZ」
（等待回覆）
「BH4ABC, 59 24」（信號報告 + CQ Zone）
（聽取對方報告）
「Thanks, QRZ VR2XYZ」（繼續下一個）
```

### 搜索呼叫（Search and Pounce / S&P）

- 喺頻段上慢慢調諧，搵到正在 CQ 嘅電台
- 等待佢哋嘅 CQ 結束後呼叫
- 適合新手同低功率電台

### 效率提升

- **用耳機**：減少外界干擾
- **用鍵盤**：利用軟件預設嘅快捷訊息
- **雙 VFO**：一邊 CQ 一邊搜索
- **頻段切換**：喺唔同頻段之間切換，利用傳播窗口

## 入門建議

### 第一次參加競賽

1. **揀一個大型競賽**：例如 CQ WW，參加者多，容易搵到人通聯
2. **用 S&P 模式**：搜索同回覆比 CQ 呼叫容易
3. **唔好追求成績**：第一次嘅目標係享受過程同學習
4. **設定合理嘅時間**：唔使參加全程 48 小時，幾個小時都可以
5. **提交日誌**：即使只有幾個 QSO，都建議提交日誌

### VHF/UHF 競賽

如果你仲未有 HF 設備，亦有 VHF/UHF 競賽可以參加：
- ARRL VHF Contest
- 各地區嘅 VHF/UHF 競賽
- 操作同 HF 競賽類似，但使用唔同嘅頻段

## 競賽成績同獎狀

- 大部分競賽會公佈排名同結果
- 提交日誌後通常會收到成績報告
- 表現優秀可以獲得證書或者獎狀
- 有啲競賽有專門嘅亞洲區排名
