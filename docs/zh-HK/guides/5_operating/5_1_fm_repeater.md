# FM 中繼操作

FM 中繼器（Repeater）操作係大部分業餘無線電愛好者最常用嘅通信方式。中繼器安裝喺高處（山頂、大廈頂層等），可以大幅擴展手持機同車機嘅通信範圍。

## 中繼器嘅工作原理

中繼器同時接收同發射，將收到嘅信號即時轉發出去：

```
電台A → (發射到中繼器輸入頻率) → 中繼器 → (喺輸出頻率轉發) → 電台B
```

中繼器使用兩個唔同嘅頻率：
- **輸入頻率**：電台發射到中繼器嘅頻率
- **輸出頻率**：中繼器轉發信號嘅頻率

兩者之間嘅差叫做**頻差（Offset）**。

### 常見頻差

| 頻段 | 標準頻差 |
|------|----------|
| 2 米（144 MHz） | ±0.6 MHz |
| 70 厘米（430 MHz） | ±5 MHz |

## 中繼器嘅設定

要使用中繼器，你嘅電台需要設定以下參數：

1. **接收頻率**：設定為中繼器嘅輸出頻率
2. **頻差方向**：正偏移（+）或負偏移（-）
3. **頻差量**：通常 0.6 MHz（2米）或 5 MHz（70厘米）
4. **CTCSS / DCS 碼**：大部分中繼器需要亞音碼先可以接入

### CTCSS（亞音頻碼）

Continuous Tone-Coded Squelch System 係一種喺音頻信號中加入低頻音調嘅技術：
- 頻率範圍：67.0 Hz - 254.1 Hz
- 人耳聽唔到（低於語音頻率範圍）
- 中繼器只會轉發帶有正確 CTCSS 碼嘅信號
- 可以防止其他信號誤觸發中繼器

### DCS（數碼碼）

Digital-Coded Squelch 係 CTCSS 嘅數碼版本：
- 使用數碼編碼代替音調
- 可用碼更多
- 抗干擾能力更強

## 中繼器操作流程

### 呼叫另一位火腿

```
你：「VR2ABC，VR2ABC，呢度 VR2XYZ 呼叫，收到請回覆。」
    （鬆開 PTT，等待回覆）

對方：「VR2XYZ，呢度 VR2ABC，收到你。信號五九。」

你：「VR2ABC，多謝回覆。我喺九龍，使用手持機。有咩可以幫到你？」
    ……正常對話……

結束：「好啦，73，VR2XYZ clear。」
對方：「73，VR2ABC clear。」
```

### CQ 呼叫（一般呼叫）

當你想同任何人通話：
```
「CQ CQ CQ，呢度 VR2XYZ，Victor Romeo Two X-ray Yankee Zulu，
喺（中繼器名稱）呼叫，有冇人收到？」
```

### 加入正在進行嘅對話

1. 等待一方發射完畢
2. 喺兩人對話嘅間隙中報出你嘅呼號
3. 例如：「VR2XYZ」
4. 對方會邀請你加入對話

::: tip 中繼器尾巴
好多中繼器喺有人發射後會發出一個短促嘅「嘟」聲（稱為 courtesy tone 或者中繼器尾巴）。等到呢個聲響完先開始發射，可以避免同其他人衝突。
:::

## 操作禮儀

### 應該做嘅
- 每次發射都報呼號
- 等中繼器嘅 courtesy tone 後先發射
- 每次發射保持簡短（唔好一次講太耐）
- 定期停頓，俾其他人插入嘅機會
- 對新手友善、耐心

### 唔應該做嘅
- 唔好霸佔中繼器長時間通話（如果有其他人想用）
- 唔好播放音樂或者錄音
- 唔好討論敏感或者冒犯性嘅話題
- 唔好故意干擾其他人嘅通信
- 唔好喺冇呼號嘅情況下發射

## Kerchunk 同測試

### 咩係 Kerchunk？
Kerchunk 係指短暫按下 PTT 鍵嚟測試自己是否可以觸發中繼器，但唔報呼號。呢個行為喺好多地方被認為係唔禮貌嘅，而且喺某啲地區係違規嘅。

### 正確嘅測試方法
```
「VR2XYZ 測試中。」
或者
「VR2XYZ 調試設備。」
```
簡單、合法、禮貌。

## 中繼器禮儀同緊急情況

如果你聽到有人喺中繼器上發出求救信號：
1. 停止你嘅通信
2. 記錄求救者嘅呼號、位置同情況
3. 如果你可以幫助，回覆佢
4. 如果需要，協助聯繫緊急服務
5. 其他電台應該保持頻率暢通

## 香港嘅中繼器

香港有多個業餘無線電中繼器，覆蓋大部分地區。常見嘅中繼器位置包括：

- 大帽山
- 飛鵝山
- 太平山
- 其他山頂位置

要搵到最新嘅中繼器列表同頻率資訊，可以：
- 查詢 HARTS 嘅網站
- 使用 RepeaterBook 應用程式
- 向本地火腿查詢

## 常見問題

### 我可以聽到中繼器但觸發唔到佢
- 檢查 CTCSS/DCS 碼係咪正確
- 檢查頻差方向（+/-）同頻差量
- 增加發射功率
- 更換更好嘅天線
- 移動到更開闊嘅位置

### 信號斷斷續續
- 你可能處於中繼器覆蓋嘅邊緣
- 試下移動位置
- 提高天線高度
- 用車機代替手持機

### 我可以收到兩個唔同嘅中繼器
- 可能有頻率重疊嘅中繼器
- 用 CTCSS 碼區分
- 調整靜噪級別
