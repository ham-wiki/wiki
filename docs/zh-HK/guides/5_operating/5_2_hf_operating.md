# 短波操作入門

短波（HF）操作係業餘無線電最令人興奮嘅領域之一。透過電離層反射，你可以用一部電台同一支天線，同幾千公里甚至上萬公里以外嘅火腿通話。

## HF 操作嘅基本模式

### SSB（單邊帶）語音

SSB 係 HF 語音通信嘅主流模式：

- **LSB（下邊帶）**：7 MHz 以下使用
- **USB（上邊帶）**：7 MHz 以上使用
- 帶寬約 2.4 kHz
- 需要仔細調諧先聽得清楚

### CW（摩斯電碼）

- 帶寬極窄（100-500 Hz）
- 喺弱信號條件下效果最好
- 需要學習摩斯電碼
- 好多老火腿最鍾意嘅模式

### 數碼模式

- FT8：目前最流行嘅 HF 數碼模式
- FT4：比 FT8 更快
- PSK31：鍵盤對鍵盤嘅文字通信
- RTTY：電傳打字機模式

## SSB 操作技巧

### 調諧

SSB 唔似 FM 咁自動鎖定頻率，需要手動微調：

1. 旋轉 VFO 旋鈕直到語音聽起來自然
2. 太高 → 向低頻方向調
3. 太低 → 向高頻方向調
4. 「鴨仔聲」= 調諧唔準確

### CQ 呼叫

當你想搵人通聯：

```
「CQ CQ CQ，this is Bravo Hotel Four X-ray Yankee Zulu，
BH4XYZ calling CQ and listening.」
```

或者用中文：

```
「CQ CQ CQ，呢度 BH4XYZ，Bravo Hotel Four X-ray Yankee Zulu，
CQ 呼叫，收到請回覆。」
```

重複幾次，然後停下嚟聽。

### 回覆 CQ

如果你聽到有人 CQ：

```
「VR2ABC，呢度 VR2XYZ，Victor Romeo Two X-ray Yankee Zulu。」
```

### 標準 QSO（通聯）流程

1. **交換呼號**
2. **信號報告**：用 RS 系統（Readability 1-5, Strength 1-9）
3. **基本資訊**：名字、QTH（位置）、設備、天線
4. **告別**：73（祝好運）

### 範例 QSO

```
A：「CQ CQ，呢度 BH4ABC 呼叫 CQ。」
B：「BH4ABC，呢度 VR2XYZ。」
A：「VR2XYZ，多謝回覆！你嘅信號 59，我喺上海，用 IC-7300 同偶極天線。Over。」
B：「BH4ABC，你嘅信號都係 59。我喺香港，用 FT-991A 同垂直天線。」
A：「收到。好靚嘅信號！73，BH4ABC clear。」
B：「73，VR2XYZ clear。」
```

## DX（遠距離）操作

DX 係指同遠方嘅電台建立通聯，通常指唔同國家或者大洲。

### DX 操作禮儀

- **簡潔**：DX QSO 通常好短，只交換呼號同信號報告
- **耐心**：DX 電台可能有好多人同時呼叫
- **準確**：確保你聽清楚對方嘅呼號先回覆
- **唔好重複呼叫**：呼叫一兩次後停下嚟聽

### Split 操作

好多 DX 電台使用 Split 模式：

- DX 電台喺一個頻率發射（例如 14.195 MHz）
- 佢聽另一個頻率或者頻率範圍（例如 14.200-14.210 MHz）
- 你需要將 VFO-B 設定到佢嘅接收範圍

### DX Cluster

DX Cluster 係一個實時報告 DX 電台嘅網絡系統：

- 顯示邊啲 DX 電台正在活動
- 提供頻率、模式同信號報告
- 可以透過網頁或者軟件訪問
- 常用網站：dxheat.com、dxsummit.fi

## 傳播條件判斷

HF 傳播受太陽活動影響好大，了解傳播條件可以幫你揀選最佳嘅頻段同時間。

### 太陽參數

| 參數 | 意義 | 好嘅值 |
|------|------|--------|
| SFI（太陽通量指數） | 太陽活動水平 | > 100 = 高頻段開放 |
| SSN（太陽黑子數） | 太陽黑子活動 | 越高越好（對高頻段） |
| K 指數 | 地磁擾動 | < 3 = 穩定 |
| A 指數 | 地磁擾動（日均） | < 10 = 穩定 |

### 各頻段嘅最佳操作時間

| 頻段 | 日間 | 夜間 | 備註 |
|------|------|------|------|
| 80 米 | 較差 | 好 | 夜間近距離通信 |
| 40 米 | 好 | 好 | 全天候可用 |
| 20 米 | 最好 | 差至中等 | DX 黃金頻段 |
| 15 米 | 好 | 差 | 需要較高 SFI |
| 10 米 | 好（高 SFI） | 差 | 太陽活動高峰才開放 |

### 傳播預測工具

- **VOACAP**：HF 傳播預測
- **PSKReporter**：實時報告 FT8 等數碼模式嘅傳播情況
- **DX Heat**：實時 DX spot 同傳播資訊

## 信號報告系統

### RS 系統（語音）

| R（可讀性） | 意義 |
|------------|------|
| R1 | 唔可以讀取 |
| R2 | 偶爾讀到幾個字 |
| R3 | 困難但可以讀取 |
| R4 | 基本可以讀取 |
| R5 | 完全清楚 |

| S（信號強度） | 意義 |
|--------------|------|
| S1 | 極弱 |
| S3 | 弱 |
| S5 | 中等 |
| S7 | 強 |
| S9 | 非常強 |

常見報告：

- **59**：信號完美（最常俾出嘅報告）
- **55**：信號中等，可以正常通話
- **33**：信號弱，勉強可以通話

### RST 系統（CW）

喺 RS 嘅基礎上加一個 T（Tone，音調）值，1-9 級。

## 通聯日誌

保持良好嘅通聯日誌係業餘無線電嘅好習慣。

### 需要記錄嘅資訊

- 日期同 UTC 時間
- 對方呼號
- 頻率 / 頻段
- 模式（SSB / CW / FT8 等）
- 信號報告（發出同收到）
- 備註（名字、QTH 等）

### 日誌軟件

- **Log4OM**：功能豐富，免費
- **N1MM+**：競賽用日誌
- **WSJT-X**：FT8 操作自帶日誌
- **QRZ.com Logbook**：線上日誌

## QSL 卡

QSL 卡係確認通聯嘅傳統方式：

### 實體 QSL 卡

- 設計同印製屬於自己嘅 QSL 卡
- 透過 QSL Bureau 交換
- 直接郵寄（Direct QSL）

### 電子 QSL

- **eQSL.cc**：免費嘅電子 QSL 系統
- **Logbook of the World（LoTW）**：ARRL 嘅官方電子日誌
- **QRZ.com**：線上日誌同 QSL 確認

## 獎狀追逐

好多火腿以收集各種通信獎狀為樂趣：

- **DXCC**：通聯 100 個或以上唔同嘅國家/地區
- **WAS**：通聯美國全部 50 個州
- **WAC**：通聯六大洲
- **IOTA**：通聯唔同嘅島嶼
