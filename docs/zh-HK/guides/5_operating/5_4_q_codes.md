# Q碼與縮語

Q 碼同各種縮語係業餘無線電通信中嘅「共同語言」，令唔同國家嘅火腿可以快速交流關鍵訊息。

## Q 碼

Q 碼源自早期嘅無線電報通信，每個 Q 碼由三個字母組成，以 Q 開頭。Q 碼可以作為問題（加問號）或者作為回答使用。

### 常用 Q 碼

| Q 碼 | 問題形式 | 回答 / 陳述形式 |
|------|----------|-----------------|
| QRA | 你嘅電台名稱係咩？ | 我嘅電台名稱係... |
| QRB | 你同我嘅距離有幾遠？ | 我同你嘅距離係... |
| QRG | 你可以話我知準確嘅頻率嗎？ | 你嘅準確頻率係... |
| QRH | 我嘅頻率有變動嗎？ | 你嘅頻率有變動 |
| QRI | 我嘅音調點樣？ | 你嘅音調係...（1=好 2=可變 3=差） |
| QRK | 我嘅信號可讀性點樣？ | 你嘅信號可讀性係...（1-5） |
| QRL | 呢個頻率有人用緊嗎？ | 係，呢個頻率有人用緊 |
| QRM | 你有冇受到人為干擾？ | 我受到人為干擾（1-5 級） |
| QRN | 你有冇受到天電干擾？ | 我受到天電干擾（1-5 級） |
| QRO | 我需要增加功率嗎？ | 請增加功率 |
| QRP | 我需要降低功率嗎？ | 請降低功率 / 低功率操作 |
| QRQ | 我需要加快發送速度嗎？ | 請加快速度 |
| QRS | 我需要減慢發送速度嗎？ | 請減慢速度 |
| QRT | 我需要停止發射嗎？ | 請停止發射 / 我即將關機 |
| QRU | 你有冇訊息俾我？ | 我冇訊息俾你 |
| QRV | 你準備好未？ | 我準備好喇 |
| QRX | 你幾時會再呼叫我？ | 我會喺...時間再呼叫你 |
| QRZ | 邊個喺呼叫我？ | 你被...呼叫 |
| QSB | 我嘅信號有衰落嗎？ | 你嘅信號有衰落 |
| QSL | 你可以確認收到嗎？ | 我確認收到 |
| QSO | 你可以直接通信嗎？ | 我可以直接通信 / 一次通聯 |
| QST | — | 致全體（廣播訊息） |
| QSY | 我需要轉到其他頻率嗎？ | 請轉到...頻率 |
| QTH | 你嘅位置喺邊度？ | 我嘅位置喺... |
| QTR | 準確時間係幾多？ | 準確時間係... |

### 最常用嘅 Q 碼

喺日常通信中，以下 Q 碼最常用到：

- **QTH**：位置（「我嘅 QTH 喺香港九龍」）
- **QSO**：一次通聯（「今日做咗幾個 QSO」）
- **QSL**：確認（「QSL，收到」）
- **QRZ**：邊個喺叫我？
- **QSY**：轉頻（「QSY 到 145.500」）
- **QRP**：低功率操作
- **QRM**：人為干擾
- **QRN**：自然干擾
- **QRT**：關機（「我要 QRT 喇」）
- **QRV**：準備好（「我 QRV 喺 20 米」）

## 常用縮語

### 數字縮語

| 縮語 | 意義 |
|------|------|
| 73 | 祝好運 / 再見（最常用嘅告別語） |
| 88 | 愛與親吻（通常對女性操作員使用） |
| 33 | 友情（通常喺 YL 之間使用） |
| 55 | 好運（用於競賽） |

::: tip 73 定係 73s？
嚴格嚟講，73 本身已經係複數形式，所以「73s」係重複嘅。但喺實際使用中，好多人都會講「73s」，呢個已經被廣泛接受。
:::

## 使用建議

1. **唔使全部記住**：慢慢學，常用嘅自然就會記得
2. **多聽多用**：聽其他火腿點樣使用呢啲縮語
3. **唔好過度使用**：日常通話中唔使每句都用 Q 碼，自然就好
4. **確認理解**：如果對方用咗你唔明白嘅縮語，唔使怕問
5. **文化差異**：唔同地區嘅火腿可能有唔同嘅習慣用語
