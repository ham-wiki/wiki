# 泉盛 UV-K5 韌體刷寫

泉盛 UV-K5 係近年最受歡迎嘅入門級手持機之一，最大嘅原因係佢嘅韌體可以被第三方替換，將一部百幾蚊嘅電台變成功能豐富嘅多功能工具。

## 點解要刷韌體

UV-K5 嘅硬件能力其實好強，但原廠韌體只開放咗一小部分功能。透過刷第三方韌體，你可以獲得：

- **頻譜分析儀**：直覺地睇到附近嘅信號
- **AM 接收**：接收航空頻段通話
- **SSB 接收**（部分韌體）：接收短波 SSB 信號
- **更多頻率範圍**：擴展接收範圍
- **改進嘅操作介面**：更好嘅頻道顯示同操作邏輯
- **NOAA 氣象頻道**：接收氣象廣播
- **自定義開機畫面**
- **改進嘅掃描功能**

## 準備工作

### 你需要嘅硬件

1. **泉盛 UV-K5**（或 UV-K5(8)、UV-K6）
2. **USB 編程線**：UV-K5 專用嘅 USB-C 或者 Kenwood 2-pin 編程線
3. **電腦**：Windows / macOS / Linux

### 你需要嘅軟件

1. **韌體文件**：由 GitHub 下載
2. **刷寫工具**：
   - **k5prog-win**（Windows 命令行工具）
   - **UV-K5 Firmware Flash Tool**（圖形介面工具）
   - **Web Flasher**（瀏覽器在線刷寫，最方便）

### 編程線驅動

- 大部分 UV-K5 編程線使用 CH340 或者 CP2102 晶片
- Windows 通常會自動安裝驅動
- 如果唔識別，需要手動安裝對應嘅驅動程式

## 常見第三方韌體

### Egzumer 韌體（推薦）

呢個係目前最受歡迎、功能最豐富嘅第三方韌體。

**主要功能**：

- 頻譜分析儀
- AM 修復（改善 AM 接收質素）
- 頻率範圍擴展（18 MHz - 1300 MHz 接收）
- 改進嘅掃描功能
- S-Meter 信號強度顯示
- 電池電壓顯示
- 更多可自定義嘅功能鍵

**下載**：[github.com/egzumer/uv-k5-firmware-custom](https://github.com/egzumer/uv-k5-firmware-custom)

### FAGCI（Tunas1629）韌體

**特點**：

- 強大嘅頻譜分析功能
- 記憶體管理改進
- 獨特嘅操作介面

### UV-K5 CEC 韌體

**特點**：

- 中文介面
- 針對中國用家優化
- 功能實用

## 刷寫步驟（Web Flasher 方法）

呢個係最簡單嘅刷寫方法，唔需要安裝任何軟件。

### 步驟 1：備份原廠韌體

**呢個步驟好重要，一定要做！**

1. 將 UV-K5 關機
2. 用編程線連接 UV-K5 同電腦
3. 打開瀏覽器（建議 Chrome 或 Edge）
4. 訪問 Web Flasher 網站
5. 選擇「Read from radio」
6. 按住 UV-K5 嘅 PTT 鍵同時開機（進入刷寫模式）
7. 喺瀏覽器中選擇對應嘅串口
8. 等待讀取完成
9. 將備份文件保存好

### 步驟 2：下載韌體

1. 去 GitHub 下載你想要嘅韌體 .bin 文件
2. 確認韌體版本同你嘅硬件兼容

### 步驟 3：刷寫韌體

1. UV-K5 保持喺刷寫模式（PTT + 開機）
2. 喺 Web Flasher 中選擇「Flash firmware」
3. 選擇下載好嘅 .bin 文件
4. 點擊開始刷寫
5. 等待刷寫完成（通常需要 1-2 分鐘）
6. 完成後重啟電台

### 步驟 4：驗證

1. 開機確認韌體版本
2. 測試基本功能（發射、接收、掃描等）
3. 設定你需要嘅功能

## 刷寫步驟（命令行方法）

如果你偏好命令行：

```bash
# Windows 使用 k5prog
k5prog.exe -r backup.bin          # 備份
k5prog.exe -f firmware.bin        # 刷寫韌體

# Linux 使用 uvk5tool
python3 uvk5tool.py -p /dev/ttyUSB0 -r backup.bin    # 備份
python3 uvk5tool.py -p /dev/ttyUSB0 -f firmware.bin   # 刷寫
```

## 刷韌體後嘅設定

### 頻譜分析儀使用

- 長按 F 鍵（或者指定嘅功能鍵）進入頻譜模式
- 用上下鍵調整中心頻率
- 用左右鍵調整掃描範圍
- 呢個功能喺搵信號同檢查頻譜佔用情況時非常有用

### AM 航空接收

- 切換到 AM 模式
- 輸入航空頻率（118-136 MHz）
- 調整靜噪級別

## 常見問題

### 刷寫失敗點算？

- 唔好慌張，通常可以重新嘗試
- 確認編程線連接穩固
- 確認進入咗刷寫模式（PTT + 開機）
- 嘗試唔同嘅 USB 端口
- 如果完全無法恢復，可以用備份嘅原廠韌體重新刷入

### 刷完韌體後頻道冇咗？

- 韌體更新可能會清除頻道記憶
- 建議刷韌體前先用 CHIRP 備份頻道
- 刷完後重新編程

### 點解我嘅 UV-K5 接收唔到某啲頻率？

- 確認韌體支持該頻率範圍
- UV-K5 嘅硬件喺某啲頻段嘅靈敏度天生較低
- 唔係所有頻率都有良好嘅接收效果

### 刷咗第三方韌體會唔會影響發射？

- 合法嘅第三方韌體通常唔會改變發射特性
- 但係部分韌體可能擴展咗發射頻率範圍
- 請確保只喺合法嘅業餘頻段上發射

::: warning 法律提醒
擴展咗嘅發射頻率範圍僅限接收用途。喺未經授權嘅頻率上發射係違法行為，可能會干擾其他通信服務。請務必遵守當地嘅無線電法規。
:::
