# 車機改裝

車機嘅改裝主要集中喺頻率擴展、功能增強同安裝優化方面。呢篇文章介紹常見嘅車機改裝項目。

## 頻率擴展（MARS/CAP Mod）

好多車機出廠時將發射頻率限制喺業餘頻段內，但硬件上其實可以覆蓋更寬嘅範圍。頻率擴展改裝可以解除呢個限制。

::: warning 法律提醒
頻率擴展後，你仍然只可以喺持有執照嘅業餘頻段上發射。喺其他頻率上發射係違法行為。呢個改裝嘅合法用途包括：

- 允許接收更寬嘅頻率範圍
- 喺美國，MARS/CAP 授權人員可以喺擴展頻率上操作
:::

### 八重洲 FTM-6000R 頻率擴展

**方法**：軟件重置法

1. 關機
2. 按住特定嘅按鍵組合同時開機
3. 選擇擴展模式
4. 重新啟動

（具體按鍵組合因韌體版本而異，請查閱相關論壇嘅最新資訊。）

### 八重洲 FTM-300DR 頻率擴展

**方法**：通常透過按鍵組合或者軟件設定

### ICOM 車機

ICOM 嘅車機通常需要修改電路板上嘅跳線或者移除特定嘅二極管嚟進行頻率擴展。

**一般步驟**：

1. 拆開車機外殼
2. 搵到控制頻率範圍嘅跳線 / 二極管位置
3. 根據文檔切斷或者添加跳線
4. 重新組裝
5. 進行全面重置

::: tip 查詢改裝資訊
每個型號嘅具體改裝方法都唔同。建議搜索 "型號名 + MARS mod" 或者 "型號名 + frequency expansion" 嚟搵到對應嘅改裝指南。mods.dk 係一個好有用嘅資源網站。
:::

## 接收前端改善

### 添加外部帶通濾波器

喺車機嘅天線輸入端加裝帶通濾波器，可以：

- 減少帶外強信號嘅干擾
- 降低互調失真
- 改善喺強信號環境（例如城市）中嘅接收質素

推薦：

- 腔體帶通濾波器（Cavity Filter）：效果最好但體積大
- 陶瓷帶通濾波器：體積細，適合車載

### 添加低噪放大器（LNA）

喺接收端加裝 LNA 可以改善弱信號嘅接收：

- 適合長距離通信
- 需要喺發射時自動切換
- 過度放大可能導致互調問題

## 音頻改裝

### 外部喇叭

大部分車機都有外部喇叭接口：

- 安裝喺車內方便聽到嘅位置
- 選擇大功率喇叭改善音質
- 防水喇叭適合開窗或者安裝喺車外

推薦：

- Diamond P-810：通信專用外部喇叭
- 任何 8Ω / 5-10W 嘅喇叭都可以

### 藍牙適配器

部分車機支持藍牙配件，或者可以加裝第三方藍牙適配器：

- 藍牙耳機方便駕駛時使用
- 藍牙 PTT 遙控器

## 電源優化

### 濾波器

車載環境嘅電源噪音可能好嚴重。添加電源濾波器可以：

- 減少引擎點火噪音
- 降低交流發電機嘅紋波干擾
- 改善接收靈敏度

**方法**：

1. 喺電源線上串聯鐵氧體磁珠
2. 加裝 DC 電源濾波器
3. 確保接地點良好

### 獨立電源線

如果之前唔係直接接到電池：

- 重新佈線，由電池直接供電
- 使用粗線材（至少 12AWG）
- 安裝合適嘅保險絲（距離電池 30cm 內）

## 天線系統優化

### 安裝位置改善

如果你嘅車載天線安裝位置唔理想：

- **最佳位置**：車頂正中央
- **次佳位置**：車頂邊緣
- **可接受**：後尾箱蓋
- **盡量避免**：車身側面、保險桿

### 同軸電纜升級

- 將 RG-58 升級到 RG-8 Mini 或者 LMR-240
- 更換接頭（由 PL-259 改為 N 型）
- 縮短電纜長度減少損耗

### 雙頻天線

如果你嘅車機係雙頻段：

- 使用雙頻段天線（唔使裝兩支天線）
- Diamond NR-770H 或者 Comet SB-2

## 散熱改善

車機長時間高功率發射會發熱：

1. **安裝位置通風**：確保車機周圍有足夠嘅空氣流通
2. **外部風扇**：喺車機上方或者後方加裝細型風扇
3. **散熱墊**：喺車機底部加裝散熱墊
4. **降低功率**：如果唔需要最大功率，用中功率操作可以大幅減少發熱

## 操作介面改善

### 外部顯示器

部分車機支持分離式面板：

- 將面板安裝喺方便觀察嘅位置
- 主機可以放喺座位下方或者後尾箱

### 外接按鍵 / 旋鈕

- 部分車機可以連接外部控制器
- 方便喺駕駛時操作

## 數碼模式添加

如果你嘅車機唔支持數碼模式，可以透過外部設備添加：

### 外接 TNC

- 連接 TNC（終端節點控制器）可以使用 APRS
- Mobilinkd TNC4 係一個便攜嘅藍牙 TNC

### 外接 DVAP / HotSpot

- 連接一個 MMDVM HotSpot 可以使用 DMR、D-STAR、C4FM
- 透過車機嘅 FM 功能操作數碼模式

## 改裝前嘅建議

1. **做好研究**：每個型號嘅改裝方法都唔同，先搜集足夠嘅資訊
2. **備份設定**：改裝前備份車機嘅所有設定
3. **拍照記錄**：拆機過程中拍照，方便復原
4. **逐步進行**：一次只做一個改裝，完成後測試再進行下一個
5. **工具準備**：確保你有合適嘅工具
6. **評估風險**：考慮改裝失敗嘅後果同復原嘅可能性
