# 寶鋒電台改裝

寶鋒（Baofeng）UV-5R 系列係全球銷量最大嘅業餘無線電手持機。雖然價格極低，但透過一啲簡單嘅改裝同優化，可以改善佢嘅使用體驗。

## UV-5R 常見改裝

### 1. 天線升級

呢個係最簡單同最有效嘅「改裝」——更換一支更好嘅天線。

**原裝天線嘅問題**：

- 效率低
- 增益差
- 匹配唔理想

**推薦更換**：

- Nagoya NA-771：39cm，增益約 2.15 dBi，性價比最高
- Diamond SRH-770S：伸縮式，方便收納
- 自製 J-Pole 或者 Slim Jim 天線

::: tip 注意接頭類型
寶鋒 UV-5R 使用 SMA-F（母頭）天線接口，同大部分其他品牌（SMA-M 公頭）相反。購買天線時要確認接頭類型，或者準備一個轉接頭。
:::

### 2. 電池升級

原裝電池容量偏細（通常 1800mAh），可以考慮：

- **大容量電池**：3800mAh 加長電池，續航大幅提升
- **電池消除器**：連接外部電源（車載 12V 或者移動電源）
- **AA 電池盒**：用普通 AA 電池供電，應急時有用

### 3. 手咪 / 耳機

加裝外部手咪或耳機可以改善操作體驗：

- **手咪**：方便車載或者固定操作
- **喉震式耳機**：戶外活動時解放雙手
- **空氣導管耳機**：較為隱蔽
- **藍牙 PTT**：無線操作（需要藍牙適配器）

### 4. 頻率擴展

部分 UV-5R 可以透過軟件操作擴展接收頻率範圍：

**方法**：透過 CHIRP 或者原廠編程軟件修改頻率限制設定。

::: warning 注意
頻率擴展後嘅額外頻率僅供接收用途。喺業餘頻段以外發射係違法嘅。UV-5R 喺非設計頻段上嘅接收性能可能較差。
:::

### 5. 音質改善

UV-5R 嘅音質一般，可以嘗試以下改善方法：

**軟件方面**：

- 調整 CHIRP 中嘅音頻設定
- 適當調整靜噪（Squelch）級別

**硬件方面**：

- 更換喇叭（需要拆機）
- 加裝外部喇叭

### 6. 防水改裝

UV-5R 本身唔防水，如果需要喺戶外使用：

- **防水袋**：最簡單嘅方案，透明防水袋可以保護電台
- **矽膠密封**：用矽膠密封電台嘅縫隙（唔建議新手嘗試）
- **防水殼**：部分廠商有出售專用防水殼

## UV-82 系列改裝

UV-82 係 UV-5R 嘅升級版，操作介面更好，功率更大。

### 與 UV-5R 嘅主要分別

- 雙 PTT 鍵設計
- 功率最高 8W（UV-82HP）
- 接收靈敏度略好
- 改裝方法同 UV-5R 大致相同

## UV-9R 系列（防水版）

UV-9R 系列係寶鋒嘅防水手持機：

- IP67 防水等級
- 唔需要額外嘅防水改裝
- 天線接頭同 UV-5R 唔同，配件唔通用

## 軟件改裝

### 透過 CHIRP 優化設定

1. **頻道管理**：整理同備份頻道列表
2. **功能設定**：開啟 / 關閉各種功能
3. **優化掃描**：設定掃描範圍同速度
4. **CTCSS/DCS 設定**：正確設定亞音頻碼

詳細嘅 CHIRP 使用方法請參考 [CHIRP 編程指南](./4_4_chirp_programming.md)。

### 命名頻道

為常用頻道設定易記嘅名稱，例如：

- `RPTR-1` — 中繼器 1
- `CALL-2M` — 2 米呼叫頻率
- `WX-HK` — 天氣頻道

## 硬件改裝注意事項

如果你打算進行硬件級別嘅改裝：

### 需要嘅工具

- 十字螺絲批（小號）
- 電烙鐵同焊錫
- 鑷子
- 萬用表
- 放大鏡或者顯微鏡

### 安全注意

- 拆機前移除電池
- 小心靜電放電（ESD）損壞電路
- 記錄拆機過程，方便重新組裝
- 細小嘅螺絲要妥善保管

### 常見嘅硬件改裝

- 更換喇叭
- 添加接收前端濾波器
- 修改 TX/RX 切換電路

::: danger 高風險操作
以下操作可能導致設備永久損壞，唔建議新手嘗試：

- 修改 PA（功率放大器）電路
- 更改 PLL（鎖相環）參數
- 繞過頻率限制硬件
:::

## 實際使用建議

與其花太多時間改裝寶鋒，不如考慮以下策略：

1. **天線升級**係投入產出比最高嘅改裝
2. **電池升級**排第二
3. **用 CHIRP 做好頻道管理**排第三
4. 如果你發現自己需要更多功能，可能係時候考慮升級到更好嘅電台（例如泉盛 UV-K5 或者八重洲嘅入門機型）
5. 寶鋒嘅優勢喺於價格，壞咗唔心痛，適合作為備用機或者實驗用途
