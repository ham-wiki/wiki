# CHIRP 編程指南

CHIRP 係一個免費、開源嘅電台編程軟件，支持超過 300 款唔同品牌同型號嘅業餘無線電設備。用 CHIRP 管理電台頻道比手動逐個輸入快得多，而且可以輕鬆備份同複製設定。

## 下載同安裝

### 下載地址

- 官方網站：[chirpmyradio.com](https://chirpmyradio.com)
- 建議下載最新嘅 CHIRP-next 版本（Python 3 版本）

### 系統要求

- **Windows**：Windows 10 或以上
- **macOS**：10.14 或以上
- **Linux**：支持大部分主流發行版

### 安裝步驟

**Windows**：

1. 下載 .msi 安裝程式
2. 雙擊安裝
3. 按提示完成安裝

**macOS**：

1. 下載 .dmg 文件
2. 拖動到 Applications 文件夾

**Linux**：

```bash
# 使用 pip 安裝
pip3 install chirp

# 或者使用 flatpak
flatpak install flathub com.danplanet.chirp
```

### 驅動程式安裝

大部分編程線使用以下晶片之一：

- **CH340/CH341**：需要安裝 CH340 驅動
- **CP2102**：需要安裝 Silicon Labs CP210x 驅動
- **PL2303**：需要安裝 Prolific PL2303 驅動
- **FTDI**：通常系統自帶驅動

建議喺連接編程線之前先安裝好驅動。

## 基本操作流程

### 1. 連接電台

1. 用編程線連接電台同電腦
2. 確保電台已開機
3. 部分電台需要進入特定模式

### 2. 由電台讀取資料

1. 喺 CHIRP 中選擇 `Radio` → `Download from radio`
2. 選擇正確嘅串口（COM Port）
3. 選擇電台型號（如果軟件無法自動識別）
4. 選擇正確嘅波特率（通常自動偵測）
5. 點擊 `OK` 開始讀取

::: tip 找不到串口？

- Windows：喺裝置管理員中查看「端口（COM 和 LPT）」
- macOS：串口通常顯示為 `/dev/tty.usbserial-XXXX`
- Linux：通常係 `/dev/ttyUSB0` 或 `/dev/ttyACM0`
:::

### 3. 編輯頻道

讀取成功後，你會見到一個表格，每行代表一個頻道。主要嘅欄位包括：

| 欄位 | 說明 | 例子 |
|------|------|------|
| Loc | 頻道編號 | 0, 1, 2... |
| Name | 頻道名稱 | RPTR-VR2 |
| Frequency | 接收頻率 | 145.0000 |
| Duplex | 雙工方向 | +, -, off |
| Offset | 頻差 | 0.600000 |
| Tone | 亞音類型 | Tone, DTCS |
| rToneFreq | 發射亞音頻率 | 88.5 |
| cToneFreq | 接收亞音頻率 | 88.5 |
| Mode | 模式 | FM, NFM |
| TStep | 調諧步進 | 12.50, 25.00 |
| Power | 功率 | High, Low |

### 4. 設定中繼器頻道

以一個典型嘅 VHF 中繼器為例：

| 設定項 | 值 | 說明 |
|--------|-----|------|
| Frequency | 145.7500 | 中繼器嘅輸出頻率（你嘅接收頻率） |
| Duplex | - | 負偏移 |
| Offset | 0.6000 | 頻差 0.6 MHz |
| Tone | Tone | 只發送亞音 |
| rToneFreq | 88.5 | 中繼器要求嘅 CTCSS 碼 |
| Name | RPT-XXX | 中繼器名稱 |

呢個設定意味住：

- 接收：145.7500 MHz
- 發射：145.7500 - 0.600 = 145.1500 MHz
- 發射時附帶 88.5 Hz 嘅 CTCSS 碼

### 5. 寫入電台

1. 檢查所有設定無誤
2. 選擇 `Radio` → `Upload to radio`
3. 確認串口同型號
4. 點擊 `OK` 開始寫入
5. 等待完成

## 進階功能

### 導入 / 導出 CSV

你可以將頻道列表導出成 CSV 文件，用 Excel 或者其他試算表軟件編輯，然後再導入。

- `File` → `Export` → 選擇 CSV 格式
- `File` → `Import` → 選擇 CSV 文件

### 由 RepeaterBook 導入

CHIRP 可以直接由 RepeaterBook 數據庫搜索同導入中繼器資訊：

1. `Radio` → `Import from data source` → `RepeaterBook`
2. 選擇國家同地區
3. 設定搜索條件（頻段、距離等）
4. 選擇想要嘅中繼器
5. 導入到頻道列表

### 複製頻道到另一部電台

1. 由源電台讀取頻道
2. 選擇想要複製嘅頻道行
3. 複製（Ctrl+C）
4. 開啟目標電台嘅標籤
5. 貼上（Ctrl+V）

## 常見電台嘅 CHIRP 設定

### 寶鋒 UV-5R

- 編程線：Kenwood 2-pin 類型
- 波特率：9600
- 讀寫速度較慢，需要耐心

### 泉盛 UV-K5

- 編程線：USB-C（部分型號）或 Kenwood 2-pin
- 建議使用 CHIRP-next 版本
- 部分第三方韌體可能需要特定版本嘅 CHIRP

### 八重洲 FT-65R

- 需要原裝編程線或者兼容嘅第三方線
- CHIRP 支持良好

### ICOM 電台

- 通常需要 ICOM 專用嘅 CI-V 編程介面
- 部分型號可以用 USB 直接連接

## 頻道規劃建議

良好嘅頻道組織可以令你喺緊急時快速搵到需要嘅頻率。

### 建議嘅頻道分組

```text
0-9     ：常用頻率同呼叫頻率
10-29   ：本地中繼器
30-49   ：鄰近地區中繼器
50-69   ：數碼模式頻率
70-89   ：掃描用頻率
90-99   ：天氣 / 應急頻率
100+    ：其他
```

### 命名規範建議

- 用統一嘅命名格式
- 頻道名稱有長度限制（通常 6-8 個字符）
- 例如：`R-城市名`（中繼器）、`S-頻段`（單工）

## 常見問題

### CHIRP 識別唔到我嘅電台

1. 檢查編程線同驅動
2. 確認電台已開機
3. 嘗試唔同嘅串口
4. 確認電台型號喺 CHIRP 嘅支持列表中

### 寫入後電台行為異常

1. 恢復出廠設定
2. 由電台重新讀取
3. 檢查有冇設定咗唔兼容嘅參數

### 頻道名稱顯示亂碼

- 某啲電台唔支持中文字符
- 使用英文同數字命名
- 檢查字符編碼設定
