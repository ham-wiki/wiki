## 改裝注意事項

::: warning 重要提醒
1. **法規遵守**：改裝後嘅電台仍然需要遵守當地嘅無線電管理法規，特別係頻率限制同功率限制
2. **保固失效**：大部分改裝都會導致設備嘅保養失效
3. **風險自負**：刷韌體或者硬件改裝有可能導致設備損壞（變磚）
4. **安全第一**：涉及電路修改嗰陣要注意安全，特別係高壓部分
5. **先備份**：喺任何改裝之前，先備份原廠設定同韌體
:::

## 點解要改裝

- **擴展功能**：解鎖設備本身具有但被軟件限制嘅功能
- **改善性能**：優化接收靈敏度、音質等
- **個性化**：自定義操作介面同功能
- **學習**：透過改裝深入了解無線電設備嘅工作原理
- **樂趣**：動手嘅過程本身就係業餘無線電嘅一部分
