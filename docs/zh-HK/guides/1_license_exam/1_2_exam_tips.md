# 備考攻略

無論你準備考 CRAC A 類定係 B 類，又或者係其他地區嘅執照考試，呢度有一套經過驗證嘅備考方法幫你高效通過考試。

## CRAC A 類備考攻略

### 備考時間表

A 類考試題庫大約有 370 題左右，建議嘅備考計劃：

| 階段 | 時間 | 內容 |
|------|------|------|
| 第一階段 | 第 1-3 日 | 通讀一遍基礎教材，建立整體概念 |
| 第二階段 | 第 4-7 日 | 開始刷題庫，記錄錯題 |
| 第三階段 | 第 8-10 日 | 重點複習錯題，強化薄弱環節 |
| 第四階段 | 第 11-14 日 | 模擬考試，確保穩定通過 |

### 重點知識領域

#### 法規部分（必考，佔比最大）

呢部分唔可以靠猜，需要認真記住：

- **業餘無線電管理辦法**嘅核心條款
- 各類操作證可以使用嘅頻率同功率限制
- 違規操作嘅處罰
- 業餘無線電通信嘅基本原則（唔可以用於商業通信、唔可以發送加密訊息等）
- 干擾處理同投訴流程

::: tip 記憶技巧
法規題目有固定嘅答案，可以整理成表格對比記憶。例如：A 類 25W / B 類 100W / C 類 1000W，呢啲數字要記牢。
:::

#### 電子學基礎

需要掌握嘅公式：

- **歐姆定律**：V = I × R（電壓 = 電流 × 電阻）
- **功率公式**：P = V × I = I² × R = V² / R
- **頻率同波長**：λ = c / f（波長 = 光速 / 頻率）
- **串聯電阻**：R_total = R1 + R2 + R3
- **並聯電阻**：1/R_total = 1/R1 + 1/R2 + 1/R3
- **分貝計算**：功率加倍 = +3dB，功率十倍 = +10dB

#### 無線電通信

- FM、AM、SSB 嘅區別同應用場景
- VHF/UHF 嘅傳播特性
- 天線嘅基本概念（極化、增益、SWR）
- 中繼器嘅工作原理

#### 操作實務

- 標準通信程序
- 常用 Q 碼（QTH、QSL、QRM、QRN 等）
- 呼號字母解釋法（Alpha、Bravo、Charlie...）
- 信號報告（RS/RST 系統）

## CRAC B 類備考攻略

### 備考時間表

B 類題庫約 700 題，建議準備時間較長：

| 階段 | 時間 | 內容 |
|------|------|------|
| 第一階段 | 第 1-7 日 | 系統學習教材，重點掌握新增理論 |
| 第二階段 | 第 8-21 日 | 分類刷題，每日 50-100 題 |
| 第三階段 | 第 22-28 日 | 錯題複習，針對薄弱環節加強 |
| 第四階段 | 第 29-35 日 | 模擬考試，穩定喺 45 分以上 |

### B 類額外需要掌握嘅內容

- **交流電路**：電容同電感喺交流電路中嘅表現、諧振電路
- **發射機原理**：振盪器、混頻器、功率放大器
- **接收機原理**：超外差接收機、靈敏度、選擇性
- **天線理論**：偶極天線、八木天線、天線增益計算
- **傳播理論**：電離層結構、MUF（最高可用頻率）、太陽黑子影響
- **電磁兼容**：干擾類型、濾波方法

## 刷題工具推薦

1. **業餘無線電考試**（Android / iOS）
   - 收錄完整 CRAC 題庫
   - 支持分類練習同模擬考試
   - 自動記錄錯題

2. **HAM考試助手**
   - 介面簡潔
   - 支持離線使用
   - 有解析說明

### 線上平台

- CRAC 官方網站提供嘅題庫
- 各地業餘無線電協會嘅學習資源

### 自製工具

如果你鍾意動手，可以將題庫導出成 Anki 卡片，利用間隔重複法（Spaced Repetition）提高記憶效率。

## 考試技巧

### 答題策略

1. **先易後難**：先做有把握嘅題目，再處理唔確定嘅
2. **排除法**：如果唔確定答案，先排除明顯錯誤嘅選項
3. **注意關鍵詞**：「必須」、「唔可以」、「所有」、「任何」呢啲詞語往往係題目嘅關鍵
4. **計算題唔好跳過**：呢啲題目嘅分數同其他題一樣，用公式一步步算就得

### 容易出錯嘅地方

- **頻率同波長搞混**：記住佢哋係反比關係
- **功率限制記錯**：A 類 25W、B 類 100W，呢個好容易搞混
- **法規細節**：例如哪啲情況可以例外，哪啲係絕對唔可以嘅
- **單位轉換**：MHz 同 kHz、W 同 dBm 之間嘅轉換

## 考試日注意事項

### 考試前

- 確認考試時間同地點
- 帶齊身份證（最重要！）
- 提前到達，熟悉環境
- 充足休息，唔好臨時抱佛腳

### 考試中

- 仔細閱讀每一道題目
- 唔好喺一道題上面花太多時間
- 做完之後檢查一遍
- 注意時間分配

### 考試後

- 大部分考場即時出成績
- 通過後記得跟進後續嘅設台申請流程
- 如果未通過，分析錯題原因，準備下一次

## 心態調整

- A 類考試真係唔難，只要你認真準備，通過率係好高嘅
- 唔好因為緊張而影響發揮
- 記住：考試只係開始，真正嘅學習係喺取得執照之後
- 即使第一次未通過，通常好快就可以再考
