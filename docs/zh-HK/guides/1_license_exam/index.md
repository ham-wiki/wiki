# 考試與執照

業餘無線電執照係合法操作業餘電台嘅必要條件。呢個章節涵蓋中國 CRAC 考試、香港 OFCA 牌照同國際執照嘅相關資訊。

- [備考攻略](./1_2_exam_tips.md) — 高效備考嘅方法同技巧
- [國際執照](./1_3_international_licenses.md) — 香港 OFCA、美國 FCC 同其他國際執照資訊

## 為咩要考執照

1. **法律要求**：未經許可發射無線電信號係違法行為
2. **安全保障**：確保操作者了解基本嘅安全知識
3. **技術能力**：證明你具備操作電台嘅基礎知識
4. **頻率管理**：有效管理有限嘅頻譜資源
5. **國際互認**：部分執照可以喺其他國家使用

## 考試通用建議

無論你準備考邊個地區嘅執照，以下建議都適用：

- 先睇一遍完整嘅教材，建立整體概念
- 重點掌握法規部分，因為呢啲知識喺實際操作中經常用到
- 利用題庫 App 進行反覆練習
- 加入備考群組，同其他考生交流
- 唔好只係死記答案，理解原理先係長遠之計
