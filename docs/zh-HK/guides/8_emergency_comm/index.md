# 應急通信

業餘無線電喺應急通信中扮演住重要嘅角色。當自然災害、大規模停電或者其他緊急情況導致電話網絡同互聯網癱瘓嗰陣，業餘無線電往往係最後仍然可以運作嘅通信手段。

## 點解業餘無線電適合應急通信

1. **獨立性**：唔依賴基站、光纖或者互聯網基礎設施
2. **靈活性**：可以快速部署，喺任何地方操作
3. **覆蓋範圍**：由本地到全球都可以通信
4. **冗餘性**：多頻段、多模式提供通信冗餘
5. **低功耗**：可以用電池長時間運作
6. **訓練有素**：業餘無線電愛好者經過考試，具備基本嘅通信技能

## 歷史案例

業餘無線電喺以下事件中發揮咗重要作用：
- **2008年 四川大地震**：業餘無線電成為早期災區通信嘅重要渠道
- **2011年 日本東北大地震**：業餘無線電提供咗關鍵嘅通信支援
- **2017年 颶風瑪利亞**：波多黎各嘅通信基礎設施幾乎全毀，業餘無線電成為生命線
- **多次颱風**：香港同華南地區嘅颱風期間，業餘無線電提供咗輔助通信

## 香港嘅應急通信

香港面對嘅主要自然災害風險包括颱風、暴雨同山泥傾瀉。雖然香港嘅通信基礎設施好發達，但喺極端情況下仍然可能出現通信中斷。

香港嘅業餘無線電愛好者可以透過以下方式參與應急通信：
- 加入 HARTS 嘅應急通信小組
- 參加應急通信演練
- 保持個人嘅應急通信裝備處於備用狀態
