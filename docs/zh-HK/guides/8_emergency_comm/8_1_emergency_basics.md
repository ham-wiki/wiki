# 應急通信基礎

應急通信（Emergency Communications，簡稱 EmComm）係業餘無線電最重要嘅社會功能之一。呢篇文章介紹應急通信嘅基本原則、方法同注意事項。

## 應急通信嘅基本原則

### 1. 通信紀律
- 保持頻率暢通，唔好閒聊
- 訊息要簡短、準確、完整
- 嚴格遵守通信程序
- 服從網絡控制站（Net Control）嘅指揮

### 2. 準備充分
- 設備隨時保持可用狀態
- 定期檢查電池同裝備
- 熟悉應急通信程序
- 參加演練

### 3. 自給自足
- 唔好成為災區嘅負擔
- 自備食物、食水同個人用品
- 自備電力（電池、太陽能板）
- 能夠獨立運作至少 72 小時

### 4. 安全第一
- 你自己嘅安全最重要
- 唔好進入危險區域
- 了解基本嘅急救知識
- 同隊友保持聯繫

## 應急通信嘅類型

### 戰術通信（Tactical Communications）
- 現場嘅短距離通信
- 通常使用 VHF/UHF FM
- 支援搜救、疏散同現場協調
- 需要快速部署

### 消息處理（Message Traffic）
- 正式格式嘅消息傳遞
- 類似電報嘅結構化通信
- 用於準確傳遞重要訊息
- 可能需要 HF 網絡進行長距離傳送

### 健康與福利訊息（Health and Welfare）
- 災民同親友之間嘅聯繫
- 透過業餘無線電網絡轉發
- 災害後嘅重要服務

## 應急通信模式

### FM 中繼（本地）
- 最常用嘅應急通信方式
- 利用本地中繼器擴展覆蓋
- 簡單、可靠
- 大部分火腿都有 FM 設備

### FM 單工（本地）
- 當中繼器失效時使用
- 直接電台對電台通信
- 需要更高嘅功率或者更好嘅天線

### HF SSB / CW（長距離）
- 跨區域甚至跨國嘅應急通信
- 唔依賴任何基礎設施
- 需要 B 類或以上執照

### Winlink（電子郵件）
- 透過 HF 或者 VHF 發送電子郵件
- 可以傳送附件（表格、圖片）
- 適合傳送結構化嘅訊息
- 被好多應急管理機構採用

### APRS（位置同狀態）
- 實時追蹤人員同車輛位置
- 發送簡短嘅狀態訊息
- 喺應急協調中好有用

### DMR / D-STAR / C4FM
- 數碼模式可以透過互聯網（如果可用）連接遠方
- 但係依賴互聯網嘅部分唔適合基礎設施全毀嘅情況
- 本地 DMR 中繼仍然有用

## 應急通信程序

### 通信網（Net）

應急通信通常以「網」（Net）嘅形式組織：

#### Net Control Station（NCS / 網控站）
- 負責控制整個通信網
- 管理頻率使用
- 記錄所有通信
- 協調訊息傳遞

#### 基本網絡程序

```
NCS：「注意，呢度係 VR2XYZ，擔任淨控站。
      呢個係[災害名稱]應急通信網。
      請有需要報告嘅電台報到。」

電台A：「VR2XYZ，呢度 VR2ABC，有緊急訊息。」

NCS：「VR2ABC，請報告。」

電台A：「[報告內容]，VR2ABC。」

NCS：「收到，VR2ABC。其他電台請待命。」
```

### 訊息優先級

| 優先級 | 說明 | 例子 |
|--------|------|------|
| 緊急（Emergency） | 涉及生命安全 | 求救、傷亡報告 |
| 優先（Priority） | 重要但唔即時危及生命 | 重要物資需求 |
| 福利（Welfare） | 健康同福利訊息 | 平安報告 |
| 常規（Routine） | 一般行政訊息 | 後勤安排 |

### 標準訊息格式

正式嘅應急訊息通常包括以下部分：

1. **前言（Preamble）**：訊息編號、優先級、處理說明
2. **收信人（Addressee）**：訊息嘅接收者
3. **正文（Text）**：訊息內容
4. **簽名（Signature）**：發送者

## 應急通信演練

### 點解要參加演練

- 熟悉應急程序
- 測試設備同天線
- 發現同修正問題
- 建立同其他火腿嘅聯繫
- 真正嘅緊急情況唔係學習嘅時候

### 常見嘅演練活動

- **Simulated Emergency Test (SET)**：ARRL 每年舉辦嘅模擬應急測試
- **Field Day**：喺戶外用臨時設備進行操作
- **本地演練**：各地業餘無線電會組織嘅演練

## 同專業機構合作

### ARES / RACES（美國制度）
- **ARES**（Amateur Radio Emergency Service）：ARRL 嘅應急通信服務
- **RACES**（Radio Amateur Civil Emergency Service）：聯邦政府嘅業餘無線電應急服務

### 香港
- 業餘無線電愛好者可以同民安處、紅十字會等機構合作
- HARTS 同其他本地組織可能有應急通信安排

### 注意事項
- 了解你同專業機構之間嘅角色同責任
- 唔好自行進入災區，除非被授權
- 遵從專業救援人員嘅指示
- 業餘無線電操作員嘅角色係提供通信支援，唔係救援

## 特殊情況下嘅通信

### 停電時
- 用電池或者太陽能板供電
- 降低功率以延長電池壽命
- 優先使用 FM 手持機

### 通信基礎設施全毀
- HF 可能係唯一嘅長距離通信方式
- 本地使用 VHF/UHF 單工
- APRS 可以配合 GPS 進行位置報告

### 颱風期間
- 留喺安全嘅室內
- 監聽本地中繼器嘅應急通信
- 如果有需要，報告你嘅位置同狀態
- 留意官方嘅天氣同災害資訊
