# 應急通信背包

應急通信背包（Go Bag）係一個隨時準備好、可以即刻出發嘅應急通信裝備包。當緊急情況發生嗰陣，你可以拎起呢個包就走，無需臨時收拾。

## Go Bag 嘅設計原則

### 1. 即刻出發

- 所有裝備已經準備好、測試過
- 電池已充滿
- 頻道已編好
- 拎起就可以行

### 2. 自給自足

- 至少可以獨立運作 24-72 小時
- 自備電力
- 自備個人物資

### 3. 模組化

- 根據唔同嘅任務需求可以增減裝備
- 分成通信模組、電力模組、個人模組

### 4. 輕便

- 你需要能夠背住行一段距離
- 控制總重量喺合理範圍（建議 < 15 kg）

## 通信裝備清單

### 核心通信設備

| 項目 | 建議 | 備註 |
|------|------|------|
| 手持機（主） | 雙頻 VHF/UHF | 最重要嘅設備 |
| 手持機（備用） | 另一部手持機 | 冗餘，以防主機故障 |
| 升級天線 | Nagoya NA-771 等 | 改善手持機嘅通信距離 |
| 備用電池 | 至少 2-3 塊 | 已充滿電 |
| 手咪/耳機 | 喉震式或者空氣導管 | 解放雙手 |
| 編程線 | USB 編程線 | 可能需要臨時修改頻道 |

### 延伸通信設備（視情況）

| 項目 | 建議 | 備註 |
|------|------|------|
| 便攜天線 | 捲繞式 J-Pole 或者 Slim Jim | 掛喺樹上大幅提升性能 |
| 便攜 HF 電台 | Xiegu G90 / Elecraft KX2 | 長距離通信（需 B 類執照） |
| HF 天線 | EFHW 隨線天線 | 配合 HF 電台使用 |
| 同軸電纜 | 短截 RG-58（已裝好接頭） | 連接外部天線 |

### 電力供應

| 項目 | 建議 | 備註 |
|------|------|------|
| 備用電池 | 手持機專用電池 × 3 | 保持充滿 |
| AA/AAA 電池 | 充電式 + 一次性各一套 | 萬用備用 |
| 行動電源 | 10000-20000mAh | 為手機同電台充電 |
| LiFePO4 電池 | 4.5-12Ah 12V | HF 電台供電 |
| 太陽能板 | 20-50W 折疊式 | 長時間部署嘅電力補充 |
| 充電線材 | USB-C、Micro-USB、車充 | 各種設備嘅充電線 |

### 工具同配件

| 項目 | 用途 |
|------|------|
| 多功能工具（Leatherman 等） | 緊急維修 |
| 電工膠帶 | 固定、修補 |
| 束線帶 | 固定天線同電纜 |
| 傘繩 / 尼龍繩 | 懸掛天線 |
| SMA 轉接頭 | 唔同接頭嘅轉換 |
| NanoVNA 或者 SWR 計 | 天線測試（可選） |
| 筆同防水筆記本 | 記錄通信日誌 |
| 頻率列表 | 印刷嘅本地中繼器同應急頻率列表 |

## 個人物資清單

### 必需品

| 項目 | 備註 |
|------|------|
| 水 | 至少 2 升 |
| 能量食品 | 能量棒、乾糧 |
| 急救包 | 基本嘅創傷處理 |
| 藥物 | 個人常備藥物 |
| 身份證明 | 身份證、執照副本 |
| 現金 | 細額紙幣同硬幣 |
| 手電筒 | 頭燈最方便 |
| 雨衣 / 風褸 | 防風防雨 |
| 哨子 | 求救用 |

### 建議額外攜帶

| 項目 | 備註 |
|------|------|
| 手機同充電器 | 通信備用 |
| 多用途刀 | 工具 |
| 保暖毯（太空毯） | 輕便保暖 |
| 口罩 | 防塵、衛生 |
| 手套 | 保護雙手 |
| 地圖 | 紙質地圖，唔依賴手機 |

## Go Bag 嘅組織方式

### 建議用色碼分區

- **紅色袋**：通信核心設備
- **黃色袋**：電力供應
- **藍色袋**：工具同配件
- **綠色袋**：個人物資
- **透明袋**：文件同頻率列表

### 背包選擇

- **容量**：30-45 升
- **舒適度**：有腰帶同胸帶嘅款式
- **防水性**：至少係防潑水，或者額外加防雨罩
- **耐用性**：選擇堅固嘅材料
- **口袋**：多個口袋方便分類

推薦品牌：5.11、Mystery Ranch、Osprey、各類軍事背包

## 維護同檢查

### 每月檢查

- [ ] 所有電池充滿電
- [ ] 電台開機測試
- [ ] 頻道列表係最新嘅
- [ ] 食品同水未過期
- [ ] 藥物未過期

### 每季檢查

- [ ] 全面測試所有設備
- [ ] 更新頻率列表
- [ ] 補充或更換消耗品
- [ ] 檢查背包同袋嘅狀態
- [ ] 更新個人物資

### 每年檢查

- [ ] 評估整體裝備組合
- [ ] 考慮升級或者更換設備
- [ ] 參加至少一次應急演練
- [ ] 更新應急聯絡資訊

## 不同級別嘅 Go Bag

### Level 1：基本隨身包

適合日常攜帶或者短時間嘅應急響應。

**重量**：約 3-5 kg

包含：

- 一部手持機 + 備用電池
- 升級天線
- 行動電源
- 耳機
- 基本急救用品
- 頻率列表

### Level 2：標準應急包

適合 24-48 小時嘅應急部署。

**重量**：約 8-12 kg

Level 1 嘅所有嘢加上：

- 備用手持機
- 便攜天線
- 更多電池
- 太陽能板
- 工具包
- 完整嘅個人物資

### Level 3：長期部署包

適合 72 小時以上嘅應急部署。

**重量**：約 12-18 kg

Level 2 嘅所有嘢加上：

- HF 便攜電台
- HF 天線
- LiFePO4 電池
- 更大嘅太陽能板
- 更多食水同食品
- 睡袋 / 保暖裝備

## 實用建議

1. **練習使用**：唔好等到緊急情況先拎出嚟用，定期用你嘅 Go Bag 裝備做便攜操作
2. **保持輕便**：你要能夠背住行幾公里，唔好裝太多嘢
3. **優先級排序**：通信能力 > 電力供應 > 個人物資
4. **標籤清楚**：每樣嘢都清楚標記，喺壓力下都可以快速搵到
5. **放喺容易攞到嘅地方**：唔好放喺雜物房嘅最深處
6. **家人知道**：確保家人知道你嘅 Go Bag 喺邊度，同埋你嘅應急計劃
7. **持續改進**：每次演練或者使用後都做總結，不斷優化

記住：最好嘅應急裝備係你有、你熟悉、而且你攞得到嘅裝備。一個簡單但你熟練使用嘅 Go Bag，遠好過一個全副武裝但你唔識用嘅裝備包。
