# 天線基礎理論

天線係將電台產生嘅射頻電能轉換成電磁波向空間輻射（發射），或者將空間中嘅電磁波轉換成射頻電能送到接收機（接收）嘅裝置。了解天線嘅基本理論，對於選擇、安裝同調整天線都好有幫助。

## 天線嘅工作原理

當交流電流通過一條導線嗰陣，會喺周圍產生交變嘅電磁場。如果導線嘅長度同電流嘅頻率有特定嘅關係（諧振），電磁波就會有效咁由導線向外輻射。

最基本嘅天線就係一條直導線（偶極子），其長度為工作波長嘅一半。

## 關鍵參數

### 諧振頻率（Resonant Frequency）

天線嘅物理尺寸決定咗佢嘅諧振頻率。喺諧振頻率上，天線嘅阻抗呈純電阻性（無電抗分量），能量傳輸效率最高。

半波偶極天線嘅長度計算：

$$L_{米} = \frac{143}{f_{MHz}}$$

呢個公式已經考慮咗導線嘅速度因子（約 0.95）。

例如：

- 145 MHz（2 米頻段）：L ≈ 143 / 145 ≈ 0.99 米（每臂約 0.49 米）
- 7.1 MHz（40 米頻段）：L ≈ 143 / 7.1 ≈ 20.1 米（每臂約 10 米）

### 阻抗（Impedance）

天線嘅饋點阻抗係一個複數，包含電阻分量同電抗分量。

常見天線嘅饋點阻抗：

| 天線類型 | 典型饋點阻抗 |
|----------|-------------|
| 半波偶極天線 | ~73Ω |
| 四分之一波垂直天線 | ~36Ω |
| 折合偶極天線 | ~300Ω |
| 八木天線 | 20-50Ω（視設計而定） |

業餘無線電系統嘅標準阻抗係 50Ω，所以天線嘅阻抗需要盡量接近 50Ω，或者用匹配網絡進行轉換。

### 增益（Gain）

天線增益表示天線喺特定方向上集中輻射能量嘅能力，相比於參考天線。

- **dBi**：以各向同性天線（理想嘅點輻射源）為參考
- **dBd**：以半波偶極天線為參考
- 關係：dBi = dBd + 2.15

常見天線嘅增益：

| 天線類型 | 增益 |
|----------|------|
| 半波偶極天線 | 2.15 dBi（0 dBd） |
| 四分之一波垂直天線 | ~2 dBi |
| 5/8 波垂直天線 | ~5 dBi |
| 3 元八木天線 | ~8 dBi |
| 10 元八木天線 | ~13 dBi |

::: warning 注意
增益唔係「無中生有」嘅。天線增益嘅本質係將能量集中喺特定方向上，而喺其他方向上嘅輻射就會減少。總輻射功率唔會因為天線增益而增加。
:::

### 方向性（Directivity）

天線嘅輻射方向圖（Radiation Pattern）描述咗天線喺唔同方向上嘅輻射強度分佈。

- **全方向天線**（Omnidirectional）：喺水平面上各方向輻射強度相同，例如垂直天線
- **方向性天線**（Directional）：喺特定方向上輻射集中，例如八木天線
- **主瓣（Main Lobe）**：輻射最強嘅方向
- **旁瓣（Side Lobe）**：主瓣以外嘅次要輻射方向
- **前後比（Front-to-Back Ratio）**：主瓣同背面輻射嘅比值

### 極化（Polarization）

電磁波嘅極化方式取決於天線嘅安裝方向：

- **垂直極化**：天線垂直安裝（如垂直天線）
- **水平極化**：天線水平安裝（如水平偶極天線）
- **圓極化**：用於衛星通信

**極化匹配**好重要：如果發射天線用垂直極化，接收天線都應該用垂直極化。極化唔匹配會導致信號損失約 20dB。

VHF/UHF FM 通信通常用垂直極化，HF SSB 通信通常用水平極化。

### 帶寬（Bandwidth）

天線嘅帶寬係指 SWR 保持喺可接受範圍（通常 2:1 以下）嘅頻率範圍。

影響帶寬嘅因素：

- 天線元件嘅直徑：越粗帶寬越寬
- 天線嘅 Q 值：Q 值越低帶寬越寬
- 天線類型：折合偶極比普通偶極帶寬更寬

### 效率（Efficiency）

天線效率係指實際輻射功率佔輸入功率嘅比例。損失嘅能量會變成熱能。

影響效率嘅因素：

- 導線電阻（特別係喺低頻段）
- 地面損耗
- 匹配網絡損耗
- 周圍環境嘅吸收

## 天線高度嘅影響

天線嘅安裝高度對性能有好大影響：

### VHF/UHF

- 越高越好（視距傳播）
- 每增加一倍高度，通信距離約增加 40%
- 建議至少離地面或者建築物頂部幾米

### HF

- 高度影響輻射角度
- 低角度輻射有利於 DX（遠距離）通信
- 高角度輻射有利於近距離通信
- 一般建議至少半個波長高

## 天線周圍環境

天線嘅性能會受周圍環境影響：

- **金屬結構**：附近嘅金屬物體會改變天線嘅輻射方向圖同阻抗
- **建築物**：會阻擋同反射信號
- **樹木**：喺 VHF/UHF 頻段會吸收信號
- **地面**：地面嘅導電性影響天線嘅輻射方向圖

## 天線安全

### 雷擊防護

- 所有室外天線都應該安裝避雷裝置
- 天線饋線入戶處應該安裝同軸避雷器
- 天線支撐結構要有良好嘅接地
- 雷暴天氣時斷開天線同電台嘅連接

### 結構安全

- 確保天線支撐結構足夠堅固
- 考慮風力同重量嘅影響
- 天線唔好安裝喺人經常行過嘅地方
- 注意附近有冇電力線
