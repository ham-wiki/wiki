# 天線與製作

喺業餘無線電圈有句話：「天線係最好嘅放大器。」一支好嘅天線對通信效果嘅影響遠超過電台本身。呢個章節會介紹天線嘅基礎理論同各種常見天線嘅製作方法。

## 點解天線咁重要

假設你有一部 100W 嘅電台：
- 配一支效率 10% 嘅差天線 → 實際輻射功率只有 10W
- 配一支效率 90% 嘅好天線 → 實際輻射功率有 90W
- 再加上天線增益 6dBi → 等效輻射功率超過 350W

所以，喺天線上面投資嘅回報往往遠高過喺電台上面投資。

## 天線選擇嘅基本考慮

1. **操作頻段**：唔同頻段需要唔同尺寸嘅天線
2. **可用空間**：你有幾多空間嚟安裝天線
3. **安裝條件**：屋頂、陽台、花園定係便攜
4. **預算**：由 DIY 零成本到商業天線幾千蚊都有
5. **方向性需求**：需要全方向覆蓋定係特定方向

## 自製天線嘅樂趣

業餘無線電嘅其中一大樂趣就係自己動手製作天線。好多高效能嘅天線其實結構好簡單，用基本嘅材料同工具就可以製作。自製天線唔單止慳錢，仲可以深入了解天線嘅工作原理。
