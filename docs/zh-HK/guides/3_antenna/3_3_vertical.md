# 垂直天線

垂直天線（Vertical Antenna）係另一種常見嘅業餘無線電天線。相比偶極天線，垂直天線嘅最大優勢係佔地面積細，而且提供全方向（Omnidirectional）嘅水平覆蓋。

## 基本原理

垂直天線最基本嘅形式係四分之一波（1/4 λ）垂直振子，配合地面或者地線系統作為「鏡像」。地面充當咗偶極天線嘅另一半，所以垂直天線有時被稱為「單極天線」（Monopole）。

```text
        |
        |  ← 垂直振子 (1/4 λ)
        |
        |
    ----+---- ← 饋點
   / / | \ \
  地線 / 地線  ← 地線系統（Radials）
```

## 常見類型

### 1/4 波垂直天線

- 振子長度 = 波長 / 4
- 需要地線系統
- 饋點阻抗約 36Ω
- 結構簡單

長度公式：$$L（米）= \frac{71.5}{f_{MHz}}$$

### 5/8 波垂直天線

- 振子長度 = 波長 × 5/8
- 增益比 1/4 波高約 3dB
- 需要匹配網絡
- VHF/UHF 車載天線常用設計

### 半波垂直天線（End-Fed Half-Wave）

- 振子長度 = 波長 / 2
- 唔需要地線系統
- 饋點阻抗好高（數千歐姆），需要匹配變壓器
- 適合空間有限嘅情況

### 多頻段陷波垂直天線（Trap Vertical）

- 喺振子中加入陷波器（LC 諧振電路）
- 一支天線覆蓋多個頻段
- 結構較複雜，帶寬可能較窄

## 地線系統

地線系統對垂直天線嘅性能至關重要。

### 理想地線系統

- 120 條以上嘅地線
- 每條長度 = 1/4 波長
- 均勻分佈喺天線周圍

### 實際妥協方案

- 最少 4 條地線（性能已經可接受）
- 16-32 條地線（良好嘅性能）
- 地線可以貼喺地面上

### 地線數量對效率嘅影響

| 地線數量 | 大約效率 | 接地電阻 |
|----------|----------|----------|
| 4 條 | ~50% | ~35Ω |
| 16 條 | ~70% | ~15Ω |
| 32 條 | ~80% | ~8Ω |
| 64 條 | ~85% | ~5Ω |
| 120 條 | ~90% | ~2Ω |

::: tip 實用建議
對於大部分業餘愛好者，16-32 條地線已經可以提供唔錯嘅效果。與其追求完美嘅地線系統，不如多花啲時間喺天線嘅調整同安裝高度上面。
:::

## DIY 垂直天線教學

### 2 米 / 70 厘米雙頻段垂直天線

呢個係一個簡單嘅 J-Pole 天線設計，用銅管或者 300Ω 雙引線製作。

#### J-Pole 天線（300Ω 饋線版本）

**材料**：

- 300Ω 扁平雙引線（電視天線用嘅那種）約 60cm
- 50Ω 同軸電纜
- SO-239 接頭

**製作**：

1. 取 51cm 嘅 300Ω 雙引線
2. 頂部：兩條導線連接喺一齊（短路）
3. 底部：一邊剪短到 14cm，另一邊保持 51cm
4. 同軸電纜嘅饋點連接喺距離底部短路端約 5cm 嘅位置
5. 中心導體接一邊，屏蔽接另一邊
6. 調整饋點位置令 SWR 最低

### 40 米頻段 1/4 波垂直天線

**材料**：

- 鋁管或者釣魚竿 + 導線，長度約 10 米
- 4-16 條地線，每條約 10 米
- 饋點安裝座
- RG-213 同軸電纜

**製作**：

1. 將 10 米長嘅垂直元件豎起
2. 饋點喺底部
3. 由饋點向外輻射式鋪設地線
4. 同軸電纜中心接垂直元件，屏蔽接地線
5. 調整垂直元件長度令 SWR 最低

## 垂直天線嘅優缺點

### 優點

- 佔地面積細小
- 全方向覆蓋（水平面）
- 垂直極化，適合 VHF/UHF FM 通信
- 低角度輻射，有利於 HF DX 通信
- 安裝相對簡單（只需要一個支撐點）

### 缺點

- 需要良好嘅地線系統（HF 頻段）
- 容易接收到人造噪音（垂直極化噪音較多）
- 增益通常比同尺寸嘅八木天線低
- 無方向性選擇，唔可以避開干擾
- HF 垂直天線可能好高

## 安裝建議

1. **位置選擇**：盡量遠離建築物同金屬結構
2. **地線鋪設**：地線唔需要埋入泥土，貼喺地面上就可以
3. **防水處理**：饋點同接頭要做好防水
4. **避雷**：垂直天線通常係附近最高嘅金屬結構，一定要做好避雷措施
5. **固定牢固**：垂直天線受風力影響較大，要確保底座穩固
