# 八木天線

八木天線（Yagi-Uda Antenna）係一種高增益嘅方向性天線，由日本嘅八木秀次同宇田新太郎喺 1920 年代發明。喺業餘無線電界，八木天線廣泛應用於 VHF/UHF 通信、HF DX 通信同衛星通信。

## 基本結構

八木天線由以下元件組成：

```text
引向器3  引向器2  引向器1   有源振子    反射器
  |         |        |        ||         |
  |         |        |        ||         |
  |         |        |        ||         |
  ===============支撐桿================
                              ↑
                           饋點（同軸電纜連接處）

  ←————————— 信號方向 ————————————→
```

### 反射器（Reflector）

- 位於有源振子嘅後方
- 長度比有源振子稍長（約長 5%）
- 反射信號向前方
- 通常只有一條

### 有源振子（Driven Element）

- 唯一連接到饋線嘅元件
- 長度約為半波長
- 係天線嘅核心部分

### 引向器（Director）

- 位於有源振子嘅前方
- 長度比有源振子稍短（約短 5%）
- 引導信號向前方集中
- 數量越多，增益越高，方向性越強

## 八木天線嘅性能

### 元件數量同增益嘅關係

| 元件數量 | 大約增益 | 半功率波束寬度 | 前後比 |
|----------|----------|----------------|--------|
| 2 元（1反+1振） | ~5 dBd | ~65° | ~10 dB |
| 3 元（1反+1振+1引） | ~7 dBd | ~55° | ~15 dB |
| 5 元 | ~10 dBd | ~40° | ~20 dB |
| 7 元 | ~12 dBd | ~30° | ~20 dB |
| 10 元以上 | ~14 dBd+ | ~25° | ~20 dB+ |

### 元件間距

- 反射器到有源振子：約 0.15-0.25 波長
- 有源振子到第一引向器：約 0.1-0.15 波長
- 引向器之間：約 0.15-0.3 波長
- 更大嘅間距通常意味住更寬嘅帶寬

## 常見嘅八木天線類型

### VHF/UHF 八木

用於 2 米同 70 厘米頻段：

- 尺寸適中，容易安裝
- 常用於中繼器通信、DX 同競賽
- 通常 3-15 元件

### HF 八木

用於短波頻段（通常 10-20 米頻段）：

- 尺寸好大（20 米頻段嘅 3 元八木可以有 10 米長）
- 需要堅固嘅支撐結構同旋轉器
- 通常 3-7 元件
- 價格較高

### 衛星通信用八木

- 通常需要兩支八木（一支水平、一支垂直）組成圓極化
- 或者用交叉八木（Crossed Yagi）設計
- 需要仰角同方位角兩軸旋轉

## 商業八木天線推薦

### VHF 八木

## DIY 八木天線

### 2 米頻段 3 元八木天線

呢個係一個簡單但有效嘅 144 MHz 八木天線設計。

**材料**：

- 鋁管或者鋁條（直徑 6-10mm）
- 木條或者 PVC 管作為支撐桿（非金屬）
- 同軸電纜
- 接頭

**尺寸**（145 MHz 設計）：

| 元件 | 長度 | 距離反射器 |
|------|------|-----------|
| 反射器 | 1030 mm | 0 mm |
| 有源振子 | 980 mm | 340 mm |
| 引向器 | 930 mm | 680 mm |

**製作步驟**：

1. **準備支撐桿**：一條約 700mm 長嘅非金屬桿
2. **固定元件**：將三條鋁管/鋁條分別固定喺支撐桿上，互相平行
3. **饋點處理**：有源振子喺中間斷開，兩端各留約 10mm 嘅間隙
4. **連接饋線**：同軸電纜中心連接有源振子一邊，屏蔽連接另一邊
5. **阻抗匹配**：可以用 Gamma Match 或者 Hairpin Match
6. **測試調整**：用 SWR 計測量，微調有源振子長度

### 70 厘米頻段 5 元八木天線

430 MHz 嘅八木天線尺寸更細小，適合自製。

**尺寸**（435 MHz 設計）：

| 元件 | 長度 | 距離反射器 |
|------|------|-----------|
| 反射器 | 345 mm | 0 mm |
| 有源振子 | 328 mm | 105 mm |
| 引向器1 | 310 mm | 180 mm |
| 引向器2 | 305 mm | 310 mm |
| 引向器3 | 300 mm | 460 mm |

## 天線旋轉器

對於方向性天線，旋轉器（Rotator）係必需嘅配件，令你可以將天線指向唔同方向。

### 常見旋轉器

- **Yaesu G-450C**：中型，適合 VHF/UHF 八木
- **Yaesu G-1000DXC**：大型，適合 HF 八木
- **Yaesu G-5500**：雙軸（方位 + 仰角），適合衛星

### 安裝注意

- 旋轉器需要堅固嘅支撐結構
- 控制線要同同軸電纜分開走線
- 定期檢查機械部分嘅磨損

## 八木天線嘅優缺點

### 優點

- 高增益
- 良好嘅前後比，可以抑制背後嘅干擾
- 方向性強，可以集中信號
- 結構理論成熟，設計工具豐富

### 缺點

- 需要旋轉器嚟改變方向
- 尺寸較大（特別係 HF 頻段）
- 安裝同維護較複雜
- 風阻較大
- 只覆蓋單一頻段（除非用多頻段設計）
